# 项目长期约定

- 剧库是独立的发行内容，不依附制作项目。支持本地视频导入和从当前项目列表选择成片导入；项目只作为来源。团队支持多个小程序，各小程序独立选剧和上下架。
- 剧库和小程序首期复用现有 Java 后端及团队权限；手工 AppID 绑定不等于微信官方扫码授权。真实小程序归属和密钥通过服务端可信配置校验。
- 用户2026-10-09提供四张目标小程序截图：底部四栏“追剧 / 小剧场 / 推荐 / 我的”。追剧含观看记录和追剧列表及空态；小剧场含搜索、横向题材分类、横幅、新剧上线三列海报和排行榜；推荐为黑底视频及剧集信息/看全集；我的含身份、宣传横幅、追剧/观看/喜欢/客服入口。普通页面白底薄荷绿渐变，选中态亮薄荷绿，播放页黑底。截图是产品形态参考，不代表现有功能已实现。
