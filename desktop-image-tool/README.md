# ANTV生图 0.2.3

Windows 客户端：火山剧创资产名称同步 → 剧智创团队项目绑定与名称匹配 → 复用已有提示词 → 本机批量生图与保存。保留自由创作、参考图编辑和本地历史。

## 安装与使用

1. 安装 `release-antv/ANTV生图-0.2.3-Setup.exe`，或运行 `ANTV生图-0.2.3-Portable.exe`。最终用户无需安装 Node.js。
2. 客户端已内置 `https://antv.aixmax.cn`，无需填写平台地址。在「连接设置」点击「登录剧智创」，手动登录并关闭登录窗口。多团队必须选择团队；首次只有一个团队自动选中。团队权限撤销后需重新选择，不会自动改到其他团队。
3. 点击「登录火山剧创」，在独立内置浏览器正常登录并进入项目列表。客户端自动获取账号可访问的全部来源团队，无需选择来源团队或逐个打开项目。关闭来源窗口会隐藏并保持会话；关闭客户端主窗口会退出程序。
4. 点击「同步全部项目名称」。完整枚举团队、项目和剧本资产范围后，拉取角色、场景、道具名称。接口不兼容、分页不完整或登录失效会明确报错。空白名称变体不参与名称匹配，并在客户端显示排除数量。
5. 为来源项目选择对应的剧智创项目，保存绑定，点击「按名称匹配」。按同类型和首尾去空白后的完整名称匹配，重名需人工选择。变体只在已匹配主体下关联。
6. 查看已有提示词。缺少提示词时点击「维护提示词」进入对应剧智创项目，维护后刷新。本流程不创建新提示词。
7. 右上角设置个人熊熊爱 API Key 与本机保存目录。勾选可生成资产，确认参数后加入队列，每个资产生成一张。
8. 在「任务队列」查看状态，设置 1～5 并发、暂停/继续、取消等待项或明确重试。所有项目批量任务与自由创作共用一个调度器。

## 真实接入的验证边界

本版已完成代码、本地模拟服务联调与构建。配套后端与运维中心联合发布，结果见 [发布记录](../docs/operations-desktop-production-release-2026-11-05.md)。已用现有火山登录态完成来源只读采集：2 个团队、44 个项目、55 个剧本范围、4,909 条有效资产名称（角色 2,222、场景 1,648、道具 1,039），另排除 1 个空白名称变体。测试不上传生产名称清单，不调用真实付费模型。

- 部署配套后端与 Flyway V176 后再接入，见 [CLOUD_SETUP.md](CLOUD_SETUP.md)。旧后端未升级时客户端会提示桌面资产接口不可用；自由创作可独立运行。
- 来源范围使用 DescribeUser 的 MemDescription.Teams，每次同步重新读取；随后分页调用 ListProjects、ListScripts、ListCharacters、ListScenes、ListProps。接口通过来源网页 SDK 调用，使用网页自身的认证处理，无需获取或导出 Cookie。
- 每个项目均需分页枚举 ListScripts，默认 ScriptId 不能代表所有剧本。来源接口变化时仍需更新适配。剧本列表只在网页内投影编号，不向客户端传回原文或剧本元数据。
- 登录可能失效，不能承诺自动续期。实际图片服务权限、余额和生成质量需使用个人 Key 验证。

## 存储与任务行为

- 新增云端只存来源项目和资产名称、必要编号、父级与匹配关系，不存剧本原文、源站图片/描述/提示词、Cookie 或模型 Key。来源写接口正文不会被读取或解析。
- 剧智创与火山剧创分别使用独立持久 Chromium 会话；不同剧智创域名也隔离。云请求使用会话 Cookie、CSRF 与实际团队权限，服务端重新校验成员和目标项目权限。
- Key 使用 Electron safeStorage / Windows DPAPI 按 Windows 用户加密，保存在用户数据目录，不回传界面、不进入任务记录。便携版也使用该目录。
- 图片调用沿用固定 `http://89.58.47.162:8080/responses`，外层默认 gpt-6-astra，image_generation 模型默认 gpt-image-2。实际推理由远程服务执行；本机加密不改变原有 HTTP 传输方式。
- 入队保存完整提示词、参数、来源及目标编号和输出位置快照，后续设置修改不改变已有任务。Key 在派发时从本机读取。
- 导出按「团队及编号 / 来源项目及编号 / 类型」分目录，文件名含资产及编号；变体含主体与形态名称。重名追加序号，不覆盖原文件。
- 原图、缩略图、提示词与参考图另存本机 creations/。导出失败可从历史另存原图，无需再次生图。
- 暂停阻止后续派发；降低并发不强制终止已提交任务。停止等待不能保证上游停止生成/计费，不会自动重试。
- 重启后未提交任务保持等待并暂停；已提交且结果未知的任务标记中断。明确重试会新建记录，保留原快照及目录。
- 自动同步默认关闭，设置分钟数后仅更新名称，不自动生图。退出、关机或休眠期间不执行；恢复时最多补一次检查。登录失效则暂停。

## 开发与验证

Node.js 22+，npm / package-lock，严格 TypeScript，Biome。

```powershell
cd desktop-image-tool
npm ci
npm run lint
npm test
npm run smoke
npm run smoke:workflow
node scripts/source-browser-smoke.cjs
npm run pack
node scripts/packaged-smoke.cjs
node scripts/source-browser-smoke.cjs --packaged
```

smoke 验证原有创作、Key 加密、参考图、预览保存、重启及主窗口关闭后隐藏窗口退出。smoke:workflow 使用本地 HTTP 云服务和本地图片响应，覆盖 Cookie/CSRF、团队选择/撤销、白名单名称上传、绑定匹配、项目切换竞争、12 个批量任务+自由创作共用 5 槽位、暂停/降低并发、分组保存和重启。均不调用真实模型。

source-browser-smoke 使用全新临时会话直接启动 Electron，验证真实火山登录表单、窗口实际绘制、关闭隐藏与重新打开；不使用调试器驱动浏览器，避免改变初始化行为。`--packaged` 读取安装包内的采集器代码。0.2.2 已修复首次导航白屏；0.2.3 移除 ListTeams 和手动切换来源团队的依赖，修正网页 SDK 认证调用，并显示空白名称变体的排除数量。

可用 ANTV_ELECTRON_EXECUTABLE 指定测试 Electron。开发依赖为 Electron 45.2.1，本次安装包使用已校验的 45.2.3 运行时；可用 `npm run pack -- --config.electronDist=本机已校验运行时目录 --config.electronVersion=45.2.3`。安装包未配置商业代码签名。
