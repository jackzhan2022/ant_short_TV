## Why

资产提取目前只能使用一套固定美术模板。项目需要选择不同系统方案，并让方案的完整正负向提示词、图片规格和角色一致性要求真实作用于最终生图。

## What Changes

- 提供动态系统资产 Skill 目录与项目选择，保留现有默认方案，增加基于用户提供文档的仿真人方案。
- 分离固定工具与事实协议和可替换的美术规则；完整提示词、负向词、比例、视觉设定及美术补充分开保存。
- 支持场景形态提取，保持身份与状态分离。
- 全量、单集和范围重提取使用项目选择并冻结规则，预估和防重使用一致的规则版本。
- 单张与批量生图继承资产规格，避免画风拼接覆盖选定方案。

## Capabilities

### New Capabilities
- `system-asset-extraction-skills`: 系统方案目录、项目选择、提取与最终图片生成的一致执行。

### Modified Capabilities
无。

## Impact

项目 API 和创建/编辑界面、Workflow Skill 解析与 Runner、逐集调度及范围重提取、资产保存/目录、生图请求和批量预检、数据库项目配置迁移及相关测试。
