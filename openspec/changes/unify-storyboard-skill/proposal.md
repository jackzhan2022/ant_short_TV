## Why

分镜的四份 Skill 分散了导演方法、素材协议与提示词表达，还存在通用读取指令和服务端预加载流程的冲突。用户要求统一为一份，并采用参考文档中更细的拆镜、表演和连续性规则。

## What Changes

- 新增中文“短剧分镜制作”Skill，统一原四份规则并增强场景拆镜、动作结果、空间/道具连续性、对白时长和口型规则。
- 现有分镜 Agent 的四个内置关联合并为一个；其他 Agent 的共享基础规则和关联保留。
- 租户只维护一份分镜补充，旧②④按原顺序合并且完整留档；继续系统 100、租户 200 并存。
- 更新编辑入口与分镜声音文字展示，保留现有 Schema、素材标签、占位和时长校验。

## Capabilities

### New Capabilities
- `unified-storyboard-skill`: 单一分镜 Skill、导演方法和现有规则迁移。

### Modified Capabilities

无；现有分镜保存协议与租户权限继续生效。

## Impact

影响 Skill 文件、分镜 Agent 关联、租户可编辑 code、历史租户记录迁移、编辑页面和声音展示。新增迁移留档表；发布前备份数据库和 Skill 文件，旧分镜专用文件仅在无其他引用时可恢复地归档。
