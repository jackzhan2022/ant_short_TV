## Why

当前微信支付 API v3 集成依赖运维人员手工下载并配置单个平台证书，无法自动跟随微信支付平台证书轮换，容易导致下单响应或支付回调在证书更新后验签失败。微信支付官方 Java SDK 已提供自动下载和更新平台证书的标准能力，应在支付上线前迁移到官方维护的信任管理链路。

## What Changes

- 引入微信支付官方 Java SDK，并使用全局单例的自动证书配置下载、缓存和轮换微信支付平台证书。
- 将 Native 下单、查单和关单迁移到官方 SDK，由 SDK 统一完成请求签名与响应验签。
- 将支付通知验签和资源解密迁移到官方 SDK，同时保留现有 AppID、商户号、订单金额、币种、订单状态和幂等校验。
- 移除运行时对 `WECHAT_PAY_PLATFORM_CERTIFICATE_PATH` 的依赖，不提供绕过验签的降级模式。
- 在微信支付未启用时避免初始化 SDK 或访问微信接口；配置无效或证书获取失败时支付能力必须失败关闭。

## Capabilities

### New Capabilities

- `wechat-pay-platform-trust`: 定义微信支付平台证书自动获取、轮换、验签复用、配置校验和失败关闭行为。

### Modified Capabilities

无。

## Impact

- 后端商业化支付适配层、微信支付通知解析器和支付配置。
- Maven 新增微信支付官方 Java SDK 依赖。
- 环境变量模板和支付运维说明不再要求本地微信支付平台证书文件。
- 商业订单状态机、支付记录、通知审计、对账、幂等和权益发放接口保持不变。
