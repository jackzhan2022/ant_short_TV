## Why

团队列表、成员、角色和权限目前分散在多个入口，管理员需要频繁切换页面，导航也出现重复。将四类管理能力收敛到一个团队管理页面，可以让团队治理流程集中、可发现且保持既有权限边界。

## What Changes

- 将团队管理主页面改为四个 Tab：团队列表、成员管理、角色管理、权限树。
- 复用现有成员邀请/移除/角色分配、角色 CRUD 和权限树内容。
- 隐藏旧的成员与角色菜单入口，并将旧路由重定向到团队管理页面。
- 保留团队所有者权限控制、当前团队选择和既有 API 行为。

## Capabilities

### New Capabilities

- `team-management-navigation`: 集中式团队管理四 Tab 导航与内容复用

### Modified Capabilities

## Impact

影响前端团队路由、团队列表/成员/角色页面组件及其测试；不新增后端 API 或数据迁移。旧路径仍可访问但不再出现在主菜单中。
