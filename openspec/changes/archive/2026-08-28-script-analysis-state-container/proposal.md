## Why

剧本页在分析未完成时仍会渲染正文、大纲和分集区域，用户容易误以为这些内容已经可用。需要一个明确的剧本状态容器，让解析阶段成为页面主体并与完成后的工作台清晰隔离。

## What Changes

- 新增剧本分析状态容器，统一承载初始化、解析中、失败和完成前的页面状态。
- `PENDING`、`RUNNING`、`RETRYING` 时保留顶部骨架，展示“当前剧集解析中”、提示文案和四阶段进度。
- 分析未完成时不挂载正文、大纲、分集等工作台主体。
- `FAILED` 时展示错误原因和重试入口；`COMPLETED` 时恢复现有工作台。
- 刷新页面继续读取已有任务并轮询，不创建重复分析任务。

## Capabilities

### New Capabilities

- `script-analysis-state-container`: 剧本解析状态驱动的页面容器

### Modified Capabilities

## Impact

影响制作台剧本页及其测试；复用现有分析 API、阶段模型、轮询和重试逻辑，不修改后端接口或数据库。
