## Context

现有路由页面分散在多个顶层菜单，团队管理已聚合团队列表、成员、角色和权限树，但邀请仍是独立页面。Umi 路由支持嵌套路由，可在不改变绝对 URL 的情况下调整菜单层级。

## Goals / Non-Goals

**Goals:**

- 形成创作、我的、管理、商业四个清晰的菜单分组。
- 团队管理页面提供团队列表、成员、角色、权限树、邀请五个 Tab。
- 保留旧 URL、权限判断和页面业务逻辑。

**Non-Goals:**

- 不改后端接口、权限编码、数据模型或页面业务流程。

## Decisions

- 使用新的路由分组对象承载菜单标题，子路由继续使用现有绝对路径，避免破坏书签和跳转。
- 将邀请页面抽取为可复用内容组件，由团队管理页面以第五个 Tab 挂载；独立路由改为隐藏重定向。
- 菜单分组和子项沿用现有 `access` 权限，未授权项不显示。

## Risks / Trade-offs

- [嵌套路由配置可能影响菜单选中态] → 增加路由可见性和页面导航测试。
- [邀请内容重复加载] → 仅在邀请 Tab 激活时挂载组件，并复用原请求逻辑。

## Migration Plan

仅发布前端配置和组件变更，无数据迁移。若出现导航问题，回滚前端 release 即可恢复旧菜单。
