## Why

当前的项目创建入口还是一个单步弹窗：先填通用项目信息，再进入后续工作台，而且没有一个独立的短剧创作菜单入口。你给的两张参考图显示，用户更需要的是一个围绕短剧创作场景的引导式创建流程，先处理“输入剧本/跳过输入 + 浏览灵感”，再补全项目基础配置。

## What Changes

- 新增独立的顶部菜单入口“短剧创作”，作为短剧项目创建的主入口。
- 将现有项目创建入口升级为两步式创建流程，保留当前 `createProject` 接口作为提交终点。
- 第一步支持剧本输入或跳过输入，并展示与当前创作方向相关的灵感广场内容。
- 第二步补全当前创建表单中缺失的项目字段，形成更完整的项目初始化配置。
- 调整创建页的信息结构与交互顺序，让用户先获得创作启发，再配置项目参数。
- 扩展前端项目类型、表单模型和后端创建请求，使新增字段能够被稳定保存和回显。

## Capabilities

### New Capabilities
- `script-project-creation`: 短剧项目创建的两步式引导、灵感广场浏览、脚本输入与项目初始化配置。

### Modified Capabilities
- None.

## Impact

- Frontend: 侧边栏菜单、创建路由、`frontend/src/pages/projects/list/` 的创建入口、相关表单组件、项目类型与本地状态流。
- Backend: `backend/src/main/java/com/antshorttv/project/ProjectRequests.java` 和项目创建/更新相关服务、测试与返回模型。
- API contract: 现有项目创建接口保持入口不变，但请求字段会补充新的创作初始化信息。
- Tests: 需要补充创建流程、字段校验、灵感广场展示与回填行为的前后端测试。
