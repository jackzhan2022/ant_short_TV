## Why

当前“AI 拆解分镜”虽然创建异步执行并调用文本模型，但没有分镜专用 Workflow Agent，也没有消费模型结果，而是固定写入三条示例分镜。系统需要一个按集独立运行、通过受控工具读取可信上下文并正式保存结果的分镜 Agent，才能生成可编辑且可直接作为视频提示词使用的真实分镜内容。

## What Changes

- 新增 `short-drama-storyboard` Workflow Agent，用户在分镜页选择一集后显式运行，每次请求只创建一个该集的 Agent Run。
- Agent 通过受控读取工具获取当前集正文、相邻集概要、全局剧情理解、项目画风，以及当前集可用的人物、场景和道具素材。
- 新增分镜规划与 Seedance 视频提示词 Skill；Seedance 词典作为可扩展示例而非封闭枚举。
- Agent 在一次 Run 内规划当前集全部分镜，并通过新的 `save_episode_storyboards` 工具提交结构化结果；未成功调用保存工具时不得完成。
- 每个正式分镜对应一个完整提示词输入框和一个独立视频生成单元；每个分镜内部包含多个重新编号的镜头，总时长为 10 至 15 秒。
- 保存工具校验整集剧情顺序与完整覆盖、对白/旁白/内心 OS 原文、单镜时长和动作复杂度，并在全部结果有效后事务性覆盖当前集原有分镜。
- 系统根据项目设定和素材绑定渲染固定格式的完整提示词，并在所有已匹配的名称位置插入带素材类型、素材 ID 和素材版本 ID 的标签；未匹配项保留普通名称并标记待补充。
- 移除当前分镜拆解路径写入固定示例内容的行为。

## Capabilities

### New Capabilities
- `short-drama-storyboard-agent`: 定义按集运行的分镜 Workflow Agent、Skills、受控读取与保存工具、结构化分镜契约、校验、素材标签绑定、提示词渲染和整集原子替换行为。

### Modified Capabilities

无。

## Impact

- 后端 Workflow Agent 注册、运行契约、工具目录、作用域校验和分镜持久化服务。
- 现有 `storyboard_breakdown` AI 业务场景及异步执行路径。
- 分镜数据结构，需要容纳一个分镜内的多个镜头、完整提示词和结构化素材标签元数据。
- 分镜页的按集生成入口、执行状态展示和完整提示词输入框。
- AI 调用、执行审计、积分预占/结算继续复用现有基础设施；文本模型取项目设定，视频模型不属于本变更范围。
