## Why

当前平台可以基于文字生成和改写剧本，但不能把用户上传的短剧视频还原成可编辑的分集剧本。视频拆剧需要保留每集的原始素材、解析过程和审核结果，并且需要真实接入支持视频理解的模型；现在引入阿里百炼 `qwen3.7-plus`，可以补齐从视频素材到分集剧本的入口。

## What Changes

- 新增视频拆剧批次，支持一次上传多个视频，并将每个视频视为一集素材。
- 新增视频拆剧单集任务，保存集数、视频文件、解析状态、剧本生成状态和失败信息。
- 将视频上传到对象存储，并为 Qwen 请求生成可访问的视频 URL。
- 通过阿里百炼 `qwen3.7-plus` 逐集解析视频，提取人物、场景、道具、时间线、对白、动作和情绪等结构化信息。
- 根据单集解析结果生成标准化剧本草稿，支持单集重试和重新生成。
- 提供批次进度、单集状态、解析结果、原始 AI 响应和草稿剧本的查询能力。
- 用户审核确认后，才将单集草稿保存为现有剧本版本体系中的视频导入版本；不直接覆盖当前剧本草稿。
- 将视频解析和剧本生成的真实 AI 调用写入现有 AI 调用日志，并记录模型请求 ID、耗时和错误信息。

## Capabilities

### New Capabilities

- `video-script-decomposition`: 管理短剧视频批次、逐集视频解析、结构化结果、剧本草稿和审核确认流程。

### Modified Capabilities

暂无。

## Impact

- 后端新增视频拆剧任务、单集结果、解析结果及相关 API、异步执行器和数据库迁移。
- AI Gateway / Provider 配置需要支持阿里百炼视频理解模型及视频 URL 请求格式，默认模型为 `qwen3.7-plus`。
- 对象存储需要提供视频上传和模型可访问 URL；URL 不可访问时，单集任务必须明确失败。
- 前端项目详情或剧本工作区新增视频上传、批次进度、单集解析结果、剧本审核和确认入口。
- 复用现有剧本、剧本版本、AI 调用日志、对象存储和权限体系。
- 需要增加阿里百炼 API 的集成测试、异步任务测试、结构化解析失败测试和前端交互测试。
