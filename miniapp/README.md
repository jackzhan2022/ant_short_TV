# 短剧小程序

原生微信小程序。首页采用浅色剧库；播放页采用全屏竖向切集，同一部剧按后台实际发布目录播放，支持不连续集号。无第三方运行时依赖。

## 本地运行

1. 用微信开发者工具导入本目录，当前配置为简行易+（`wx2a250e3fe6b31ce4`）。导入其他小程序时请填写对应 AppID；需具有该小程序的开发权限。
2. `config.js` 已配置生产接口 `https://antv.aixmax.cn`，不带 `/api`。第三方平台模板也可用 `extConfig.apiBase` 覆盖。
3. 微信公众平台配置合法域名：请求域名为服务端域名；视频和图片 CDN 域名按开发者工具及微信平台的媒体域名要求配置。视频 CDN 需支持 HTTPS、Range 请求和当前签名查询参数，禁止用固定过期的签名 URL 当作剧集封面。
4. 服务端运行数据库迁移至 V177，完成小程序授权（或已有服务端配置的历史手工绑定）。管理后台编辑封面、题材、更新状态、计划总集数；导入视频，确认媒体信息；选择小程序和单集，执行预检后发布。
5. 编译并预览。首页、搜索、详情、观看足迹均调用真实接口，不含默认模拟数据。

## 自动检查

在仓库根目录运行：

```powershell
node --test miniapp/tests/*.test.js
node miniapp/scripts/validate.js
frontend/node_modules/.bin/biome lint miniapp
```

Node 测试覆盖跳集、切集请求竞态、后台恢复、观看进度、登录刷新及清空历史并发。静态检查覆盖 JS、JSON、WXML 标签、表达式、页面路径与事件绑定；不能代替微信编译器与真机视频组件测试。

## 播放行为

- 上下滑动只切换当前剧的已发布单集；轻拖由原生 swiper 回弹，首尾反馈不循环。
- 仅当前页创建 video。下一集预取的是短期播放地址，切入时重新判断有效期；不同时播放多个视频。
- 点按播放/暂停，进度拖动、静音、0.5～2倍速、清屏、分组选集和自动下一集。横版内容用 contain 完整显示。
- 播放中大部分控件三秒后收起，保留底部选集入口；暂停后显示控件。顶端避开微信胶囊与状态栏，底部适配安全区。
- 播放地址有效期300秒，提前30秒刷新并保留当前进度；从后台回来重新检查地址。src 更新后通过 loadedmetadata 再次 seek 恢复位置。
- 每五秒、切集、离开及播放结束写入进度。断网进度暂存在当前微信用户的本地存储，下次进入页面补传。同一播放会话使用递增序号防止乱序覆盖；服务端按小程序和 openid 隔离。
- 清空历史先等待当前进度写入完成，再删除服务器历史与本地补传队列。不同设备上的新观看行为仍可生成新的历史。
- 已下架单集不可播放；用户可返回剧库获取最新目录。登录401会重新微信登录并重试一次。

## 体验版与正式版

本仓库新增的 `miniapp/` 是小程序源码，不会因后台“发布剧集”自动上传到微信。先在开发者工具上传此源码；多小程序场景将验证过的代码加入第三方平台模板库，沿用管理端模板上传/体验码流程。体验版验证通过后，由有权限的运营人员在微信公众平台提交代码审核，审核通过后手动发布正式版。

上架剧集只更新服务端内容版本；普通标题、封面、简介、单集标题修改先保存为草稿，需要再次预检和发布才会影响线上目录。小程序按内容版本识别分页期间的目录变更并重新加载。

## 真机验收

需要实际 AppID、服务端域名、COS 媒体分析权限和已发布视频：验证 iOS/Android 触摸切集与短拖回弹、视频上层控件点击、横版字幕、弱网、长暂停超过五分钟后的续播、微信切后台、连续快速切集、最后一集和下架状态。代码测试通过并不表示这些平台行为已经实机验证。
