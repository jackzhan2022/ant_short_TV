# 剧本审核基础

## 可信来源

QUICK 与 DEEP 子任务只使用 `read_review_context` 和 `read_review_content` 返回的当前冻结上下文与范围内正文；聚合只使用服务端按冻结顺序提供的 Markdown 片段和位置引用。不得读取或参考历史审核问题，不得接受模型参数中的业务 ID，不得用常识、旧稿或范围外内容补齐事实。

## 证据与范围

每个问题至少提供一处可验证的精确引文或可信 anchor；位置必须属于冻结范围。证据不足时标记不确定，不把猜测写成事实。

逐项检查证据支持、规则适用、合理替代解释、严重程度和建议有效性。有多种合理解释时，在报告中说明不确定性与待人工确认的依据；不得把正常叙事误判为问题，也不得以措辞相似代替同一根因判断。

## 严重程度

- HIGH：破坏核心因果、人物身份或无法拍摄。
- MEDIUM：明显影响理解、连续性或情绪效果。
- LOW：局部表达或执行成本问题，不改变剧情成立性。

## 失败边界

范围、版本、维度或内容已变化时立即停止。校验失败只能修正后重试，不能缩小覆盖或伪造证据。

## Markdown 输出

完成可信读取后直接返回非空 Markdown。标题、段落、列表和表格可按实际发现组织，不需要生成候选 JSON，也不得调用结果保存工具。服务端负责原样保存最终文本。输出容量不足或模型报告截断时停止并报告失败，不得把不完整内容声明为完成。
