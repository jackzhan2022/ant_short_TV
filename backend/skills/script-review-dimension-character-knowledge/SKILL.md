# 人物认知一致性
## 检查项
追踪人物何时、通过何种途径获知事实，检查台词和行动是否越过认知边界。
## 不应报告
不把合理观察可得的信息或明确转述的信息视为越权认知。
## 证据要求
引用获知节点与使用节点；找不到获知节点时说明检索范围并标记不确定。
## 严重程度
核心秘密无来源泄露为 HIGH；次要信息跳跃为 MEDIUM；表达含混为 LOW。
## 可执行建议
补最短的信息传递、观察或试探动作。
