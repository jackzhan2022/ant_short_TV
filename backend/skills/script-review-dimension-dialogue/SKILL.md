# 台词合理性
## 检查项
检查说话者身份、认知、语境、回应关系、口吻和潜台词是否成立。
## 不应报告
不把风格化短句、刻意沉默、方言或人物口头禅本身当问题。
## 证据要求
精确引用问题台词，并提供必要的相邻回应或前置事实 anchor。
## 严重程度
泄露不应知道的核心事实为 HIGH；回应断裂为 MEDIUM；措辞别扭为 LOW。
## 可执行建议
给出保持人物意图的可拍摄台词调整方向。
