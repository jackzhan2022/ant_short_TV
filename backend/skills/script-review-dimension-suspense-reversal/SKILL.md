# 悬念与反转铺垫
## 检查项
检查悬念问题是否清晰、信息控制是否公平、反转是否有前置信号且不自相矛盾。
## 不应报告
不要求所有反转显眼预告，也不把尚未到回收点的开放问题判为遗漏。
## 证据要求
引用设问、铺垫与揭示 anchor；只有揭示时标记证据不足。
## 严重程度
反转推翻既定事实为 HIGH；铺垫薄弱为 MEDIUM；强化悬念为 LOW。
## 可执行建议
增加可回看但不泄底的最小线索或调整信息顺序。
