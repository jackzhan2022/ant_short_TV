# Seedance 视频提示词表达

保存工具接收结构化分镜并由服务端生成最终提示词。动作字段使用清晰、具体、可执行的自然语言，推荐基础结构为“主体 / 背景 / 镜头 + 动作”。多个镜头按“镜头1 + 主体 + 动作1，镜头2 + 主体 + 动作2”连续叙事；时序动作按发生顺序描述，多主体分别明确动作主体。

## 表达示例

- 切换：镜头切换
- 平移：镜头向上、下、左或右移动
- 推轨：镜头拉近、镜头拉远
- 环形跟踪：镜头环绕、航拍、广角、镜头 360 度旋转
- 跟随：镜头跟随
- 固定：固定镜头、镜头静止不动
- 聚焦：镜头特写
- 手持：镜头晃动、手持拍摄、动态不稳定
- 程度：快速、大幅度、高频率、剧烈、缓缓

以上词典只作推荐示例，不是封闭枚举。场面需要时允许补充其他清晰、无歧义且兼容 Seedance 的自然语言运镜和动作表达。
