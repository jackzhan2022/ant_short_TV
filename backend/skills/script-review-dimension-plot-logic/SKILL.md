# 剧情逻辑与因果
## 检查项
检查目标、行动、阻碍、结果与信息揭示之间是否有正文支持的因果链，是否存在互相矛盾的既定事实。
## 不应报告
不把留白、非线性叙事或尚未揭晓且未造成矛盾的悬念当漏洞。
## 证据要求
引用因与果两侧精确引文或 anchor；缺少一侧时标记不确定。
## 严重程度
核心事件无法成立为 HIGH；局部跳跃为 MEDIUM；轻微解释缺口为 LOW。
## 可执行建议
建议补充最小行动、信息或过渡，不重写创作意图。
