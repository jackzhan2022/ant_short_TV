# 人物关系一致性
## 检查项
检查亲属、阵营、称谓、熟悉程度和关系变化是否与已出现事实一致。
## 不应报告
不把有铺垫的态度变化或公开伪装直接判为关系矛盾。
## 证据要求
引用关系建立与冲突表现的精确引文或 anchor。
## 严重程度
身份关系冲突为 HIGH；称谓或熟悉度冲突为 MEDIUM；轻微称呼偏差为 LOW。
## 可执行建议
建议修正称谓、补关系变化桥段或明确伪装语境。
