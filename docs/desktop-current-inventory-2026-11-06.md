# ANTV 生图 0.2.7：每次同步更新当前资产清单

## 最终行为

手动与定时同步均只采集每个火山剧创项目当前使用的资产名称。项目列表的 `ScriptId` 与源站点击项目的跳转规则一致；分页枚举 `ListScripts` 仅用于验证身份，不采集历史剧本资产。仅有一个剧本时可直接确认；多个剧本缺少有效当前指针时明确报错，不按列表顺序、时间或编号猜测。

客户端调用新增的 `POST /api/desktop/source-projects/sync-current`，要求完整快照。后端以团队、连接、来源团队和来源项目为范围锁定清单，在事务内更新当前资产并停用其他清单及其名称。失败回滚、保留此前有效数据；历史行保留在库内，不再显示或用于新建任务。旧版 `/sync` 保留兼容，客户端需要升级至 0.2.7 才使用新规则。

新清单可继承历史清单中唯一有效且有权限的目标项目绑定；绑定冲突时要求重新选择。不同清单的资产匹配不自动复制。同一清单再次更新保留已有匹配，名称或类型等变更需要复核。界面自动保持在原来源项目，隐藏已删除资产，不再将历史范围称为多个可选剧本。

不读取或存储剧本原文，不删除源站数据、本机图片或已入队任务快照。本次没有数据库迁移。客户端继续共用最多 5 个图片并发槽位。
