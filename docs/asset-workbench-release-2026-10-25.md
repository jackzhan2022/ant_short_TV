# 2026-10-25 资产工作台发布

本次发布包含今天完成的角色面部差异规则、角色提示词 AI 语义相似度检查及修改稿应用、主要形态提示词编辑、设定页自适应布局，以及项目音频、角色和分镜音色配置、道具精简和制作形态引用。

## 界面与交互

角色详情的主图和缩略图按可用高度紧凑排列，主要形态提示词保留独立展示和编辑区域。切换变装仍查看主要形态提示词；保存、取消不触发出图。资产归一与进入下一步跟随资产列表容器，在底部居中悬浮。分类、统计和操作工具栏按内容高度排列，长列表单独滚动。

相似度检查沿用项目文本模型、积分预估和确认，结果提供原文、修改稿及检查说明，修改稿必须由用户明确应用。道具精简先分析并展示建议，再由用户确认应用；源资产、图片和使用记录保留。

## 数据库与共享技能

Flyway 按顺序新增 V151、V152、V153、V154，建立项目音频、角色音色、分镜音色、道具精简方案、制作策略和角色相似度检查共六张表。这四项迁移仅新增结构，不改写历史角色提示词。

部署前备份数据库、共享技能和运行环境。实际共享技能目录中的角色识别框架同步加入面部结构差异规则，同时保留线上已有定制内容。历史迁移内容和校验记录必须保持一致。

## 发布与验证

前端完整测试 129 个文件、1045 项通过；Biome、TypeScript、antd 检查通过，antd 保留既有 requestErrorConfig 静态反馈 API 使用提示。后端回归覆盖角色相似度、道具精简、项目音频、音色视频引用、资产目录、视觉形态、归一、分镜引用和积分链路，使用隔离构建目录。

发布使用版本目录及原子 current 链接切换，旧静态资源保留，避免已打开页面的异步资源失效。后端确认 V154、六张新表和服务健康后再发布新前端。制品、备份校验值和线上验证结果记录在本次发布 manifest 和 deployment-receipt 中。

应用回退保留新增表及业务记录，不删除历史数据；切回旧应用前等待进行中的生成和分析任务排空，并恢复对应技能文件。真实模型检查和图片生成仍由用户按积分确认流程发起。
