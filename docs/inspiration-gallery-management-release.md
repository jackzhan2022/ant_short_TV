# 灵感广场管理发布说明

## 数据迁移与权限

- Flyway `V121` 为 `inspiration_creation` 增加提示词、标签、发布状态、来源和软删除字段及查询索引。
- 既有记录迁移为 `PUBLISHED` / `IMPORTED`，升级后继续在公开广场展示。
- 新权限 `PLATFORM_INSPIRATION_MANAGE` 默认授予 `PLATFORM_ADMIN`；其他账号无法调用管理 API。

## 上传限制与清理

- 图片仅支持 JPEG/PNG；浏览器压缩到最长边不超过 1920px、文件不超过 1.5MB，后端再次校验。
- 视频仅支持 MP4，最大 200MB；后端保存原视频并生成缩略图。
- 创建失败会尽力删除本次产生的媒体对象；删除内容先软删除数据库记录，再尽力清理对象存储。

## 回滚

1. 前端可先回滚管理入口，公开读取不受影响。
2. 后端回滚时恢复旧版查询与控制器，保留新增列，避免损坏已经上传的数据。
3. 不建议直接回滚 `V121` 或删除媒体对象；需要完整回退时先导出新增记录，再由运维核对对象存储引用后清理。
