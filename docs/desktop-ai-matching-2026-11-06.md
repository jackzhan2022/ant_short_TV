# ANTV 生图 0.2.5：桌面交互与 AI 名称匹配

本版将已预览的项目选择、账号状态和任务队列交互落入客户端，并接入真实文本模型辅助匹配。平台默认地址继续为 `https://antv.aixmax.cn`。

## 使用流程

1. 右上角账号入口查看剧智创、火山剧创的连接状态，登录或验证连接，配置同步间隔。状态来自实际接口验证，不能仅凭打开过登录窗口推断已登录。
2. 点击左侧来源项目卡片，在弹窗中搜索项目并选择剧本资产范围；取消不改变当前项目。右侧弹窗选择剧智创目标项目，确认后保存绑定。
3. 对未匹配、冲突或待复核资产点击「AI 辅助匹配」。在个人设置中配置 OpenAI 兼容的文本服务地址、模型和 Key；独立文本 Key 缺省时沿用本机图片 Key。
4. 查看名称语义匹配建议。单一候选默认勾选，多个候选需明确选择；用户确认前不会写入匹配。变体仅在已解析的主体下匹配，主体缺少提示词不阻止具有独立提示词的变体。
5. 勾选可生成资产，读取剧智创已有提示词后批量生图。主体/默认形态使用主体已有提示词；非默认变体使用变体自己的提示词。

## 数据与任务约束

- 云端只保存来源项目、资产原名、必要身份和匹配关系。文本服务仅接收名称、类型、主体名称和候选编号；不接收剧本、图片、已有提示词、Cookie 或其他平台登录凭证。
- 图片 Key、文本 Key 均使用本机 safeStorage 加密。设置界面只获知是否配置 Key。自定义远端文本地址使用 HTTPS，兼容本机 HTTP 服务及既有内置服务。
- 推荐在内存保留 10 分钟；确认时核对团队、项目绑定、来源状态和完整合法候选。新增 `/api/desktop/source-projects/assets/{id}/ai-match` 在事务锁内再次比较，过期或并发变化不能覆盖已有匹配。旧后端不支持时明确提示升级。
- 资产文件名主干逐字使用火山剧创原名，包括变体原名、句点和合法空格，不拼接主体、编号或序号。同名输出保存到独立导入批次目录，不覆盖旧文件。源名包含换行、Windows 无效字符等情况会在生图提交前提示修正；同步保留原名，避免悄悄改名。
- 图片任务的全局并发上限为 5，包括多个项目批次和自由创作。暂停只停止后续派发，重启不自动重试已提交但结果未知的请求。

## 验证

桌面端 TypeScript、Biome 和 85 项单元测试通过。隔离 Electron 流程覆盖本机加密 Key、真实 HTTP 文本请求、人工确认、已有提示词生图、原名保存、批次隔离及全局 5 并发。普通创作与项目批量流程分别完成回归；来源登录窗口使用全新会话实际打开验证。所有文本/图片模型响应均来自本地模拟服务，没有调用真实付费模型。

配套后端 27 项测试通过，覆盖并发确认、来源改名/父级变化、项目绑定变化、候选新增/删除/改名/提示词缺失、已有匹配保护及提示词来源。前端计费、商业化和运维菜单相关 56 项测试通过。仓库 lint 与 antd 检查退出码为 0，保留既有前端警告。
