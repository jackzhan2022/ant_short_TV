# 资产身份歧义自动处理

## 目标与交互

单集提取遇到多个同名或同别名候选时，由系统核对身份，用户不需要手动匹配。已有成功剧集保持原有结果；单集仍原子保存，不允许通过删减有效资产绕过错误。

1. 保存前汇总本次角色、场景、道具的身份冲突。
2. 向资产识别 Agent 返回当前作用域的候选描述、别名、来源集原文摘录和已有提示词状态。
3. 身份依据充分时填写 `assetKey` 复用；相同名称或通用别名本身不构成身份依据。
4. 依据不足时使用 `deferIdentity=true`，保留独立资产和本集绑定，由全剧归一核对。明确请求独立保存时，即使只剩一个候选，也不自动改为复用。
5. 全剧归一有原文证据时合并，否则保留单成员组。发布成功后，存活资产的待核对标记更新为 `RESOLVED`，后续生成按现有执行门禁继续。

## 数据与执行约束

- 待归一记录使用独立的内部 `normalized_name`，显示名称保持提取名称；不需要数据库迁移。
- `content_json.identityResolution` 记录状态、来源集、内容指纹、运行内条目标识及候选安全 key。
- 待归一幂等键包含资产类型、剧集、内容指纹、`localKey`、规范名和证据。同一提交重试不重复创建，不同条目不会因为共用名称和证据被提前合并。改变条目标识或证据的新提取可能保留额外记录，交给归一处理。
- 待归一记录不能被其他集直接引用；相关编辑和生成继续受归一门禁约束。
- 模型核对在数据库保存事务回滚之后进行，不在持有资产锁时调用模型。
- 自动纠错最多两次；身份核对阶段允许为后续可纠正校验错误预留一次模型/保存调用对，总步数增量不超过四步，原超时仍有效。
- 每个候选及来源摘录有长度限制，详细冲突反馈预算为 24,000 字符，整个反馈最多 64,000 字符。省略条目通过 `deferIdentities` 明确标记；极端超限使用 `deferAllUnresolved`，不允许假定已读取省略的依据。
- 只调整资产识别执行协议和全剧归一输入，不修改分镜技能。

## 验证范围

覆盖候选复用、多个分类一次反馈、作用域隔离、独立保存、跨集待核对引用拒绝、重复提交、同名同证据不同条目、归一合并或保留单例、对象格式别名保留、旧 JSON null 元数据、反馈总体积、纠错次数和步数，以及原有自动分镜派发门禁。

验证日志保存在 `.temp/asset-identity-*.log`。本次实现与线上数据修复分开，未主动触发线上付费分析。
