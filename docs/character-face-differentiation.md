# 角色面部区分

角色主体模板的 `脸型` 字段现在要求完整描述轮廓与比例、眉眼、鼻部、嘴唇。在已知设定允许的范围内，同批设计的独立角色应在至少三组结构上有明确差异；剧情要求相似、双胞胎等情况保留原设定。同一角色跨集、换装继续继承主体面部结构。

`read_asset_details` 在角色 `content.visualIdentity` 中返回从当前 `character_asset.prompt` 提取的视觉字段，供识别 Agent 对照与继承。仅提取白名单中的 Markdown 字段，不返回完整提示词、任务指令或服装。历史自由文本不能可靠解析时不编造设定。响应超限降为 `SUMMARY` 时保留脸型、性别、年龄，每字段最多 180 个 Unicode 码点，省略仍由 `contentTruncated` 标识。既有权限、剧本作用域、分页及 32 KiB 预算继续生效。

部署时同步更新后端与实际 `AI_WORKFLOW_SKILL_ROOT` 下的 `short-drama-asset-recognition-framework/SKILL.md`。无需数据库迁移。`FILL_EMPTY` 继续保留历史非空提示词；重新点击旧提示词生图不会自动补全旧的面部设计。处理已有撞脸资产时，先审阅并调整角色主体提示词，再生成主体图并检查头像对照，确认后再按新主体图重做换装图。

验收应选至少三个同性别、相近年龄的不同角色，在相同模型、画风和构图下生成头像对照，再为其中一个角色生成换装图，检查“不同角色可区分、同一角色面部稳定”。当前自动化测试验证字段传递、权限调用、历史兼容与摘要预算；实际图像差异仍需上述生图验收。
