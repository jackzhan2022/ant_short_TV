# 自由创作参考图片与自动虚拟人像恢复

## 参考图片入口

图片与视频生成均支持在创作区粘贴图片、本地上传，以及从可访问项目中搜索、选择图片资产引用。三种来源复用模型约束；本地文件保留上传进度、暂停和重试，项目图片直接引用并由服务端校验团队、项目权限与素材状态。

## 自动恢复与连续状态

原生火山 Ark 视频明确返回输入图片真人相似拒绝时，自动冻结本次参考图片，复用分镜视频的虚拟人像入库与容量队列。素材 Active 后重新校验原作者权限、模型与积分，创建独立计费的关联重试视频。每条原始失败记录最多自动恢复一次，自动子记录不再次触发恢复；准备期间防止手动重试重复创建。

同一张原创作卡片连续展示“生成中 → 智能虚拟化中 → 生成中 → 已完成”，使用与分镜相同的 `AVATAR_PREPARING` 阶段。原始执行及计费记录保留，列表合并自动子记录，状态筛选、计数、详情、预览和下载使用当前关联结果。准备或重试最终失败时展示当前失败原因。

服务商返回的结构化错误码会保留，视频、音频、文本和输出视频拒绝不会因相同真人描述触发图片入库。

## 容量与部署

沿用既有 `ArkAvatarRecoveryWorker` 和 `ark.avatar.recovery-enabled` 开关及 AK/SK 配置。生成中或提交结果待确认的关联视频会保护其库内素材，避免被容量回收；分镜视频原有 primitive project 参数入口保持兼容。

迁移 `V166__free_creation_avatar_recovery.sql` 扩展恢复队列、自由创作快照与资源消费者，支持无项目的自由创作。发布需要后端、迁移和前端配套更新。
