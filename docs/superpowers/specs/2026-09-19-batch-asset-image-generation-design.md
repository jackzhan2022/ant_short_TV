# 批量资产图生成设计

## 目标

- 将设定页现有“批量生成 / 全部生成”资产提取入口合并为一个菜单按钮。
- 支持在当前资产分类中多选资产，并批量生成主形象图或全部形象图。
- 对角色非主形象自动处理主形象参考图依赖。
- 批量操作具备预检、确认、持久化进度和部分失败语义。

## 选择与工具栏

- 角色、场景、道具资产卡均显示复选框。
- 选择范围仅限当前标签页；切换标签页时清空选择。
- 工具栏显示“全选当前分类”和“已选择 N 项”。
- 未选择资产时，“资产图生成”按钮禁用。
- “资产提取”菜单包含“提取当前分类”和“提取全部资产”，分别复用现有 `extractAssets(activeType)` 与 `extractAssets('ALL')`。
- “资产图生成”菜单包含“生成主形象图”和“生成全部形象图”。

## 批量确认

选择生成模式后先请求后端预检，再打开确认弹窗。弹窗显示：

- 所选资产数。
- 计划生成的视觉形象任务数。
- 已完成、生成中、缺少提示词和其它不可生成项目的跳过数量。
- 角色主形象成功后才能继续的依赖任务数。
- 图片模型、比例和每个形象的候选图数量。
- 预计总图片数量为“计划任务数 × 每项图片数”。

模型选项复用项目图片模型配置。比例选择复用单图生成的选项；所有资产类型默认 `16:9`，单个角色生成默认值同步改为 `16:9`。候选数量支持 `1/2/4`。

## 预检规则

- 请求只允许一种资产类型和非空资产 ID 集合，且所有 ID 必须属于当前租户和项目。
- `PRIMARY` 模式只考虑每个资产的主形象。
- `ALL` 模式考虑每个资产的全部有效视觉形象。
- 没有视觉形象的资产按一个待创建的“默认形象”主形象计算；正式提交时再创建，不在预检中写数据。
- `NOT_STARTED` 和 `FAILED` 为可生成状态。
- `COMPLETED` 和 `GENERATING` 默认跳过。
- 主形象使用资产主体提示词；非主形象使用自身提示词。空提示词项目跳过并报告。
- 角色非主形象在主形象已有可用图片时可直接提交；否则标记为依赖任务，等待本批次主形象成功。

## 持久化与执行

新增批次与批次项表：

- 批次保存租户、项目、资产类型、生成模式、模型、比例、候选数量、状态和汇总计数。
- 批次项保存资产、视觉形象、阶段、状态、对应图片任务、依赖项和错误信息。
- 批次状态支持 `PENDING`、`RUNNING`、`SUCCEEDED`、`COMPLETED_WITH_FAILURES`、`FAILED`。
- 批次项状态支持 `WAITING_DEPENDENCY`、`PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED`、`SKIPPED`。

提交批次时立即创建所有可直接执行的图片任务。角色依赖项保持等待：

1. 主形象任务成功后，使用已发布主图作为参考图创建对应非主形象任务。
2. 主形象任务失败时，对应依赖项转为 `SKIPPED`，记录“主形象生成失败”。
3. 单项失败不阻断其它资产；批次最终允许部分成功。

图片任务、模型解析、积分预留、结果发布与对象存储继续复用现有 `AiImageTaskService`。批次提交使用幂等键避免重复创建。

## 接口

- `POST /api/projects/{projectId}/asset-image-batches/preflight`
- `POST /api/projects/{projectId}/asset-image-batches`
- `GET /api/projects/{projectId}/asset-image-batches/{batchId}`

预检和提交请求包含资产类型、资产 ID、模式、模型、比例和图片数量。提交返回批次详情；查询返回汇总与批次项。

## 前端跟踪

- 提交成功后关闭确认弹窗并清空选择。
- 活跃批次每两秒查询一次批次详情，同时刷新资产汇总，使卡片状态覆盖层及时更新。
- 批次进入终态后停止轮询，并显示成功、部分失败或失败消息。
- 页面卸载或项目切换时停止轮询，迟到响应不得覆盖新项目状态。

## 权限与错误

- 预检需要资产查看与图片任务查看权限。
- 提交需要 `AI_IMAGE_TASK:CREATE` 与 `AI_SERVICE:USE`，并沿用项目访问边界。
- 空选择、跨类型资产、无可生成项目和无效模型返回明确业务错误。
- 积分不足或单任务创建失败记录到对应批次项，批次继续处理其它可执行项。

## 测试

- 后端覆盖预检分类、默认主形象、状态跳过、角色两阶段依赖、部分失败、租户隔离和幂等。
- 前端覆盖当前标签页选择、切换清空、无选择禁用、两个菜单、确认统计、提交参数和批次终态刷新。
- 回归覆盖单个视觉形象生成以及现有资产提取流程。
