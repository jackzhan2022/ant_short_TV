# 项目设定页统一图片占位设计

## 目标

统一项目设定页中角色、场景、道具和视觉形象画廊的无图状态，移除以资产名称首字作为占位的差异化表现。

## 组件

新增 `AssetImagePlaceholder` 页面级共享组件：

- 使用 Ant Design `PictureOutlined`，不新增远程图片请求或位图资源。
- 使用现有中性背景与次级文字颜色，保持设定页安静、工具型的视觉风格。
- 标准模式显示图片图标和“暂无图片”，用于外层资产卡与画廊主预览。
- 紧凑模式仅显示图片图标，用于画廊缩略图；通过 `aria-label="暂无图片"` 保留可访问语义。
- 组件尺寸由父级图片区域决定，不改变卡片、缩略图或主预览的现有布局。

## 数据流

`StableImage` 继续负责加载、解码和失败状态。无 URL 或图片加载失败时，由调用方传入统一的 `AssetImagePlaceholder` 作为 `fallback`。

生成中、等待生成和生成失败覆盖层继续位于占位图上方；加载中的旋转指示器保持不变。

## 接入范围

- 角色、场景、道具外层资产卡。
- 画廊每个视觉形象缩略图。
- 画廊当前视觉形象主预览。

## 验收

- 所有无图资产卡显示相同的图片图标和“暂无图片”。
- 所有无图画廊缩略图显示相同的紧凑图片图标。
- 无图主预览显示标准占位图。
- 不再显示资产名称或视觉形象名称的首字占位。
- 图片正常、加载中、生成状态和错误处理行为不受影响。
