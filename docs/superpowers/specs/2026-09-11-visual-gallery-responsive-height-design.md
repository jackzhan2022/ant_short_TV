# 视觉形象画廊弹窗高度自适应设计

## 目标

避免视觉形象画廊在较矮视口中超出屏幕而需要反复滚动，同时在大屏上保留足够的主图预览面积。

## 布局规则

- 画廊弹窗内容最大高度使用 `88vh`，并由弹窗内容区域内部处理溢出，页面背景不参与滚动。
- 主图预览高度从固定 `430px` 调整为 `clamp(260px, 48vh, 430px)`：小屏不会压缩到不可读，大屏不超过原有预览高度。
- 画廊内容使用纵向 flex 布局；标题、主体提示词和缩略图条保持自身高度，预览区占用剩余空间。
- 当内容仍超过可用空间时，仅画廊内容区域出现纵向滚动，缩略图条可继续保持横向滚动与右侧新增入口行为。

## 验收

- 预览图容器不再固定为 430px，而是随视口高度变化。
- 弹窗在常见笔记本分辨率下不推动页面整体上下滚动。
- 既有缩略图滚动、固定新增入口、删除确认及图片生成弹窗不受影响。
