# 视觉形象画廊与独立生成弹窗设计

## 目标

将制作台角色资产中的视觉形象管理从单一混合弹窗拆成两个明确的工作区：用于浏览和管理的视觉列表画廊，以及用于编辑并发起图片任务的角色生成弹窗。交互参考用户提供的两张界面图。

## 范围

仅调整 `production-workbench/settings` 前端交互与样式。不变更视觉变体接口、字段或后端任务流程。

## 视觉列表画廊

- 维持“管理角色视觉形象”的入口和现有主形象、变装列表数据。
- 弹窗以当前选中形象的大图为主视觉；左右切换可浏览变体，下方缩略图轨道直接选中变体。
- 名称、主形象状态、生成状态、关联剧集和失败提示围绕当前项呈现，避免在画廊内编辑任务配置。
- 画廊保留“设为主形象”和“删除”操作；“生成图片”或“重新生成”打开独立的角色生成弹窗。
- 主形象、变装和未生成占位图均可选中。键盘和现有可访问名称维持可用。

## 角色生成弹窗

- 画廊打开时保留在后台；生成弹窗显示当前变体名称和当前图片预览。
- 提示词使用可编辑的任务区。打开时预填该变体已保存的提示词。
- 用户点击“生成”时，以输入框的最新提示词调用既有视觉变体更新接口，然后调用既有图片生成流程。
- 若提示词没有变化，跳过无意义的保存请求，直接发起生成。
- 生成中、失败、成功状态继续使用既有接口返回的数据。成功后刷新画廊数据，用户关闭生成弹窗即可看到更新后的图；不自动改变主形象。

## 状态与错误处理

- 生成按钮在保存或生成请求进行时禁用，防止重复提交。
- 保存失败时不发起生成，并保留用户当前输入以便修正或重试。
- 生成失败时显示已有错误信息，画廊缩略图与状态保持可查看。
- 删除当前变体后，选择剩余的主形象或第一项；没有项时展示空状态。

## 测试

- 更新组件测试，验证画廊显示及选择一个变体。
- 验证点击生成/重新生成打开独立弹窗，且提示词被预填。
- 验证修改提示词后点击生成会先保存新提示词，再发起生成。
- 验证未修改提示词时不触发保存，但仍发起生成。

## 非目标

- 不新增模型、尺寸、比例等生成参数。
- 不加入下载、收藏、上传或从角色库选择等参考图中但项目当前没有的能力。
