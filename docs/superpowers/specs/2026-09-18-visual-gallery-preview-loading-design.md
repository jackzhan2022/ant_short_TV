# 视觉形象画廊预览加载设计

## 目标

- 主预览不直接暴露原始大图的渐进下载过程。
- 点击任一视觉形象缩略图后，主预览立即切换到对应形象。
- 画廊顶部不再展示资产主体提示词输入区域。

## 交互与数据流

- 缩略图仍以视觉形象 `id` 更新当前选择。
- 当前视觉形象有图片时，主预览先使用其缩略图；如果没有缩略图，则在原图就绪前保留稳定的占位背景。
- 浏览器在后台加载并解码当前视觉形象的原图。只有原图触发加载完成后，主预览才一次性替换为原图，避免展示逐行或逐帧加载过程。
- 原图加载状态同时绑定视觉形象 `id` 和原图 URL。用户快速连续切换时，先前图片的迟到加载事件不得覆盖当前选择。
- 当前视觉形象没有原图时，沿用名称首字占位行为。
- 移除画廊标题下方的主体提示词输入框及其失焦保存逻辑。生成图片弹窗中的提示词编辑保持不变。

## 实现边界

- 仅修改前端画廊组件及其测试，不调整服务接口和后端图片数据。
- 复用接口已有的 `currentImageThumbnailUrl` 与 `currentImageUrl`。
- 不增加动画、缓存库或新的通用图片组件。

## 验收与测试

- 打开画廊时，主预览先显示当前形象缩略图；原图加载完成后切换为原图。
- 点击另一个有图片的缩略图后，主预览立即使用该形象缩略图，并在对应原图加载完成后更新。
- 快速切换后触发旧图加载事件，主预览仍保持当前形象。
- 画廊中不再存在主体提示词输入框。
- 缩略图选择、上一张/下一张和生成图片入口保持可用。
