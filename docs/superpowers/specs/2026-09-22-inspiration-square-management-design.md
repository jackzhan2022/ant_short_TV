# 灵感广场管理抽屉设计

## 目标

为管理员提供灵感广场内容管理入口。管理员从页面右侧悬浮设置按钮打开管理抽屉，在不离开创作页的前提下新增、编辑、排序和控制内容展示。

## 范围

- 使用右侧抽屉承载“灵感广场管理”。
- 支持上传图片或视频作为灵感素材。
- 图片直接作为广场封面；上传前在浏览器端自动压缩，最长边限制为 1920px，目标文件体积不超过 1.5MB，并展示压缩状态及前后体积。
- 视频自动截取首帧作为缩略图。
- 每条内容维护标题、分类标签、完整提示词、展示状态及排序。
- 支持编辑提示词、上架/下架、拖动排序和删除；操作结果即时反映在广场预览区。

## 交互与状态

抽屉顶部展示内容数量和“新增内容”按钮。内容列表按排序值展示缩略图、标题、标签、素材类型、展示开关及操作入口。

新增或编辑使用抽屉内的表单面板。素材上传后显示处理过程：图片显示压缩中/压缩完成，视频显示缩略图生成中/生成完成。处理失败时保留原表单数据并显示可重试提示。保存后，内容立即出现在广场中；下架内容不显示在广场但仍保留在管理列表。

## 原型边界

本次只生成独立、可交互的 HTML 预览。上传、图片压缩、视频首帧预览及列表状态均在浏览器本地运行，不连接现有 API，也不持久化数据。

## 验收标准

1. 点击右侧设置入口可打开及关闭管理抽屉。
2. 可通过本地上传新增图片或视频灵感；图片被压缩，视频显示自动生成的首帧缩略图。
3. 可填写并编辑完整提示词，卡片仅显示摘要。
4. 上下架、排序和删除操作会即时更新广场内容。
5. 在窄屏下管理抽屉和表单保持可用，无内容遮挡。
