# 视觉形象画廊与生成弹窗设计

## 目标

将设定页的视觉形象管理升级为以图片为中心的画廊，同时保留独立的角色生成弹窗，并清晰展示角色变装生成使用的主形象引用图。

## 画廊

- 画廊弹窗以选中视觉形象的大图为主体，底部横向排列主形象、变装缩略图和新增变装入口。
- 缩略图显示名称、主形象标记和生成状态；可横向滚动，左右箭头切换大图。
- 当前形象继续支持设为主形象、删除、查看关联剧集和生成/重新生成。

## 生成弹窗

- 保留独立的“角色生成”弹窗。
- 上部同时展示待生成形象的当前图与引用图区域；角色的非主形象展示主体主图作为引用图，主形象则明确显示“无引用图”。
- 下部提供提示词编辑、项目可用图片模型选择、画面比例和生成数量；积分预估随所选模型和数量显示。
- 提交复用现有图片任务接口；非主角色形象继续将主图 URL 写入 `referenceImages`，不改变一致性生成逻辑。

## 测试

- 覆盖画廊缩略图选择和生成入口。
- 覆盖非主角色形象弹窗中的引用图展示及生成请求包含该引用图。
- 覆盖模型、比例、数量字段传入图片任务请求。
