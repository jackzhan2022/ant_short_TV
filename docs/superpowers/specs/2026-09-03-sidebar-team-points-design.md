# 侧栏团队积分入口设计

## 目标

在左侧侧栏账户区显示当前团队的实时积分余额。用户点击该行后进入充值中心。

## 交互与视觉

- 积分入口位于账户资料入口上方。
- 单行依次显示钱包图标、`团队积分`、右对齐的余额和跳转箭头。
- 整行是可访问的按钮，点击跳转至 `/recharge`。
- 加载中、未取得当前租户或请求失败时显示 `-`，不阻断侧栏其他操作。
- 悬停和键盘聚焦使用系统既有的浅紫背景与主色文字反馈。

## 数据流

- 新增一个全局积分状态，按当前租户通过 `queryTeamPointAccount(tenantId)` 拉取余额。
- 应用首次需要积分数据时请求一次；窗口重新获得焦点时刷新，避免固定轮询。
- 充值成功后调用同一状态的刷新方法，使侧栏与充值中心显示一致。
- 不修改后端接口，也不改动自动生成的服务代码。

## 验收与测试

- 当前租户 ID 会用于查询团队积分账户。
- 成功响应中的余额会展示在侧栏。
- 点击积分入口会导航到 `/recharge`。
- 无当前用户时继续不渲染账户区。
- 覆盖加载/失败时的降级展示，并运行组件测试、类型检查和 Biome 检查。
