# 视觉形象生成状态展示设计

## 目标

在资产列表、画廊主预览和画廊缩略图三个位置统一展示视觉形象生成状态，让用户能定位正在生成、生成失败和待生成的形象。

## 状态映射

- `NOT_STARTED`：待生成，使用默认灰色。
- `GENERATING`：生成中，使用蓝色。
- `COMPLETED`：已完成，使用绿色。
- `FAILED`：生成失败，使用红色。
- 未识别状态：显示原始状态值，使用默认颜色，避免后端新增状态时界面空白。

## 展示规则

- 外层资产卡根据 `generationSummary` 显示一个汇总状态，优先级为生成中、生成失败、待生成、已完成；标签包含该状态的数量。
- 画廊主预览下方将原始英文状态替换为对应的中文彩色标签。
- 每个画廊缩略图右上角显示该视觉形象自身的中文状态标签；现有悬浮删除按钮保持在缩略图右上角，状态标签放在左上角，避免重叠。
- 不增加轮询或后端接口。状态继续随现有数据刷新、画廊打开和生成提交后的刷新流程更新。

## 验收

- 有生成中任务的资产卡显示“生成中 N”。
- 主预览与当前选中视觉形象的中文状态一致。
- 每个缩略图显示自身状态，切换选中项不改变其它缩略图状态。
- 失败状态仍保留现有错误信息和重新生成入口。
