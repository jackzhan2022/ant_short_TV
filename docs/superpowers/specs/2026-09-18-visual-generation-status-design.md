# 视觉形象生成状态展示设计

## 目标

在资产列表、画廊主预览和画廊缩略图三个图片渲染区域内展示视觉形象生成状态，让用户能直接从图片区域识别正在生成、生成失败和待生成的形象。

## 状态映射

- `NOT_STARTED`：在图片区域显示“等待生成”。
- `GENERATING`：在半透明遮罩中显示旋转加载图标和“生成中”。
- `COMPLETED`：正常显示图片，不显示状态覆盖层。
- `FAILED`：在图片区域显示红色“生成失败”。
- 未识别状态：显示原始状态值，使用默认颜色，避免后端新增状态时界面空白。

## 展示规则

- 外层资产卡根据 `generationSummary` 在图片区域显示一个汇总覆盖层，优先级为生成中、生成失败、待生成；文案包含该状态的数量。全部完成时不显示覆盖层。
- 画廊主预览在图片区域显示当前视觉形象的状态覆盖层，移除预览下方的英文或中文状态标签。
- 每个画廊缩略图仅在缩略图片区域显示对应视觉形象的状态覆盖层，不遮挡下方名称和右上角删除按钮。
- 不增加轮询或后端接口。状态继续随现有数据刷新、画廊打开和生成提交后的刷新流程更新。

## 验收

- 有生成中任务的资产卡图片区域显示旋转加载效果和“生成中 N”。
- 主预览与当前选中视觉形象的覆盖层状态一致。
- 每个未完成缩略图在图片区域显示自身状态，切换选中项不改变其它缩略图状态。
- 已完成状态不显示覆盖层或额外状态标签。
- 失败状态仍保留现有错误信息和重新生成入口。
