# 视觉形象画廊缩略图操作设计

## 目标

将视觉形象画廊底部的新增与删除操作收纳到缩略图列表中，使画廊的操作方式与缩略图浏览保持一致。

## 交互

- 移除缩略图列表左侧常驻的“新增变装名称”输入框和“新增”按钮。
- 在缩略图列表最后渲染一张固定的“新增变装”虚线卡片。点击卡片后，在该卡片内显示名称输入框和确认新增按钮；提交成功后恢复为入口卡片并刷新列表。
- 每张已有视觉形象缩略图都使用可悬停的容器。鼠标移入时，在右上角显示仅含垃圾桶图标的危险操作按钮；未悬停时不占用缩略图空间。
- 点击删除图标不立即删除，而是先展示确认对话框。只有用户确认后才调用现有删除接口；取消则不改变当前选择或列表。
- 移除主预览信息区已有的文字“删除”按钮，避免同一删除操作出现两个入口。

## 边界与兼容性

- 继续复用现有的新增、删除服务，以及成功后刷新视觉资产的逻辑。
- 主图和非主图都可以通过缩略图删除入口删除，后端现有约束仍负责最终校验。
- 缩略图选择按钮与删除按钮分层，删除图标阻止事件冒泡，不能误触选择对应缩略图。
- 新增卡片始终排在变装/视觉形象缩略图之后，并可随横向滚动到达。

## 验收与测试

- 点击“新增变装”卡片出现名称输入与新增确认；提交后调用新增接口。
- 鼠标移入缩略图后可见删除图标；点击后出现确认对话框。
- 取消确认不调用删除接口；确认后调用现有删除接口。
- 原主预览区不再出现文字删除按钮。
