# 消息中心

左侧底部、团队积分上方的消息中心面向所有已登录用户；收件箱与当前团队无关，只读取本人收到的消息。支持分类、标题与阅读状态筛选、倒序分页、详情、批量已读和个人删除。

平台管理员可发送给指定用户或发送时的全部有效用户；发送前预览正文与范围。普通用户不能发送。消息来源和发送人由后端设置，客户端不能伪造系统来源。

管理员的「已发送」页面查询管理员及系统的全部发送记录，支持来源、分类、标题搜索。详情显示发送范围、正文、收件人数、已读/未读人数与分页收件明细。用户删除收件箱记录不会删除发送记录或改变历史投递人数。已发送正文不可编辑，未提供撤回或重复发送操作。

系统流程调用内部 `MessageCenterService.sendSystem(recipientIds, category, title, content)`；没有对外系统发信 API。本次未新增具体业务事件触发规则。

后端接口 `/api/messages/sent`、`/api/messages/sent/{id}`、`/api/messages/sent/{id}/recipients` 均强制校验平台管理员角色。

部署包含 V143，仅新增消息与收件状态两张表；基于线上 fc660c2 构建，保留原有 V142 自动资产规范化迁移。应用回滚保留新增表及已有消息，不回滚数据库或共享环境。

验证：54项相关前端测试、后端收发与权限集成测试、Biome/TypeScript、antd 检查和生产构建。全库现有 cookie 与静态反馈 API 警告不属于此功能。
