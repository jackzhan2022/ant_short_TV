# 画风 1.0 / 画风 2.0

## 使用方式

- 短剧创建页的「画面风格」可选择画风版本；项目列表的「编辑项目」也可切换。
- 新建和历史项目默认画风 1.0，沿用原画风库和资产生成规则。
- 画风 2.0 使用 11 种 Toonflow 衍生画风，每种展示一张对象存储示例图。点击图片放大预览，点击名称选择；同时展示分类与所选画风说明。
- 分镜技能独立选择。画风版本不修改分镜技能、拆镜方式、时长或输出结构。
- 切换配置不会覆盖历史提示词和图片。需要转换现有资产时，使用现有按范围重新提取及重新生成提示词功能；跨画风转换先处理主体，再处理依赖主体参考图的变体。
- 编辑过程中切换版本会记住各版本选项；画风 2.0 必须选定具体风格才能保存，从 2.0 切回 1.0 也必须选择旧画风。

## 数据与调用边界

- 项目新增 `visualStyleVersion`（V1/V2）与 `visualStyleCode`；原 `visualStyle` 保留可读名称，继续供现有分镜及生图流程使用。
- `GET /api/style-library/v2` 返回 11 种选项。原画风库接口和图片资源保持原样。
- 初始/手动分析任务、资产重提取和提示词补齐任务提交时保存完整美术规则快照。旧任务无快照时按 1.0 处理。重试使用已保存快照。
- 画风 2.0 快照参与资产重提取请求指纹。旧任务执行期间切换画风再提交，会触发现有任务冲突提示，不静默复用旧画风任务；同一幂等键仍返回原任务。
- 资产识别在专属运行消息中追加对应类别规则；不修改共享剧集前缀、缓存内容或分镜技能。
- 画风 2.0 的 `ALL` 提示词补齐拆成资产、分镜两次独立模型请求，各自使用不同幂等键；分镜请求不携带资产美术规则。任一范围无待补记录时跳过调用。画风 1.0 保留原单次调用方式。
- 继续遵循 `FILL_EMPTY` / `REGENERATE_ALL`、人工字段保护和现有资产提示词存储规则。

## 内容适配

规则位于 `backend/src/main/resources/art-styles/toonflow-adapted-1.json`。
每种画风包含公共视觉、角色、场景、道具规则，只在相关范围加载。

保留当前角色特写与全身三视图、场景正/俯/背/侧四宫格、道具白底展示规范和变体增量契约。不导入 Toonflow 的导演、运镜、视频、工具调用或审批流程指令。风格规则不得改写剧本事实、时代、角色身份或已确认资产结构。

来源固定为 Toonflow 提交 `ecd5325c7f9b38721491382ee6952fa2318b4693` 的 `visualStyles.md` 与 `assetDesign.md`，版权、MIT 许可及适配说明保留在同目录 `NOTICE.txt`。

2026-11-04 已通过「自由创作」上传旧版样图作为画风参考，生成 11 张新人物、新场景样图，每种一张。10 张使用 gpt-image-2.5-sunburst（high），国风赛博三维使用 gpt-image-2.5-flare（medium）；原图 1672×941。逐图任务编号、模型、提示词、原始 PNG 校验值及参考来源见 `frontend/public/media/art-styles-v2/sources.json`。旧参考来自 Toonflow 提交 `cd3e7c4e83963bea255be2e621eb78d2cd1c2188`；原许可与声明保留，参考生图不自动消除上游素材的权利义务。

## 示例图对象存储

- 复用现有 COS 原图上传、媒体登记、腾讯 CI `imageSlim` 压缩与持久化 CDN 签名授权服务。
- 固定清单位于 `backend/src/main/resources/art-styles/preview-images-v2.json`，记录画风代码、稳定资产 ID 和原图 SHA-256。独立 `STYLE_LIBRARY_V2` 类型，租户 0，不往 1.0 的 `style_library` 表插入数据。
- 原图对象键为 `materials/0/style_library_v2/202611/{assetId}/{sha256}/original.png`；展示图位于同版本 `derived/display.png`。
- `GET /api/style-library/v2` 返回稳定 `imageUrl`。`GET /api/style-library/v2/images/{code}` 只接受清单中的画风，校验 READY、对象键、MIME 与非空文件后，以 302 返回有效 CDN 地址，并设 `Cache-Control: no-store`。前端不保存过期签名，也不打包 WebP 图片。
- 独立维护工具见 `scripts/art-style-v2/`，先校验完整 11 张原图摘要，再导入；不启动业务调度器、不执行数据库迁移、不部署或重启应用。
- 2026-11-04 实测 11 个展示对象全部 READY，COS HEAD 元数据匹配，带站点 Referer 的签名 CDN GET 全部 200 且可解码。CDN 已有防盗链策略，省略站点 Referer 的请求返回 403。原始 PNG 已较充分压缩，`imageSlim` 仅小幅降低体积。
- 原始 PNG、WebP 备份和脱敏验证回执保存在本地 `outputs/art-styles-v2-2026-11-04/`。生产 `style_library` 保持 139 条。
- 再次执行导入后，既有压缩任务 ID、尝试次数与状态全部未变。11 张原图共 10,852,151 字节，展示图共 10,840,125 字节，无损压缩降幅约 0.11%。
