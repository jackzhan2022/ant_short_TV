# 分镜生成技能优化方案（生成阶段）

日期：2026年10月21日  
状态：已于2026年10月21日15:49整合到线上系统技能（北京时间）  
适用技能：`short-drama-storyboard-production`（短剧分镜制作）

## 一、优化目标

通过调整生成阶段的创作规则，让模型直接生成动作紧凑、情绪有推进、声画自然配合的分镜。

本方案采用现有生成流程，通过技能条款、规划顺序及示例改善首次生成结果，不增加审查模型、评分环节或生成后审查流程。本文记录本次确认并落地的修改方向；创作规则已整合到本地正式技能与线上系统技能。具体内容与验证见[发布记录](storyboard-generation-rhythm-skill-release-2026-10-21.md)。

核心方向：先明确剧情变化和声音需要，再组织连续表演，最后划分符合平台要求的生成单元。

## 二、这次问题说明了什么

新禾反馈对应《大伯一勺救酒楼》第1集《罚站误宴，大伯登门》。线上生成记录显示，以下安排在模型首次提交时已经存在：

| 分镜 | 原安排 | 需要改善的生成习惯 |
| --- | --- | --- |
| 第2镜 | 拿衣起身并说话4秒，再冲出门3秒 | 进一步组织动作与台词的连续关系，减少准备与离场的停留。 |
| 第5镜 | 站位3秒、握拳3秒、隐忍面部4秒 | 同一情绪分成多个充分展示的镜头，整体信息增量不足。 |
| 第7镜 | 再次握拳3秒、坚定眼神4秒，另有抽烟3秒 | 保留心理转折，用不同的表演变化推进，减少重复握拳。 |
| 第9镜 | 完整走近3秒，再开始要求开火的台词 | 直接从接近的最后一步切入，让停步与开口自然衔接。 |

线上技能已经要求删除无变化的镜头、减少重复反应、压缩非关键过程。此次优化重点是补充具体的创作方法，避免模型把“站位有作用、手部有作用、面部有作用”分别解释成必须独立停留的镜头。

第5镜与第7镜也不能简单视为重复剧情：两者之间有宾客等菜的压力，分别承担“长期忍耐”和“决定干预”。应压缩重复表现，保留情绪转折。

## 三、建议写入技能的具体规则

以下条款建议融入对应章节，并调整原有相近表述，形成统一指令。

### 1. 保留原文动作的语义和结果，允许压缩非关键过程

> 原文明确要求的动作、先后关系、关键变化与结果必须可辨认。动作的准备、执行与收尾不必各自独占镜头，也不必完整展示每一步的现实耗时。
>
> 拿衣、起身、转身等服务于同一行动目标的相邻动作，优先组织为可看清的连续表演。接触、交接、受力、重要道具变化等需要看清因果的过程，应保留必要画面。
>
> 普通进出场可以从动作已经开始的位置切入，在观众明确方向和结果后切走。原文包含犹豫、阻碍、悬念或关系变化时，保留其必要过程。

作用：让模型理解“动作没有遗漏”和“动作全过程全部展开”之间的区别。

### 2. 一个内部镜头围绕一个核心叙事重点，相关动作可同镜发生

> 一个内部镜头围绕一个核心叙事重点组织。服务于同一重点、同一构图可读且自然连续的动作，可以在同镜完成。
>
> 空间交代、情绪表达与动作推进可以由同一画面承担。能够通过人物表演镜头同时看清的位置关系，不默认另设静态站位镜头。
>
> 需要切换观看重点、呈现新的刺激、揭示关键细节、表现关系变化，或保证关键因果可读时，再安排新的内部镜头。

建议调整现有“一个主要动作或信息重点对应一个内部镜头”的表述，避免模型机械地把原文中的每个动词拆成一镜。

### 3. 同一情绪优先合成连续表演，有变化时再拆开

> 同一情绪的站姿、手指收紧、握拳和面部变化，优先整合为一次连续表演，不按身体部位依次充分展示。
>
> 同一人物再次出现相似动作时，优先承接既有状态。新的刺激、情绪方向或行动决定发生变化时，用视线、姿态、呼吸或原文已有的后续行动表现推进；不默认再次安排同样的握拳特写。
>
> 情绪从忍耐到决定行动属于有效变化，应保留其形成过程。压缩重复表现不等于删掉人物动机或心理转折。

作用：让模型从“不断强调她很愤怒”转向“表现她如何从愤怒走向行动”。

### 4. 先规划剧情变化和声音，再划分生成单元

> 先根据原文确定本段发生的动作、信息和情绪变化，估算对白、旁白及内心独白的自然表达时间，再选择构图、动作衔接和切点，最后划分正式分镜。
>
> 不先把一个简单表情或普通位移划为独立分镜，再延长停留满足最低时长。
>
> 内容不足时，优先调整前后同场、时间连续且剧情顺序一致的分镜边界，合并互相关联的内容。明确的时间跳跃、远距离地点变化或不连续事件应单独划分，不能为满足时长强行拼接。
>
> 情绪、动作与声音所需时间不能容纳时，按原文及平台允许的来源边界拆分；不能删词、异常加速或省略关键结果。

建议的规划顺序：

1. 明确这一段原文发生了哪些有效变化。
2. 明确声音所需时间及与动作的先后关系。
3. 将可同时发生的表演组织进同一画面。
4. 在需要切换观看重点的位置安排切点。
5. 组合为满足平台时长的正式分镜。

这些是生成时的创作步骤，不新增对外输出字段或独立调用环节。

### 5. 声音与动作自然并行，停顿具有明确用途

> 对白、旁白和内心独白可与相关动作自然同时发生。人物可以在起身、拿衣或走近时说话，内心独白可以覆盖人物表演及其关注对象。
>
> 独白不必等待站位、手部或面部画面逐项展示完才开始。与当前心理活动有关的画面可以共同承载连续声音。
>
> 原文强调、心理转折、对方反应及关键动作结果需要独立时间时，保留必要停顿。不能为了声画并行而把所有内容挤在同一瞬间。
>
> 连续声音只表达一次。具体声音归属和跨镜安排使用当前线上支持的字段及后端注入方式，不通过重复原句制造延续，也不新增不受支持的协议字段。

说明：本地新版涉及具体声音片段分配的字段变化，不能直接作为本次纯技能优化的前提。建议先采用当前线上协议可表达的创作规则。

### 6. 进出场保留方向与关系，缩短纯位移

> 前镜已经建立人物目标、相对位置及移动方向时，后镜可以从接近目标的最后一步、即将停步或即将离画的位置切入。
>
> 移动结束后，尽快进入原文中的台词、反应或新动作。普通走路不默认完整跟拍。
>
> 需要建立对话轴线、站坐差异、逼近压力或新空间时，用必要的关系构图交代。省略路程必须保证前后空间可理解，不能造成人物瞬移或关键行动缺失。

## 四、模型可模仿的正反示例

示例用于说明创作方法，不是固定镜头模板，也不是已经按成片或配音验证的时长方案。

### 示例一：拿衣起身并离场

原文：王大山拿起衣服站起来，说“不成！俺马上去找她！”，转身冲出家门。

不推荐的安排：拿衣、站起、表态、转身和出门各自完整展开，人物完成一项后再等待进入下一项。

推荐的安排：王大山伸手抓衣，顺势起身，动作中说原台词；随后转身冲向已经交代的出口，在去向明确后切走。保留拿衣、起身、原台词和离场结果，减少动作间等待。

### 示例二：同一情绪的身体与面部表现

原文：王晓梅站在一旁，紧紧握拳。内心独白：“这个主厨立的规矩，我忍了整整六年。”

不推荐的安排：先看她站着，再看握拳，再看隐忍表情，三段画面各充分停留。

推荐的安排：中近景同时交代她的位置、视线和手指收紧，独白自然进入；需要强调时，用一次短暂细节或面部构图变化承接“六年”，随后进入下一项剧情压力。

### 示例三：保留从忍耐到决定行动的变化

原文顺序：长期忍耐 → 宾客等菜、已经超时 → “这一次，我忍不了了”。

不推荐的安排：前后两次都用握拳与愤怒面部近景充分强调，人物状态缺乏可辨认的变化。

推荐的安排：前一段表现克制，宾客等待带来现实压力，后一段通过抬眼、视线转向胡百德或准备干预的姿态，体现决定形成。相关表演必须服务于原文已有的情绪与行动。

### 示例四：走近对手并开口

原文：王晓梅快步走到坐着的胡百德面前，低头直视他，要求先开火。

不推荐的安排：在位置和目标已经清楚时，仍完整跟拍走近，停稳后才开始台词。

推荐的安排：前镜交代她转向胡百德，后镜从逼近的最后一步切入，停步时接原台词；构图交代她站着、胡百德坐着且不抬头，保留对峙关系。

若内部镜头下限不允许将最后一步独立成镜，可将停步、对视和开口合在一个内部镜头中。

## 五、现有时长约束怎样处理

当前线上要求：每条正式分镜10—15秒，每个内部镜头1.5—4秒，至少两个内部镜头，内部时长之和满足正式分镜总时长。

本方案在这一约束内调整内容组合和表演方式。

| 具体情况 | 生成时的处理 |
| --- | --- |
| 单独的隐忍表演自然只需几秒 | 重新考虑同场连续内容的分镜边界，不将一个表情拉长至10秒。 |
| 走近只需一个短动作 | 将最后一步、停步、对视和开口放入同一镜头，不提交低于下限的纯位移镜头。 |
| 声音比动作长 | 让声音覆盖相关画面变化，保留可读的表演，不要求人物重复同一动作。 |
| 必须保留的声音与动作超过单条容量 | 按当前平台支持的原文边界拆分，保证说话顺序和动作状态连续。 |
| 情绪或悬念确实需要停留 | 保留具有叙事作用的时长，不把“紧凑”理解为所有镜头都要快。 |

此前提到第5镜可以试剪至5—6秒，属于成片节奏的参考，不是当前可以直接保存的独立生成分镜方案。

## 六、建议调整技能的位置

| 现有章节 | 建议调整 |
| --- | --- |
| 可信上下文与执行边界 | 明确保留动作语义、关键因果与结果，允许压缩非关键过程。 |
| 分镜与内部镜头 | 按核心叙事重点组织镜头，相关动作可连续完成，空间与表演可以同镜承担。 |
| 情绪与决定 | 补充同义表演合并，以及相似动作在前后段落中的差异化表达。 |
| 进出场、转场与时间跳转 | 补充动作中段切入、最后一步切入、去向明确后切走的方法。 |
| 平台时长与声画关系 | 明确先规划剧情和声音、再划分生成单元，优先自然声画并行。 |
| 示例说明 | 加入上述正反示例，并明确只借鉴方法，不套用人物和剧情。 |

优先调整“分镜与内部镜头”和“平台时长与声画关系”。两部分共同决定模型会不会先把简单动作拆散，再用停留填满时长。
