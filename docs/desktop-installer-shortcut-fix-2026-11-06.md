# ANTV 生图 0.2.6：安装后快捷方式无法启动修复

## 原因与修改

0.2.5 安装后的主程序实际命名为 `ANTV鐢熷浘.exe`，而桌面快捷方式指向 `ANTV生图.exe`。安装载荷为 ZIP，NSIS 使用 `nsisunz::Unzip` 解包时对中文文件名的解码与打包结果不一致。原有 `win-unpacked` 启动检查跳过了解包过程，因此没有覆盖这个故障。

0.2.6 将 Windows 内部程序名固定为 `ANTVImageStudio.exe`，产品和快捷方式继续显示「ANTV生图」。应用包名、应用标识和用户数据目录不变。安装后的卸载程序名称也使用英文内部名。

`packaged-smoke.cjs` 新增 `--installed <安装目录>` 与 `--shortcut <快捷方式>`，检查安装目录的全部打包文件及其 SHA-256、快捷方式目标、ASAR 与编译文件一致性、包版本和应用名称，并从实际安装目录使用临时用户数据启动客户端验证页面与预加载桥接。

## 验证结果

- 修复前：新增安装检查在缺失 `ANTV生图.exe` 处失败，复现用户故障。
- 修复后：0.2.6 安装包实际升级本机，检查安装目录所有打包文件与快捷方式目标通过，已安装程序的隔离启动、项目/创作/队列页面与设置入口通过。
- 随后直接启动桌面「ANTV生图」快捷方式，实际安装程序创建标题为「ANTV生图」的主窗口。
- 升级前记录的设置、工作区、加密状态、登录 Cookie 和本机作品文件共 5 项校验值在安装后全部一致；验证不读取或输出凭证内容。
- 桌面 85 项单元测试、TypeScript 与 Biome 检查通过。仓库 lint 和前端 antd 检查退出码为 0，保留既有前端警告。
- 未调用付费模型。本次只修复 Windows 包装和安装验证，无需更新线上后端。
