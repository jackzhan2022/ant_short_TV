# 场景背景说明示例：苏贞家客厅

此说明用于审阅场景设计，不自动写入线上资产。依据为《儿媳要边界》项目（88）当前第二集正文及场景资产1806；下列美术补充尚不是剧本事实或已确认设定。

## 剧本依据

- 场次为“2-1 日 内 苏贞家客厅”，明确是白天、室内、苏贞家。
- 苏贞穿红色旗袍，周建平穿炭灰色唐装，周承泽穿中式新郎礼服，郑怡穿秀禾服；出场人物还包括大姨和宾客群像。
- “郑怡将喜茶重重磕在桌上”“大喜的日子”等内容支持这是婚礼敬茶的家庭场景。
- 剧情出现放茶、展开红卷、拍桌、起身上前、拉人至身边和面向宾客说话等动作。

正文没有明确房间面积、装修档次、家具全套清单、宾客确切人数、窗户数量与全部家具位置。不能仅凭台词中的“穷亲戚”认定家庭贫困或把空间设计成破旧小屋。

## 场景背景与设计目标

这里是日常使用的家庭客厅，当前因婚礼敬茶而作了临时布置。画面既要体现家中长期使用的功能陈设，也要体现这一天接待亲友、敬茶的具体用途，不能只在空客厅里挂两只红饰物。

桌子需要支持放茶、展开红卷与拍桌，周围需要容纳长辈就座、新人站立及亲友在场的空间。结合可信既有场景设定安排门窗与家具；若既有设计无法容纳剧情动作，应标明空间冲突供审阅，不能靠镜像、瞬移家具或另造房间解决。

## 建议补全的陈设（美术补充）

| 区域 | 具体陈设与摆放建议 | 设计理由与边界 |
| --- | --- | --- |
| 长辈就座与敬茶区 | 沿主墙设置可供长辈就座的沙发或座椅，前方安排稳定的桌面，留出新人站立与递茶的位置 | 对应敬茶、放茶和拍桌动作；桌面高度与距离适合实际使用，不被装饰占满 |
| 亲友接待区 | 依据场地容量补充侧椅或临时座位，靠墙摆放，座位朝向核心交流区 | 对应大姨和宾客在场，不虚构确切人数，不用桌椅堵住过道 |
| 日常起居区 | 在已有布局允许处补全收纳柜或电视柜、普通收纳盒、纸巾、常用杯具等；沙发有适度抱枕和自然织物褶皱 | 表达家庭长期使用；按实际功能取舍，不能把所有物件机械加入或把陈设都登记为剧情道具 |
| 临时婚庆布置 | 在门边、主墙或适合位置安排协调的红色婚庆装饰；空余边柜可承载接待用茶盘、纸巾或少量待客用品 | 属于婚礼氛围的美术补充；数量克制、位置固定，不凭空编造礼金、贺词、姓名或家庭照片 |
| 入口与收纳区 | 如既有场景确有入户门，在不挡门的位置安排合理的玄关收纳和少量日常用品 | 不把普通室内门自动认定为住宅入户门，不新增出口或改变动线 |
| 活动与视线区域 | 桌前及核心人物之间保留连续的站立和行走空间，亲友区域能看到核心交流区 | 对应拉人到身边、起身上前和指向宾客等动作；物品丰富度服从剧情表演空间 |

喜茶、红卷及金镯子具有明确剧情功能，应独立提取并保持连续性。红卷由人物在动作中展开，金镯子由人物佩戴，不能为了填充环境把它们提前铺在桌上或摆进柜中。需要出现桌上喜茶时，依照选定场景状态和原文动作前后确定，不把冲突中的瞬间当作所有镜头的固定陈设。

## 可供审阅的场景描述

苏贞家的室内客厅，白天，正在为家庭婚礼敬茶接待亲友。空间以长辈就座处和前方可实际使用的桌面为核心，桌前保留新人递茶、站立和上前交涉的位置，亲友座位沿侧方组织，朝向核心交流区。既有门窗、家具和通路优先保留；在合理空间内补全日常收纳、普通杯具、纸巾与适度织物软装，并以少量位置固定的婚庆装饰表现当天用途。整体有人日常使用、临时收拾接待的痕迹，陈设有功能、有主次，桌面可用、通路畅通。具体风格、材质和配色沿用可信既有设定；没有依据的部分作为美术补充供确认，不因家庭争执就擅自把装修或布光改成阴暗破败。
