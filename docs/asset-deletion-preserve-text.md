# 删除资产并保留分镜文字

设定页中的角色、场景、道具共用此删除流程。卡片图片右上角的“操作”按钮常显，选择“删除资产”后先读取影响范围，再弹出确认框。确认框显示当前受影响的分镜数量，按钮为“删除并保留文字”；取消或影响读取失败不提交删除。已有图片和视频保持不变。

新增只读接口：`GET /api/projects/{projectId}/script-elements/{elementType}/{elementId}/deletion-impact`，返回资产名、受影响分镜去重数量和提示词引用数量。权限与原删除入口一致。现有 DELETE 路径不变，执行时重新读取关联，不依赖浏览器传入的影响计数。

删除事务锁定资产和当前项目的有效分镜，将提示词中属于该资产的引用节点替换为普通文字，文字取原显示名称；同时退役相关素材关联，再软删除资产。识别资产 ID 和所属形态 ID，包含未出现在素材关联表中的独立提示词引用。其他提示词节点、正文、普通提示词、已有媒体链接与历史执行记录保持不变。失败时整体回滚。

旧页面随后保存或新建分镜时，已删除且无归一目标的资产引用也转为普通文字，避免重新写入失效引用。生成接口、生成确认和计费流程不变。

本次不新增数据库迁移。删除会短暂锁定当前项目的分镜行以保留并发编辑结果，较大项目的删除耗时未做生产压测。历史已删除分镜和历史执行快照不改写。

验证包括：三类资产、独立提示词引用、影响去重、租户/项目隔离、事务失败回滚、旧页面保存、未引用资产，以及前端确认、取消、请求失败和防重复提交。回归使用本地 H2 与模拟接口，不调用付费模型。
