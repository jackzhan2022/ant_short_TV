# AI文本创作工作流二期技术需求文档

## 1. 文档说明

| 项目 | 内容 |
|---|---|
| 文档名称 | AI文本创作工作流二期技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 功能模块 | AI文本创作工作流 |
| 当前版本 | v1.0 |
| 编写日期 | 2026-08-17 |
| 前置依赖 | 一期 AI 服务中台，包含服务商配置、默认文本服务、调用代理、调用日志、RBAC 权限 |
| 本期定位 | 基于 AI 服务中台，建设短剧文本生产链路，支持剧本生成、剧本改写、角色/场景/道具提取、分镜拆解、提示词生成 |
| 参考原型 | huobao-drama 的文本 Agent 工作流，仅参考能力拆分，不接入火宝品牌服务 |

## 2. 需求背景

一期 AI 服务中台解决了模型服务接入、密钥管理、默认服务选择、调用代理和日志追踪问题，但平台仍缺少面向短剧制作业务的 AI 创作能力。用户在短剧项目中仍需要手工完成故事创意扩写、剧本整理、角色梳理、场景拆分、分镜设计和生成提示词编写，整体效率低，且不同创作者输出格式不统一，影响后续图片、视频、配音和成片生产。

二期需要在 AI 服务中台基础上建设短剧文本创作工作流，将通用大模型能力包装为短剧业务可使用的功能模块，使平台具备从创意到结构化分镜的基础生产能力。

| 现状问题 | 说明 |
|---|---|
| 创作链路依赖人工 | 剧本扩写、角色提取、分镜拆解等环节需要人工反复处理 |
| 内容结构不统一 | 剧本、角色、场景、分镜缺少统一字段和输出格式 |
| AI 调用缺少业务上下文 | 仅有通用 Chatbot，无法理解项目、剧集、单集、剧本等业务对象 |
| 后续生产缺少输入 | 图片、视频、语音生成需要角色、场景、镜头、提示词等结构化数据 |
| 结果难以回溯 | AI 生成内容如果不落库，无法对比版本、恢复历史或继续编辑 |

## 3. 建设目标

| 目标 | 说明 |
|---|---|
| 建立文本创作链路 | 支持从创意/原始剧本到结构化分镜的 AI 辅助生产 |
| 沉淀业务数据 | 将剧本、角色、场景、道具、分镜等结果保存为平台业务资产 |
| 复用 AI 服务中台 | 所有 AI 调用通过一期 AI 服务中台完成，不直接调用外部服务商 |
| 支持人工编辑 | AI 生成结果必须允许用户查看、编辑、确认、重新生成 |
| 输出标准格式 | AI 输出需转换为可校验、可保存、可供后续任务使用的结构化数据 |
| 保留生成记录 | 记录每次生成的输入、模型、业务场景、状态和失败原因 |
| 控制本期范围 | 本期只做文本工作流，不做图片、视频、语音和成片合成 |

### 4.1 本期包含

| 模块 | 是否本期 | 说明 |

## 6. 总体流程

### 6.1 用户操作流程

```text

创建短剧项目
  -> 输入故事创意或上传/粘贴原始剧本
    -> AI 生成/改写剧本
      -> 用户编辑并确认剧本
        -> AI 提取角色/场景/道具
          -> 用户编辑并确认元素
            -> AI 拆解分镜
              -> 用户编辑并确认分镜
                -> AI 生成提示词
                  -> 用户编辑并保存提示词

```

### 6.2 系统调用流程

```text

前端业务页面
  -> 后端文本创作接口
    -> 校验登录、租户、项目权限
      -> 获取当前团队默认文本服务
        -> 拼装业务 Prompt
          -> 调用 AI 服务中台文本代理
            -> 解析模型输出
              -> 校验结构化结果
                -> 保存草稿/版本/正式数据
                  -> 返回前端展示

```

## 7. 功能需求

### 7.1 剧本生成

#### 功能说明

用户可基于一句话创意或基础设定生成短剧剧本草稿。生成结果进入草稿状态，用户可编辑后保存为项目剧本。

#### 页面入口

建议入口：

```text

项目详情 / 剧本管理 / AI生成剧本

```

#### 输入字段

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 项目 | 是 | 当前短剧项目，系统自动带入 |
| 剧名 | 否 | 未填写时可由 AI 推荐 |
| 故事创意 | 是 | 一句话创意或剧情梗概 |
| 题材类型 | 是 | 都市、古装、甜宠、逆袭、悬疑、家庭、职场等 |
| 目标集数 | 否 | 如 10 集、20 集、30 集 |
| 单集时长 | 否 | 如 1 分钟、2 分钟、3 分钟 |
| 主角设定 | 否 | 主角身份、目标、困境、关系 |
| 风格要求 | 否 | 爽感、强冲突、轻喜剧、现实向等 |
| 受众偏好 | 否 | 可填写目标用户偏好 |
| 参考内容 | 否 | 可粘贴参考剧情、人物关系、世界观 |

#### 输出内容

| 输出项 | 说明 |
|---|---|
| 剧名建议 | AI 推荐剧名，可编辑 |
| 故事简介 | 100-300 字剧情简介 |
| 核心看点 | 3-5 条短剧卖点 |
| 人物关系 | 核心人物及关系概述 |
| 分集大纲 | 按目标集数输出每集剧情 |
| 剧本正文 | 按场次/对白格式生成正文 |

#### 操作说明

| 操作 | 说明 |
|---|---|
| 生成 | 调用默认文本服务生成剧本草稿 |
| 重新生成 | 保留上一次结果版本，重新生成新版本 |
| 局部改写 | 针对选中文本进行扩写、压缩、润色 |
| 保存草稿 | 保存当前生成结果，不覆盖正式剧本 |
| 确认使用 | 将当前结果保存为项目正式剧本 |

### 7.2 剧本改写

#### 功能说明

用户可对已有剧本进行 AI 改写，包括节奏优化、对白优化、冲突增强、风格转换和集数拆分。

#### 改写类型

| 改写类型 | 说明 |
|---|---|
| 节奏优化 | 压缩铺垫，增强短剧节奏 |
| 冲突增强 | 增加矛盾点、反转点、悬念点 |
| 对白优化 | 优化角色对白，使表达更自然或更有情绪 |
| 风格转换 | 转为甜宠、逆袭、悬疑、轻喜剧等风格 |
| 字数压缩 | 在保留核心剧情前提下压缩篇幅 |
| 内容扩写 | 扩展场景、对白、心理活动 |
| 分集拆分 | 将长剧本拆分为多集结构 |

#### 输入字段

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 原始剧本 | 是 | 当前项目已有剧本文本 |
| 改写类型 | 是 | 从预设类型选择 |
| 改写要求 | 否 | 用户补充的具体要求 |
| 保留内容 | 否 | 指定不可改动的人名、剧情点、台词 |
| 输出长度 | 否 | 保持原长度、压缩、扩写 |

#### 输出内容

| 输出项 | 说明 |
|---|---|
| 改写后剧本 | AI 改写结果 |
| 改写说明 | 简要说明调整了哪些内容 |
| 风险提示 | 如剧情断裂、人物关系不完整等异常提示 |

#### 操作说明

| 操作 | 说明 |
|---|---|
| 生成改写 | 基于当前剧本和要求生成新版本 |
| 对比原文 | 支持查看原文和改写后文本 |
| 应用改写 | 将改写结果应用到当前剧本 |
| 放弃结果 | 不保存当前改写结果 |

### 7.3 角色提取

#### 功能说明

系统从剧本中自动提取角色信息，生成角色库草稿。用户确认后写入项目角色资产。

#### 提取规则

| 规则 | 说明 |
|---|---|
| 提取范围 | 从正式剧本或用户选择的剧本文本中提取 |
| 去重规则 | 同名角色合并；别名需提示用户确认 |
| 主次判断 | 根据出现频率、剧情作用判断主角、配角、群演 |
| 可编辑 | 所有提取字段用户均可编辑 |

#### 输出字段

| 字段 | 说明 |
|---|---|
| 角色名称 | 角色姓名或称呼 |
| 角色类型 | 主角、配角、反派、群演 |
| 性别 | 男、女、未知 |
| 年龄段 | 少年、青年、中年、老年等 |
| 身份职业 | 角色身份、职业、社会关系 |
| 性格特点 | 角色性格关键词 |
| 外貌特征 | 发型、服饰、气质、辨识点 |
| 人物关系 | 与其他角色的关系 |
| 剧情作用 | 在剧情中的功能 |
| 角色提示词 | 用于后续角色图生成的 Prompt |

#### 操作说明

| 操作 | 说明 |
|---|---|
| AI 提取 | 调用文本服务提取角色 |
| 合并角色 | 用户可将重复角色合并 |
| 删除角色 | 删除误提取角色 |
| 编辑角色 | 修改角色字段 |
| 确认入库 | 保存为项目角色资产 |

### 7.4 场景提取

#### 功能说明

系统从剧本中自动提取故事发生场景，生成场景库草稿。用户确认后写入项目场景资产。

#### 输出字段

| 字段 | 说明 |
|---|---|
| 场景名称 | 如“总裁办公室”“女主出租屋”“医院走廊” |
| 场景类型 | 室内、室外、虚拟、交通工具等 |
| 时间氛围 | 白天、夜晚、雨天、黄昏等 |
| 空间描述 | 场景布局、重要陈设 |
| 视觉风格 | 现代、复古、冷色调、暖色调等 |
| 关联剧情 | 该场景出现的剧情说明 |
| 出现场次 | 关联剧本场次或分镜 |
| 场景提示词 | 用于后续场景图生成的 Prompt |

#### 操作说明

| 操作 | 说明 |
|---|---|
| AI 提取 | 从剧本提取场景 |
| 合并场景 | 合并含义相同或相近场景 |
| 删除场景 | 删除误提取场景 |
| 编辑场景 | 修改场景字段 |
| 确认入库 | 保存为项目场景资产 |

### 7.5 道具提取

#### 功能说明

系统从剧本中自动提取关键道具，用于后续画面一致性、镜头设计和素材生产。

#### 输出字段

| 字段 | 说明 |
|---|---|
| 道具名称 | 道具名称 |
| 道具类型 | 线索道具、生活道具、装饰道具、武器、文件等 |
| 外观描述 | 颜色、材质、形状、标识 |
| 剧情作用 | 该道具在剧情中的作用 |
| 关联角色 | 使用或持有该道具的角色 |
| 出现场次 | 关联剧本场次或分镜 |
| 道具提示词 | 用于后续道具图生成的 Prompt |

#### 操作说明

| 操作 | 说明 |
|---|---|
| AI 提取 | 从剧本提取关键道具 |
| 删除道具 | 删除非关键或误提取道具 |
| 编辑道具 | 修改道具字段 |
| 确认入库 | 保存为项目道具资产 |

### 7.6 分镜拆解

#### 功能说明

系统将剧本拆解为镜头级分镜，输出镜头内容、画面描述、角色动作、对白、时长建议和拍摄/生成提示，为后续图片和视频生产提供结构化输入。

#### 拆解范围

| 范围 | 说明 |
|---|---|
| 全剧本拆解 | 对当前项目完整剧本进行拆解 |
| 单集拆解 | 对指定单集剧本进行拆解 |
| 片段拆解 | 对用户选择的剧本文本进行拆解 |

#### 输出字段

| 字段 | 说明 |
|---|---|
| 分镜序号 | 系统生成，按顺序排列 |
| 所属集数 | 如第 1 集 |
| 场次 | 关联剧本场次 |
| 镜头类型 | 远景、全景、中景、近景、特写等 |
| 画面描述 | 当前镜头画面内容 |
| 出场角色 | 当前镜头出现的角色 |
| 角色动作 | 角色行为、表情、走位 |
| 对白/旁白 | 当前镜头对应台词或旁白 |
| 场景 | 当前镜头发生场景 |
| 道具 | 当前镜头涉及道具 |
| 情绪氛围 | 紧张、甜蜜、压抑、反转等 |
| 时长建议 | 单位秒 |
| 图片提示词 | 用于生成分镜首帧图 |
| 视频提示词 | 用于生成分镜视频 |

#### 操作说明

| 操作 | 说明 |
|---|---|
| AI 拆解 | 调用文本服务拆解分镜 |
| 编辑分镜 | 修改镜头字段 |
| 新增分镜 | 手工新增镜头 |
| 删除分镜 | 删除不需要的镜头 |
| 调整顺序 | 支持上移、下移或拖拽排序 |
| 重新拆解 | 基于当前剧本重新生成分镜版本 |
| 确认分镜 | 将当前分镜保存为正式分镜 |

### 7.7 提示词生成

#### 功能说明

系统基于角色、场景、道具和分镜内容生成图片提示词和视频提示词。提示词本期只作为文本资产保存，不发起图片或视频生成。

#### 提示词类型

| 类型 | 说明 |
|---|---|
| 角色提示词 | 用于后续角色定妆图生成 |
| 场景提示词 | 用于后续场景图生成 |
| 道具提示词 | 用于后续道具图生成 |
| 分镜图片提示词 | 用于后续分镜首帧图生成 |
| 分镜视频提示词 | 用于后续镜头视频生成 |

#### 生成规则

| 规则 | 说明 |
|---|---|
| 结构化输入 | 优先使用已确认的角色、场景、道具、分镜字段 |
| 保持一致性 | 同一角色的外貌、服装、气质描述应保持一致 |
| 可编辑 | 所有提示词生成后均可编辑 |
| 不触发生成任务 | 本期不调用图片或视频服务 |

#### 输出字段

| 字段 | 说明 |
|---|---|
| 中文提示词 | 面向运营和创作者可读 |
| 英文提示词 | 面向部分图片/视频模型使用 |
| 负向提示词 | 用于排除低质量画面、畸形、乱码等 |
| 风格标签 | 写实、电影感、竖屏短剧、自然光等 |
| 关联对象 | 角色、场景、道具或分镜 |

| 目标集数 | 正整数 | 请输入正确的目标集数 |
| 单集时长 | 正整数 | 请输入正确的单集时长 |
| 角色名称 | 保存角色时必填 | 请输入角色名称 |
| 场景名称 | 保存场景时必填 | 请输入场景名称 |
| 道具名称 | 保存道具时必填 | 请输入道具名称 |
| 分镜画面描述 | 保存分镜时必填 | 请输入画面描述 |
| 分镜序号 | 同一项目、同一集数下不可重复 | 分镜序号重复 |
| AI 服务 | 当前团队必须存在启用的文本服务 | 当前团队未配置可用文本服务 |
| AI 输出 | 必须能解析为要求格式 | AI 返回内容格式异常，请重试或手动编辑 |

## 14. 异常场景

| 场景 | 处理规则 |
|---|---|
| 未配置文本服务 | 禁用 AI 操作或点击后提示配置文本服务 |
| 文本服务调用失败 | 保留当前页面输入，不覆盖已有数据 |
| AI 返回格式异常 | 展示原始文本预览，允许用户复制或重试 |
| 生成超时 | 提示服务响应超时，生成记录标记失败 |
| 用户取消生成 | 停止前端等待，已产生的结果不自动保存 |
| 重复生成 | 新结果保存为新版本，不覆盖旧版本 |
| 应用版本失败 | 保留当前正式数据并提示失败原因 |
| 提取结果重复 | 前端提示可能重复，允许用户合并或跳过 |
| 分镜拆解为空 | 提示未识别到可拆解内容，建议调整剧本 |

## 16. 验收标准

| 编号 | 验收项 |
|---|---|
| 1 | 用户可在项目详情中基于故事创意生成剧本草稿 |
| 2 | 剧本生成必须通过 AI 服务中台的默认文本服务调用 |
| 3 | 用户可对已有剧本执行 AI 改写并查看改写结果 |
| 4 | AI 生成和改写结果不会自动覆盖正式剧本，必须用户确认 |
| 5 | 用户可从剧本中 AI 提取角色、场景、道具 |

| 7 | 用户可基于剧本执行 AI 分镜拆解 |

| 9 | 用户可编辑、新增、删除、调整分镜顺序 |
| 10 | 用户可为角色、场景、道具、分镜生成提示词 |
| 11 | 本期提示词生成不触发图片或视频生成任务 |
| 12 | 未配置可用文本服务时，所有 AI 文本功能给出明确提示 |
| 13 | 所有 AI 调用均记录调用日志，且不包含 API Key 明文 |
| 14 | 剧本生成和改写形成历史版本 |
| 15 | 无项目权限用户不可访问项目文本创作数据 |
