# AI图片生产增强技术需求文档

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 文档名称 | AI图片生产增强技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 关联前置能力 | AI 服务中台、AI 图片生成任务、角色/场景/分镜基础数据、素材管理 |
| 增强范围 | 批量分镜首帧生成、图片局部重绘、扩图、Prompt 模板、风格一致性控制 |
| 建设目标 | 提升短剧图片资产批量生产效率、可控性和一致性 |
| 不包含 | 视频生成、视频重绘、语音合成、单集合成、外部平台发布 |

## 2. 建设背景与目标

第三期图片生成任务已支持角色图、场景图、分镜首帧图的单次生成，但在实际短剧生产中，单条分镜逐个生成效率较低，且生成结果容易出现角色不一致、场景风格不一致、构图不稳定、局部瑕疵难修复等问题。

因此需要在图片生成能力基础上补充批量生产和精修能力，使平台可以支持从“单张生成”升级为“批量生成、局部修复、画幅扩展、模板复用、风格统一”的图片生产工作流。

| 目标 | 说明 |
| --- | --- |
| 提升批量效率 | 支持按单集、分镜范围批量生成首帧图 |
| 提升修复能力 | 支持对已生成图片进行局部重绘，修复人物、背景、物体等瑕疵 |
| 提升画幅适配 | 支持扩图，将已有图片扩展到目标比例 |
| 提升提示词复用 | 支持 Prompt 模板管理，沉淀角色图、场景图、分镜首帧图生成规则 |
| 提升风格一致性 | 支持项目级风格配置，生成时统一角色、场景、色调、镜头风格 |
| 支撑下游视频 | 为视频生成提供更稳定、更一致的首帧图资产 |

## 6. 批量分镜首帧生成

### 6.1 功能说明

批量分镜首帧生成用于一次性为多个分镜创建图片生成任务，减少用户逐条分镜操作成本。系统根据分镜内容、角色、场景、镜头语言、项目风格和 Prompt 模板，为每条分镜生成对应首帧图。

### 6.2 发起入口

| 入口 | 说明 |
| --- | --- |
| 单集详情页 | 选择【批量生成首帧】 |
| 分镜列表页 | 勾选多个分镜后点击【批量生成首帧】 |
| 图片任务列表 | 新建批量任务，选择项目、单集和分镜范围 |

### 6.3 批量选择规则

| 选择方式 | 说明 |
| --- | --- |
| 全部未生成分镜 | 仅选择当前单集中没有首帧图的分镜 |
| 全部分镜 | 选择当前单集全部有效分镜 |
| 手动勾选 | 用户从分镜列表中选择指定分镜 |
| 按范围选择 | 按分镜序号范围选择，例如 1-20 |
| 排除已锁定分镜 | 已锁定或已确认首帧的分镜默认不覆盖 |

### 6.4 批量任务字段

| image_service_config_id | bigint | 图片服务配置 |

| style_profile_id | bigint | 风格配置 ID |
| total_count | int | 总分镜数量 |
| pending_count | int | 待生成数量 |
| success_count | int | 成功数量 |
| failed_count | int | 失败数量 |
| skipped_count | int | 跳过数量 |
| status | varchar(32) | 任务状态 |
| error_message | text | 失败原因 |
| started_at | datetime | 开始时间 |
| completed_at | datetime | 完成时间 |

| created_at | datetime | 创建时间 |

### 6.5 批量明细字段

建议表名：`ai_image_batch_item`

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| tenant_id | bigint | 所属团队 |
| project_id | bigint | 所属项目 |
| batch_task_id | bigint | 批量任务 ID |
| storyboard_id | bigint | 分镜 ID |
| storyboard_order | int | 分镜顺序 |
| image_task_id | bigint | 关联的单张图片生成任务 ID |
| status | varchar(32) | 待生成、生成中、成功、失败、跳过 |
| error_message | text | 失败原因 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 6.6 状态规则

| 状态 | 说明 |
| --- | --- |
| 待执行 | 批量任务已创建，尚未开始 |
| 执行中 | 正在逐条创建或执行图片生成 |
| 部分成功 | 至少一条成功且至少一条失败或跳过 |
| 全部成功 | 所有明细均生成成功 |
| 全部失败 | 所有明细均生成失败 |
| 已取消 | 用户取消未完成任务 |

### 6.7 执行规则

1. 批量任务创建后，系统按分镜顺序生成明细。
2. 每个分镜明细创建一条独立图片生成任务。
3. 单个明细失败不影响其他明细继续执行。
4. 已有首帧且未选择覆盖时，明细状态为跳过。
5. 批量任务支持整体取消，已完成明细不回滚。
6. 批量任务支持失败明细重试。

## 7. 图片局部重绘

### 7.1 功能说明

图片局部重绘用于对已有图片的指定区域进行重新生成，适用于修复人物手部、脸部、服装、背景物体、文字水印、画面瑕疵等场景。

### 7.2 发起入口

| 入口 | 说明 |
| --- | --- |
| 图片结果详情 | 对生成图片点击【局部重绘】 |
| 素材库图片详情 | 对已有图片素材点击【局部重绘】 |
| 分镜首帧区域 | 对当前首帧点击【局部重绘】 |

### 7.3 输入参数

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| 原图 | 是 | 待重绘图片 |
| 遮罩区域 | 是 | 用户涂抹或框选的重绘区域 |
| 重绘提示词 | 是 | 描述重绘区域需要生成的内容 |
| 负向提示词 | 否 | 描述不希望出现的内容 |
| 参考图 | 否 | 可引用角色图、场景图或其他素材 |
| 重绘强度 | 否 | 弱、中、强 |
| 生成数量 | 是 | 默认 1，最多 4 |
| 图片服务 | 否 | 默认图片服务 |

### 7.4 数据模型

建议表名：`ai_image_inpaint_task`

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| tenant_id | bigint | 所属团队 |
| project_id | bigint | 所属项目 |
| source_image_id | bigint | 原图 ID |
| source_image_url | varchar(1000) | 原图地址 |
| mask_url | varchar(1000) | 遮罩图片地址 |
| prompt | text | 重绘提示词 |
| negative_prompt | text | 负向提示词 |
| strength | varchar(32) | 重绘强度 |
| image_count | int | 生成数量 |
| service_config_id | bigint | 图片服务配置 |
| provider_code | varchar(64) | 服务商 |
| model | varchar(128) | 模型 |
| status | varchar(32) | 任务状态 |
| error_message | text | 失败原因 |
| created_by | bigint | 创建人 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 7.5 操作规则

1. 原图必须为当前团队、当前项目可访问图片。
2. 遮罩区域不能为空。
3. 遮罩区域面积过小时需提示用户重新选择。
4. 重绘结果不直接覆盖原图。
5. 用户确认后可将重绘结果保存为新素材。
6. 若原图是分镜首帧，可将重绘结果设置为新的分镜首帧。
7. 若原图是角色主图或场景主图，可将重绘结果设置为新的主图。

## 8. 图片扩图

### 8.1 功能说明

图片扩图用于将已有图片扩展为指定画幅或尺寸，适用于横竖屏适配、分镜画面补全、角色图转封面图、场景图转视频首帧等场景。

### 8.2 发起入口

| 入口 | 说明 |
| --- | --- |
| 图片结果详情 | 对生成图片点击【扩图】 |
| 素材库图片详情 | 对已有图片素材点击【扩图】 |
| 分镜首帧区域 | 对当前首帧点击【扩图】 |

### 8.3 输入参数

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| 原图 | 是 | 待扩展图片 |
| 目标比例 | 是 | 1:1、3:4、4:3、9:16、16:9 |
| 扩展方向 | 否 | 自动、上下、左右、四周 |
| 扩图提示词 | 否 | 描述扩展区域内容 |
| 负向提示词 | 否 | 描述不希望出现的内容 |
| 生成数量 | 是 | 默认 1，最多 4 |
| 图片服务 | 否 | 默认图片服务 |

### 8.4 数据模型

建议表名：`ai_image_outpaint_task`

| 字段 | 类型建议 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| tenant_id | bigint | 所属团队 |
| project_id | bigint | 所属项目 |
| source_image_id | bigint | 原图 ID |
| source_image_url | varchar(1000) | 原图地址 |
| target_aspect_ratio | varchar(32) | 目标比例 |
| expand_direction | varchar(32) | 扩展方向 |
| prompt | text | 扩图提示词 |
| negative_prompt | text | 负向提示词 |
| image_count | int | 生成数量 |
| service_config_id | bigint | 图片服务配置 |
| provider_code | varchar(64) | 服务商 |
| model | varchar(128) | 模型 |
| status | varchar(32) | 任务状态 |
| error_message | text | 失败原因 |
| created_by | bigint | 创建人 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 8.5 操作规则

1. 原图必须为当前团队、当前项目可访问图片。
2. 目标比例必须与原图比例不同，否则提示无需扩图。
3. 扩图结果不覆盖原图。
4. 扩图后图片需保存到平台可控存储。
5. 用户可将扩图结果保存为素材。
6. 若扩图结果用于分镜首帧，需满足分镜视频生成的比例要求。

## 9. Prompt 模板管理

### 9.1 功能说明

Prompt 模板用于沉淀不同图片生成场景的提示词结构，减少重复编写，提高输出稳定性。模板支持变量占位，系统在生成任务时根据角色、场景、分镜和项目风格自动渲染。

### 9.2 页面入口

```text
项目设置 / Prompt 模板
AI 工具 / Prompt 模板
```

### 9.3 模板类型

| 类型 | 说明 |
| --- | --- |
| 角色图模板 | 用于角色定妆图生成 |
| 场景图模板 | 用于场景图生成 |
| 分镜首帧模板 | 用于分镜首帧生成 |
| 局部重绘模板 | 用于图片局部修复 |
| 扩图模板 | 用于图片扩图 |

### 9.4 模板字段

| template_type | varchar(32) | 模板类型 |
| prompt_content | text | 正向 Prompt 模板 |

| variables | text | 支持变量，JSON 存储 |
| example_output | text | 示例渲染结果 |

### 9.5 支持变量

## 10. 风格一致性控制

### 10.1 功能说明

风格一致性控制用于在项目维度管理统一视觉方向，减少不同分镜、角色、场景之间的风格偏差。生成图片时，系统根据项目风格配置、角色参考图、场景参考图和模板规则自动注入风格约束。

### 10.2 页面入口

```text
项目设置 / 视觉风格
```

| --- | --- |

| 角色参考保持 | 分镜首帧生成时优先引用角色主图作为参考 |
| 场景参考保持 | 分镜首帧生成时优先引用场景主图作为参考 |
| 色调统一 | Prompt 中注入项目色调要求 |
| 画幅统一 | 默认使用项目画幅，短剧竖屏默认 9:16 |
| 模板统一 | 同一类型任务默认使用项目默认 Prompt 模板 |
| 锁定结果 | 已确认的角色图、场景图、首帧图可锁定，批量任务不覆盖 |

### 10.5 操作规则

1. 每个项目可维护多个风格配置。
2. 同一项目只能有一个默认风格。
3. 默认风格会影响新建图片生成任务。
4. 修改默认风格不影响历史任务结果。
5. 批量分镜首帧生成时默认使用当前默认风格。
6. 单张任务可手动选择其他启用风格。
7. 已停用风格不可被新任务选择，历史任务保留原风格信息。

## 13. 任务执行方式

### 13.1 批量首帧执行

```text
用户提交批量任务
  -> 生成批量任务和明细
  -> 按并发限制创建单张首帧任务
  -> 更新每条明细状态
  -> 聚合批量任务进度
  -> 用户查看成功/失败结果
```

### 13.2 局部重绘执行

```text
用户选择原图和遮罩
  -> 创建局部重绘任务
  -> 上传或生成遮罩文件
  -> 调用图片重绘服务
  -> 保存重绘结果
  -> 用户对比并确认使用
```

### 13.3 扩图执行

```text
用户选择原图和目标比例
  -> 系统计算扩展画布
  -> 创建扩图任务
  -> 调用图片扩图服务
  -> 保存扩图结果
  -> 用户对比并确认使用
```

### 13.4 并发控制

| 项目 | 建议 |
| --- | --- |
| 批量首帧并发 | 同一团队默认 2-5 条并发，具体可配置 |

| 失败重试 | 支持用户手动重试，不自动无限重试 |
| 批量取消 | 取消未开始明细，执行中明细以模型返回为准 |

## 20. 验收标准

1. 用户可以在单集详情页发起批量分镜首帧生成。
2. 用户可以按全部未生成、全部分镜、手动勾选、序号范围选择分镜。
3. 批量任务能够展示总数、成功数、失败数、跳过数。
4. 单个分镜生成失败不影响其他分镜继续生成。
5. 批量任务支持取消未完成明细。
6. 批量任务支持重试失败明细。
7. 用户可以对生成图片或素材图片发起局部重绘。
8. 局部重绘必须选择遮罩区域。
9. 局部重绘结果不覆盖原图。
10. 用户可以对生成图片或素材图片发起扩图。
11. 扩图目标比例与原图一致时不可提交。
12. 扩图结果不覆盖原图。
13. 用户可以新增、编辑、复制、启用、停用 Prompt 模板。
14. 同一项目同一模板类型只能有一个默认模板。
15. 用户可以预览 Prompt 模板变量渲染结果。
16. 用户可以新增、编辑、启用、停用项目视觉风格。
17. 同一项目只能有一个默认视觉风格。
18. 新建图片生成任务可自动应用默认模板和默认风格。
19. 批量首帧生成时可引用角色主图和场景主图作为一致性参考。
20. 增强结果可以保存为素材。
21. 增强结果可以回写为角色主图、场景主图或分镜首帧图。
22. 被锁定的图片默认不被批量任务覆盖。
23. 相关任务、模板和风格配置按租户、项目隔离。
24. 无权限用户不能创建增强任务或管理模板、风格。
25. 所有关键操作均写入操作日志。
26. 所有图片模型调用均写入 AI 调用日志。
