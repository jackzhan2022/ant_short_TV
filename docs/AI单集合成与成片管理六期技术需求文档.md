# AI单集合成与成片管理六期技术需求文档

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 文档名称 | AI单集合成与成片管理六期技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 关联前置能力 | AI 服务中台、AI 文本创作工作流、图片生成任务、视频生成任务、语音字幕与单镜头合成、素材管理、分镜基础数据 |
| 本期目标 | 建设单集合成、成片导出和成片管理能力 |
| 服务依赖 | 依赖第五期生成的单镜头视频结果，依赖后端媒体处理能力 |
| 不包含 | 多集批量合成、自动发布到外部平台、复杂剪辑工作台、版权审核、成本统计 |

## 2. 建设目标

第六期目标是在第五期单镜头合成能力基础上，将同一集下的多个分镜镜头按顺序合成为完整单集视频，并支持成片预览、下载、保存、版本管理和导出记录，为短剧制作流程形成从文本到成片的基础闭环。

本期需要实现：

| 目标 | 说明 |
| --- | --- |
| 统一单集合成入口 | 支持在单集详情页、分镜列表页发起整集镜头合成 |
| 统一合成任务管理 | 所有单集合成请求以任务形式记录和追踪 |
| 统一镜头校验 | 合成前校验分镜顺序、镜头视频、视频格式和时长 |
| 统一成片输出 | 输出完整单集视频、封面、时长、文件大小等信息 |
| 统一版本管理 | 同一单集可保留多个历史成片版本，并设置当前版本 |
| 统一导出管理 | 支持成片下载、保存素材、导出记录和失败原因追踪 |

## 4. 业务对象关系

第六期以单集为核心对象，将单集下多个分镜的当前单镜头结果合成为完整成片。

```text
项目
 └─ 剧集
     └─ 单集
         ├─ 分镜 1
         │   └─ 当前单镜头视频
         ├─ 分镜 2
         │   └─ 当前单镜头视频
         ├─ 分镜 N
         │   └─ 当前单镜头视频
         └─ 单集合成任务
             └─ 成片版本
```

### 4.1 业务对象说明

| 对象 | 说明 |
| --- | --- |
| 项目 | 单集合成任务必须归属某个短剧项目 |
| 剧集 | 单集所属剧集，用于成片归档 |
| 单集 | 单集合成的核心业务对象 |
| 分镜 | 单集下的镜头顺序单位 |
| 当前单镜头视频 | 第五期合成结果，是单集合成的输入 |
| 单集合成任务 | 每次单集合成请求对应一条任务记录 |
| 成片版本 | 单集合成成功后生成的完整视频版本 |
| 素材 | 成片可保存为项目视频素材 |

## 5. 技术架构

### 5.1 总体链路

```text
前端页面
  -> 发起单集合成
    -> 后端校验租户 / 项目 / 权限
      -> 查询单集分镜列表
        -> 校验每个分镜当前单镜头视频
          -> 创建单集合成任务
            -> 后端媒体处理拼接视频
              -> 生成成片文件和封面
                -> 写入成片版本
                  -> 更新单集合成任务状态
                    -> 前端轮询查看结果
```

### 5.2 模块划分


| episode validator | 合成前检查分镜完整性、视频可用性、顺序和格式 |
| media compose | 多镜头拼接、输出成片 |

## 7. 状态设计

### 7.1 单集合成任务状态

| 状态 | 说明 |
| --- | --- |
| 待校验 | 任务已创建，等待合成前校验 |
| 校验失败 | 分镜或镜头素材不满足合成要求 |
| 待执行 | 校验通过，等待执行合成 |
| 合成中 | 正在执行单集视频合成 |
| 合成成功 | 已生成有效成片视频 |
| 合成失败 | 合成失败或输出文件无效 |
| 已取消 | 用户取消任务 |

### 7.2 状态流转

```text
创建任务
   ↓
【待校验】
   ├── 校验失败 ->【校验失败】
   └── 校验通过 ->【待执行】
                    ↓
                【合成中】
                    ├── 成功 ->【合成成功】
                    ├── 失败 ->【合成失败】
                    └── 取消 ->【已取消】
```

### 7.3 成片版本状态

| 状态 | 说明 |
| --- | --- |
| 有效 | 成片版本可预览、下载、设置为当前版本 |
| 已删除 | 版本记录已删除，不在默认列表展示 |

### 7.4 状态规则

| 规则 | 说明 |
| --- | --- |
| 重新合成创建新任务 | 不覆盖原任务和原成片版本 |
| 合成成功生成新版本 | 每次成功合成都生成新的成片版本 |
| 当前版本唯一 | 同一单集只能有一个当前成片版本 |
| 删除为逻辑删除 | 删除成片版本不物理删除已归档素材 |
| 当前版本删除需二次确认 | 删除当前成片版本前需提示用户先切换版本或确认影响 |
| 合成失败保留任务 | 保留失败任务和失败原因，支持重新合成 |

## 8. 合成前校验规则

### 8.1 校验内容

| 校验项 | 规则 |
| --- | --- |
| 单集存在性 | 单集必须存在且用户有权限访问 |
| 分镜数量 | 单集下至少存在 1 条有效分镜 |
| 分镜顺序 | 分镜需存在明确排序 |
| 单镜头视频 | 参与合成的每条分镜必须存在当前单镜头视频 |
| 视频可访问 | 每个单镜头视频文件必须可访问 |
| 视频可播放 | 每个单镜头视频必须可读取时长、尺寸和格式 |
| 视频比例 | 默认要求同一集内镜头比例一致 |
| 视频格式 | 本期优先支持 mp4 |
| 视频时长 | 单个镜头时长需大于 0 |

### 8.2 校验结果

| 结果 | 说明 |
| --- | --- |
| 校验通过 | 允许进入合成任务 |
| 校验失败 | 阻止合成，展示失败分镜和原因 |
| 部分缺失 | 明确列出缺少单镜头视频的分镜 |
| 比例不一致 | 阻止合成或提示需统一比例，默认阻止 |

### 8.3 校验失败展示

校验失败时，任务详情需展示失败清单：

| 字段 | 说明 |
| --- | --- |
| 分镜编号 | 失败分镜编号 |
| 分镜名称 / 内容摘要 | 用于定位问题 |
| 失败原因 | 如无单镜头视频、视频不可访问、比例不一致 |
| 处理建议 | 如生成单镜头、重新上传视频、统一比例 |

## 9. 合成配置

### 9.1 通用配置

| 参数 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 单集 | 是 | 当前单集 | 合成任务必须关联单集 |
| 合成范围 | 是 | 全部分镜 | 本期支持全部分镜，可预留选择部分分镜 |
| 镜头顺序 | 是 | 分镜排序 | 按分镜顺序拼接 |
| 输出比例 | 是 | 跟随分镜视频 | 默认要求所有镜头比例一致 |
| 输出分辨率 | 否 | 跟随镜头视频 | 若不一致需转码统一 |
| 输出格式 | 是 | mp4 | 本期优先支持 mp4 |
| 视频质量 | 否 | 标准 | 标准、高清 |
| 是否生成封面 | 否 | 是 | 默认使用第一镜头首帧 |
| 版本名称 | 否 | 自动生成 | 如“第1集 成片 v1” |

### 9.2 拼接规则

1. 按分镜排序从小到大拼接。
2. 本期默认不添加转场。
3. 本期默认不添加片头片尾。
4. 若镜头视频编码不一致，后端需转码为统一格式后再拼接。
5. 若分辨率不一致，默认按输出分辨率缩放并居中裁切或补边，具体策略待确认。
6. 合成完成后生成封面图，默认取成片第一帧。

待确认：分辨率不一致时采用“裁切填满”还是“补边保全画面”。

## 12. 任务执行方式

### 12.1 本期建议

本期采用“创建任务 + 后端异步合成 + 前端轮询”的方式。

```text
用户提交
  -> 创建任务为待校验
  -> 后端执行合成前校验
  -> 校验通过后进入待执行
  -> 后端异步拼接视频
  -> 保存成片和封面
  -> 生成成片版本
  -> 前端轮询任务状态
```

### 12.2 执行要求

| 要求 | 说明 |
| --- | --- |
| 异步执行 | 单集合成耗时较长，不阻塞前端请求 |
| 状态可查询 | 前端通过任务 ID 查询状态 |
| 超时控制 | 单次合成任务需有最大执行时长 |
| 并发控制 | 限制同一团队或同一单集同时合成任务数量 |
| 幂等控制 | 避免重复点击创建多条相同任务 |
| 异常记录 | 所有异常需写入任务失败原因 |
| 日志记录 | 校验、开始、成功、失败均记录日志 |

### 12.3 前端轮询

| 项目 | 建议 |
| --- | --- |
| 轮询间隔 | 5 秒 |
| 轮询结束 | 合成成功、合成失败、校验失败、已取消 |
| 页面关闭 | 不影响任务执行 |
| 重新进入页面 | 可继续查看任务状态 |
| 长时间合成 | 展示“合成耗时较长，请稍后查看”提示 |

## 16. 异常处理

| 异常 | 处理规则 |
| --- | --- |
| 单集不存在 | 阻止创建任务，提示“当前单集不存在” |
| 无权限访问单集 | 阻止创建任务，提示无权限 |
| 单集无分镜 | 阻止合成，提示“当前单集暂无分镜” |
| 分镜缺少单镜头视频 | 校验失败，列出缺失分镜 |
| 单镜头视频不可访问 | 校验失败，列出异常视频 |
| 视频比例不一致 | 默认校验失败，提示统一比例 |
| 视频格式不支持 | 校验失败或转码失败，展示失败原因 |
| 合成任务超时 | 标记合成失败，提示合成超时 |
| 输出视频为空 | 标记合成失败，提示未生成有效成片 |
| 成片不可播放 | 标记结果无效，任务失败或要求重新合成 |
| 保存素材失败 | 不影响成片版本展示，允许用户重试保存 |
| 下载失败 | 记录导出失败，提示稍后重试 |
| 用户重复提交 | 前端按钮 loading，后端做幂等校验 |

## 18. 校验规则

| 字段/操作 | 校验规则 | 错误提示 |
| --- | --- | --- |
| 单集 | 必填且可访问 | 请选择有效单集 |
| 分镜数量 | 至少 1 条有效分镜 | 当前单集暂无可合成分镜 |
| 单镜头视频 | 每条分镜必须存在当前单镜头视频 | 存在分镜缺少单镜头视频 |
| 视频文件 | 必须可访问、可播放 | 存在不可用视频文件 |
| 视频比例 | 默认要求一致 | 分镜视频比例不一致 |
| 输出格式 | 必须为系统支持格式 | 请选择正确的输出格式 |
| 版本名称 | 最多 100 字 | 版本名称不能超过 100 字 |
| 设置当前版本 | 仅有效版本可设置 | 当前版本不可设置 |
| 删除当前版本 | 需二次确认 | 当前版本删除后将影响单集成片展示，是否继续 |
| 取消任务 | 仅待执行、合成中可取消 | 当前任务状态不可取消 |

## 19. 验收标准

1. 用户可以在单集详情页发起单集合成任务。
2. 系统可在合成前校验单集分镜和单镜头视频完整性。
3. 单集无分镜时无法创建合成任务，并展示明确提示。
4. 存在分镜缺少单镜头视频时，校验失败并列出问题分镜。
5. 视频比例不一致时，按本期规则阻止合成并展示原因。
6. 单集合成任务支持待校验、校验失败、待执行、合成中、合成成功、合成失败、已取消状态。
7. 前端可以轮询查看单集合成任务状态。
8. 合成成功后可以在线播放成片视频。
9. 合成成功后生成成片封面。
10. 合成成功后生成新的成片版本。
11. 同一单集可保留多个成片版本。
12. 同一单集只能有一个当前成片版本。
13. 用户可以将历史有效版本设置为当前版本。
14. 用户可以下载成片视频。
15. 用户可以将成片保存到素材库。
16. 用户可以查看成片导出记录。
17. 合成失败时任务详情展示失败原因。
18. 用户可以基于历史任务或当前单集重新合成，新任务不覆盖旧任务。
19. 删除任务记录不删除已保存素材。
20. 已被设置为当前版本的成片删除时需二次确认。
21. 单集合成任务和成片版本按租户、项目隔离。
22. 无权限用户不能创建、取消、删除合成任务或下载成片。
23. 单集合成关键操作均写入操作日志。
