## 执行与验证

1. 读取旧 MinIO 配置和线上 COS 配置，盘点源对象、业务引用及目标对象。
   迁移前 COS 没有与源清单同名的对象。
2. 对线上数据库执行一致性备份，并验证 gzip 完整性；同时保存配置、
   共享文件和迁移前业务引用快照。
3. 按原对象键复制全部 450 个对象。每次读取使用源 ETag 条件，
   COS 写入禁止覆盖；逐对象计算 SHA-256，再从 COS 回读校验。
   原始对象、旧缩略图和未被当前业务引用的旧文件均保留。
4. 对风格和灵感资源建立当前存储规范的原图对象，复用线上版本的媒体登记、
   万象任务协调器及原生回调。视频封面按现有截帧策略生成，再执行 imageSlim。
   未启动 AI 生成、计费或应用调度工作线程。
5. 仅在展示对象 READY 且 COS 元数据校验通过后，按记录 ID 和旧路径条件

   历史灵感的类型值同时规范为当前接口使用的 IMAGE / VIDEO。
6. 最终核对全部复制日志、COS 大小/ETag/SHA-256 元数据、MinIO 源清单、
   225 份展示对象与原图尺寸、业务路径以及处理任务状态。
