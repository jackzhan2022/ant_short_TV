# AI 操作积分预估

所有生产页面的付费提交、失败重试和重新生成先调用只读预估接口，再显示积分确认弹窗。确认前不创建任务、不联系模型、不预占积分；取消或预估失败不提交原请求。

## 接口

`POST /api/tenants/{tenantId}/points/estimate`

```json
{
  "operations": [
    {
      "url": "/api/projects/123/ai-image-tasks",
      "data": {
        "taskType": "CHARACTER",
        "targetType": "VISUAL_VARIANT",
        "targetId": 456,
        "imageCount": 2,
        "aspectRatio": "3:4"
      }
    }
  ]
}
```

该接口仅识别白名单操作，不转发 URL。服务端按租户、项目及原任务权限读取上下文，再使用模型积分价格和商业套餐折扣计算。返回预计总额、分项、可用余额、视频可用余额和余额是否足够。未配置价格时拒绝预估，不回退为零积分。

图片使用实际生图数量、参考图数量及图片参数。视频复用正式任务的参数校验、素材选择、计费用量和维度计算。批量资产图复用正式批次计划，排除已完成、生成中及其它跳过项。批量视频一次展示本批总额。

文本根据当前上下文、Agent/Skill、输出预算及预计调用次数估算；缓存输入按与实际预占相同的最高适用输入费率估算。审核复用范围冻结和分片算法，区分快速、深度审核。分析及资产识别的预估包含可能触发的自动分镜。

文本和视频的最终用量在执行前未知，预估金额不是固定收费承诺或强制费用上限。执行仍按实际调用用量结算并释放未使用的预占；技术重试可能产生额外用量。余额不足时确认按钮禁用，视频不能使用试用积分。

## 已接入入口

- 携带剧本开始创作后的自动分析。
- 剧本重新分析、阶段重试、剧集拆分、本集概要和本集资产重生成。
- 资产提取、图片生成及重生成、批量资产图和失败项重试。
- 单集及批量分镜、首帧、分镜引用资产图、单条及批量视频和失败视频重试。
- 快速/深度剧本审核及审核重试。
- 视频拆剧批次及分集重试。
- 任务中心和共享 AI 执行客户端的付费重试、重生成。

三项原有同步 Agent 入口（剧集拆分、本集概要、本集资产）改为返回 HTTP 202 的共享 AI 执行任务，使用相同积分预占、用量记录、结算和轮询链路。队列执行前检查提交时的剧本版本，阻止覆盖已变更的版本。

上传、浏览、下载、轮询、取消、手工编辑、本地语音占位、字幕和本地镜头/整集合成不弹出扣费确认。

## 验证说明

新增测试覆盖确认前无提交、取消和预估失败拦截、真实 antd 弹窗、批量汇总、试用积分限制、价格缺失及重试冻结价格。接口集成测试检查预估前后任务、预占、流水均未变化。

发布副本验证：277 项前端测试、61 项后端测试通过（含完整 V138 迁移后的接口集成测试）；前端构建、TypeScript、Biome 和 antd 检查通过（保留既有警告）。

初次验证的旧工作区构建目录残留了另一版 V134，导致与 V138 重复添加 `trial_balance`。发布副本从最新远端 master 创建，保留已部署的 V134–V138 正式迁移，使用完整迁移重新验证，不修改线上迁移历史。
