# 桌面端 0.2.3：自动发现火山来源范围

## 修正行为

火山账号登录并进入项目列表后，直接点击「同步全部项目名称」。无需打开团队切换器、选择来源团队或逐个访问项目。

来源范围来自 `DescribeUser.Result.MemDescription.Teams[].TeamID`，每次同步刷新。随后按团队分页读取 `ListProjects`，按项目分页读取 `ListScripts`，再按剧本范围读取角色、场景和道具。保留总数、重复身份、范围一致性及失败不返回部分结果的校验。

原实现错误依赖页面并未使用的 `ListTeams`，且直接 fetch 缺少网页 SDK 的认证处理。本版在来源网页内发现并调用现有 SDK，只允许六个只读接口，不固定易变化的模块编号。

剧本列表只在来源网页内投影身份字段，资产只投影编号、名称及父子关系。取消调试器读取完整响应正文；Cookie、剧本元数据、源站提示词和图片不传入采集器。空白名称变体无法用于名称匹配，排除后显示数量，不编造名称。

剧智创团队用于决定云端保存和匹配归属：只有一个团队时自动选中，多团队仍由用户选择。来源团队不需要手动选择。图片队列继续全局最多 5 个并发。
