## 2. 需求背景

自研短剧制作平台后续需要支持剧本生成、剧本改写、角色提取、场景提取、分镜拆解、提示词生成、图片生成、视频生成、语音合成等 AI 能力。

如果各业务模块直接调用外部 AI 服务，会带来以下问题：

| 问题 | 说明 |
|---|---|
| 配置分散 | 不同模块各自维护 API Key、模型、接口地址，后续难以管理 |
| 安全风险 | 前端或业务模块可能直接暴露密钥 |
| 切换成本高 | 更换服务商或模型时，需要修改多个业务模块 |
| 调用不可追踪 | 无法统一记录谁调用了什么模型、是否成功、失败原因 |
| 权限不可控 | 无法按团队、角色、权限控制 AI 服务使用范围 |
| 后续扩展困难 | 图片、视频、语音等异步生成任务需要统一任务与日志体系支撑 |

因此需要先建设 AI 服务中台，作为短剧制作平台的 AI 能力底座。

## 3. 建设目标

| 目标 | 说明 |
|---|---|
| 统一服务商管理 | 预置 OpenAI、Gemini、火山、MiniMax 四类服务商 |
| 统一服务配置 | 支持按团队配置文本、图片、视频、语音等 AI 服务 |
| 统一调用入口 | 前端和业务模块不直接调用外部 AI 服务，统一通过后端代理 |
| 统一默认策略 | 支持同一服务类型设置默认服务和优先级 |
| 统一安全管理 | API Key 后端加密存储，前端脱敏展示 |
| 统一测试能力 | 支持服务连通性测试，验证接口、Key、模型是否可用 |
| 统一日志追踪 | 记录 AI 调用日志，便于排查问题和后续成本统计 |
| 支撑短剧链路 | 为后续剧本、分镜、图片、视频、语音等 AI 功能提供基础能力 |

## 5. 名称解释

| 名称 | 说明 |
|---|---|
| AI服务中台 | 平台统一管理 AI 服务商、模型配置、调用代理、测试和日志的基础模块 |
| AI服务商 | 提供 AI 能力的厂商或平台，例如 OpenAI、Gemini、火山、MiniMax |
| 服务类型 | AI 能力分类，包括文本、图片、视频、语音 |
| AI服务配置 | 团队维度下具体可调用的 AI 服务配置，包含服务商、模型、接口地址、API Key 等 |
| 默认服务 | 某一团队、某一服务类型下默认使用的服务配置 |
| 优先级 | 当没有默认服务或需要候选服务时，用于决定服务选择顺序 |
| 连通性测试 | 验证当前服务配置是否可访问、鉴权是否通过、模型是否可用 |
| AI调用代理 | 后端统一接收业务调用请求，再转发至对应 AI 服务商 |
| AI调用日志 | 记录每次 AI 调用的上下文、模型、状态、耗时和失败原因 |
| 脱敏展示 | API Key 等敏感信息仅展示部分字符，避免明文泄露 |

当前系统已有以下基础能力：

| 能力 | 当前情况 | AI服务中台接入方式 |
|---|---|---|

| 前端请求 | 已统一携带 Token 和租户 ID | AI 服务页面复用现有 request |
| Chatbot 页面 | 当前前端直连外部模型地址 | 改为调用后端 AI 代理接口 |

## 7. 总体架构设计

### 7.1 架构原则

| 原则 | 说明 |
|---|---|
| 后端代理 | 所有 AI 调用必须经过后端，前端不得直接访问外部 AI 服务 |
| 租户隔离 | 不同团队的 AI 服务配置、Key、调用日志互相隔离 |
| 配置驱动 | 业务模块通过服务类型调用，不直接绑定具体服务商 |
| 可扩展 | 后续可扩展更多服务商、模型类型和异步任务 |
| 安全优先 | API Key 加密存储，接口返回不包含明文 Key |
| 可追踪 | 每次调用必须记录日志，便于排查与审计 |

### 7.2 调用链路

```text
前端业务页面
  -> 后端 AI 调用接口
    -> 校验登录态
      -> 解析当前团队
        -> 校验权限
          -> 查询 AI 服务配置
            -> 选择默认服务或优先级最高服务
              -> 调用外部 AI 服务商
                -> 记录调用日志
                  -> 返回调用结果
```

## 8. 功能需求

### 8.1 AI服务商预置

#### 功能说明

系统预置 OpenAI、Gemini、火山、MiniMax 四类 AI 服务商。服务商预置用于降低配置成本，用户新增服务配置时可以选择预置服务商，并自动带出服务商能力说明、推荐接口地址和支持服务类型。

#### 预置服务商

| 服务商 | 支持服务类型 | 说明 |
|---|---|---|
| OpenAI | 文本、图片、语音 | 支持 OpenAI 官方接口及 OpenAI Compatible 接口 |
| Gemini | 文本、图片、多模态 | 支持 Gemini 系列模型 |
| 火山 | 文本、图片、视频、语音 | 支持豆包、火山引擎相关模型能力 |
| MiniMax | 文本、语音、视频 | 支持文本生成、语音合成及后续视频能力 |

#### 字段说明

| 字段 | 说明 |
|---|---|
| 服务商名称 | 系统展示名称 |
| 服务商标识 | 系统内部唯一标识 |
| 支持服务类型 | 文本、图片、视频、语音，可多选 |
| 默认接口地址 | 新增配置时自动带出的默认 Base URL |
| 推荐模型 | 新增配置时可选择的推荐模型 |
| 服务商说明 | 展示服务商能力和配置说明 |
| 启用状态 | 控制该服务商是否可被选择 |

#### 操作说明

| 操作 | 说明 |
|---|---|
| 查看 | 管理员可查看预置服务商列表 |
| 启用 | 启用后，新增服务配置时可选择该服务商 |
| 停用 | 停用后，不影响历史配置，但不能新增该服务商配置 |
| 编辑说明 | 可维护服务商说明、默认地址、推荐模型等非敏感信息 |

### 8.2 AI服务配置管理

#### 功能说明

AI 服务配置是团队维度下可实际调用的模型服务。每个团队可以维护多条服务配置，用于不同服务类型和业务场景。

#### 页面入口

建议入口：

```text
团队管理 / AI服务
```

#### 列表字段

| 字段 | 说明 |
|---|---|
| 服务名称 | 用户自定义名称，如“OpenAI 文本默认服务” |
| 服务类型 | 文本、图片、视频、语音 |
| 服务商 | OpenAI、Gemini、火山、MiniMax |
| 模型 | 当前服务配置的模型名称 |
| 接口地址 | Base URL，列表中可展示域名或脱敏路径 |
| 是否默认 | 标识是否为当前服务类型默认服务 |
| 优先级 | 数值越大优先级越高 |
| 启用状态 | 启用、停用 |
| 最近测试状态 | 未测试、测试成功、测试失败 |
| 最近测试时间 | 最近一次连通性测试时间 |
| 更新时间 | 服务配置最近更新时间 |
| 操作 | 编辑、测试、设为默认、启用/停用、删除 |

#### 新增配置字段

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 服务名称 | 是 | 1-50 个字符，同一团队内建议唯一 |
| 服务类型 | 是 | 文本、图片、视频、语音 |
| 服务商 | 是 | 从启用中的预置服务商选择 |
| 接口地址 | 是 | Base URL |
| API Key | 是 | 保存后加密存储，不明文回显 |
| 模型 | 是 | 可选择推荐模型，也可手动输入 |
| 调用端点 | 否 | 特殊服务商需要时填写 |
| 查询端点 | 否 | 视频、图片异步任务查询时使用，本期可预留 |
| 优先级 | 是 | 默认 100，数值越大优先级越高 |
| 是否默认 | 否 | 默认否 |
| 启用状态 | 是 | 默认启用 |
| 备注 | 否 | 0-200 字符 |

#### 编辑配置规则

| 场景 | 规则 |
|---|---|
| 编辑基础信息 | 服务名称、接口地址、模型、端点、优先级、备注可编辑 |
| 编辑 API Key | 默认不回显明文；用户可点击“修改密钥”重新输入 |
| 不修改 API Key | 保存时沿用原加密密钥 |
| 修改服务类型 | 不建议允许修改；如需修改，应提示可能影响默认服务 |
| 修改服务商 | 不建议允许修改；如需修改，应重新测试连通性 |
| 编辑后状态 | 编辑接口地址、模型、Key 后，最近测试状态重置为未测试 |

### 8.3 默认服务与优先级

#### 功能说明

同一团队、同一服务类型下，只允许存在一个默认服务。业务模块未指定具体服务配置时，系统优先使用默认服务。

#### 选择规则

| 场景 | 规则 |
|---|---|
| 存在默认服务且已启用 | 使用默认服务 |
| 存在默认服务但已停用 | 不允许作为调用服务，提示无可用默认服务 |
| 无默认服务 | 使用同类型启用状态下优先级最高的服务 |
| 多个服务优先级相同 | 使用最近更新的一条，或按创建时间倒序选择 |
| 无启用服务 | 返回明确错误提示 |

#### 设为默认规则

| 规则 | 说明 |
|---|---|
| 同类型唯一 | 同一团队、同一服务类型只能有一个默认服务 |
| 自动取消旧默认 | 新服务设为默认后，旧默认服务自动取消默认 |
| 停用默认服务 | 停用前提示用户；停用后该服务不可被调用 |
| 删除默认服务 | 删除前提示用户；删除后该服务类型可能无默认服务 |

### 8.4 服务启用与停用

#### 功能说明

服务配置支持启用和停用。停用后，业务调用不再选择该服务。

#### 规则说明

| 操作 | 规则 |
|---|---|
| 启用服务 | 启用后可参与默认服务和优先级选择 |
| 停用服务 | 停用后不可被业务调用 |
| 停用默认服务 | 需要二次确认，提示可能影响业务调用 |
| 停用后恢复 | 恢复启用后，保留原默认标识和优先级 |
| 停用唯一服务 | 允许停用，但需提示该服务类型将无可用服务 |

### 8.5 连通性测试

#### 功能说明

管理员可对单个 AI 服务配置发起连通性测试，用于验证接口地址、API Key、模型和服务商调用方式是否可用。

#### 测试入口

| 入口 | 说明 |
|---|---|
| 列表操作 | 点击“测试”按钮 |
| 新增/编辑页 | 保存前或保存后可测试 |
| 详情抽屉 | 查看最近测试结果并重新测试 |

#### 测试状态

| 状态 | 说明 |
|---|---|
| 未测试 | 新增或关键配置变更后默认状态 |
| 测试中 | 正在发起测试请求 |
| 测试成功 | 服务可访问，鉴权通过，模型可调用 |
| 测试失败 | 服务不可用，需展示失败原因 |

#### 失败原因

| 失败类型 | 提示说明 |
|---|---|
| 接口不可达 | 接口地址无法访问或网络异常 |
| 鉴权失败 | API Key 无效或权限不足 |
| 模型不存在 | 配置的模型名称不可用 |
| 请求超时 | 服务商响应超时 |
| 返回格式异常 | 服务商返回数据无法解析 |
| 服务商不支持 | 当前服务商不支持该服务类型 |

#### 本期测试范围

本期优先支持文本服务连通性测试。图片、视频、语音服务可保存配置，但测试能力可按服务商能力逐步补齐。

### 8.6 AI调用代理

#### 功能说明

AI 调用代理是后端统一对外提供的 AI 调用入口。前端和业务模块只调用平台后端，不直接调用 OpenAI、Gemini、火山、MiniMax。

#### 本期调用场景

本期优先支持现有 chatbot 页面改造：

```text
chatbot 页面
  -> 后端 AI Chat 接口
    -> 当前团队默认文本服务
      -> 外部 AI 服务商
```

#### 请求处理规则

| 步骤 | 说明 |
|---|---|
| 登录校验 | 未登录用户不可调用 |
| 租户校验 | 必须携带当前团队 ID |
| 权限校验 | 用户需具备 AI 服务使用权限 |
| 服务选择 | 优先使用当前团队默认文本服务 |
| 参数校验 | 校验消息内容、模型参数、上下文长度等 |
| 服务调用 | 根据服务商适配调用协议 |
| 日志记录 | 成功和失败均记录 AI 调用日志 |
| 结果返回 | 返回统一格式给前端 |

#### 响应方式

| 类型 | 本期建议 |
|---|---|
| 普通响应 | 支持 |
| 流式响应 | 建议支持，用于 chatbot 打字机效果 |
| 异步任务 | 本期不做，后续用于图片/视频/语音 |

### 8.7 AI调用日志

#### 功能说明

每次 AI 调用都应记录日志，用于问题排查、审计和后续成本统计。

#### 字段说明

| 字段 | 说明 |
|---|---|
| 所属团队 | 当前租户 |
| 调用人 | 当前登录用户 |
| 业务场景 | chatbot、剧本生成、分镜拆解等 |
| 服务类型 | 文本、图片、视频、语音 |
| 服务商 | OpenAI、Gemini、火山、MiniMax |
| 服务名称 | 实际使用的服务配置名称 |
| 模型 | 实际调用模型 |
| 请求摘要 | 输入内容摘要，避免保存过长敏感内容 |
| 调用状态 | 成功、失败 |
| 失败原因 | 失败时记录错误信息 |
| 耗时 | 请求开始到结束的耗时 |
| 创建时间 | 调用发起时间 |

#### 日志保留规则

| 规则 | 说明 |
|---|---|
| 成功调用 | 记录服务、模型、耗时、结果摘要 |
| 失败调用 | 记录服务、模型、错误码、失败原因 |
| 敏感内容 | API Key 不得写入日志 |
| 请求内容 | 可记录摘要，不建议完整保存用户输入 |
| 返回内容 | 可记录摘要，不建议完整保存生成结果 |

### 8.9 安全要求

| 安全项 | 要求 |
|---|---|
| API Key 存储 | 后端加密存储，不允许明文入库 |
| API Key 展示 | 前端只展示脱敏值，例如 `sk-****abcd` |
| API Key 编辑 | 不回显明文，只允许重新输入覆盖 |
| API Key 日志 | 操作日志、调用日志、异常日志均不得记录明文 |
| 前端调用 | 前端不得直接访问外部 AI 服务商接口 |
| 权限控制 | 所有管理接口必须校验 RBAC 权限 |
| 租户隔离 | 服务配置和调用日志必须按团队隔离 |
| 删除保护 | 删除默认服务需二次确认 |
| 异常提示 | 不向前端暴露服务商完整错误堆栈 |

## 12. 校验规则汇总

| 字段/操作 | 校验规则 | 错误提示 |
|---|---|---|
| 服务名称 | 必填，1-50 字符 | 请输入服务名称 |
| 服务类型 | 必填 | 请选择服务类型 |
| 服务商 | 必填，必须为启用服务商 | 请选择可用服务商 |
| 接口地址 | 必填，必须为合法 URL | 请输入正确的接口地址 |
| API Key | 新增必填，编辑可不填 | 请输入 API Key |
| 模型 | 必填 | 请输入或选择模型 |
| 优先级 | 必填，整数 | 请输入正确的优先级 |
| 设为默认 | 同类型只能一个默认 | 当前服务类型已有默认服务，将自动替换 |
| 删除服务 | 默认服务删除需二次确认 | 删除后可能影响业务调用，是否继续 |
| 停用服务 | 默认服务停用需二次确认 | 停用后该服务不可被业务调用 |
| 测试服务 | 必须配置完整后才可测试 | 请先完善服务配置 |
| AI 调用 | 当前团队必须存在可用服务 | 当前团队未配置可用 AI 服务 |

## 13. 异常场景

| 场景 | 处理规则 |
|---|---|
| 当前团队无 AI 服务配置 | 调用时提示“当前团队未配置可用 AI 服务” |
| 默认服务被停用 | 调用时不使用该服务，按规则选择其他启用服务 |
| 无可用启用服务 | 返回明确业务错误 |
| API Key 失效 | 调用失败，记录日志，提示鉴权失败 |
| 模型不存在 | 调用失败，记录日志，提示模型不可用 |
| 接口超时 | 调用失败，记录日志，提示服务响应超时 |
| 服务商返回异常 | 统一包装为平台错误，不暴露原始堆栈 |
| 流式调用中断 | 前端提示生成中断，后端记录失败或中断状态 |
| 删除服务配置 | 已有调用日志保留，不删除历史日志 |
