# 视频自动虚拟化统一任务展示

用户可见流程：生成中 → 智能虚拟化中 → 生成中 → 已完成。

- 保留原任务编号和创建时间，任务中心列表与统计不重复展示自动恢复子任务。
- 自动准备素材期间隐藏首次真人图片拦截错误，分镜预览持续显示处理阶段；最终无法恢复时才显示失败。
- 原任务详情、媒体摘要和结果分页读取关联任务产出，状态筛选采用逻辑任务的有效状态。
- 虚拟化处理中隐藏取消操作；重新生成开始后，从原入口取消会转发至关联任务。
- 对已结束的关联任务手动再生成会创建新的正常请求，仍在运行的关联任务继续复用。
- 保留底层执行、审计和独立积分结算记录。本次不新增数据库迁移，使用既有 V164 结构。
