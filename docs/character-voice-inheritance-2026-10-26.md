# 分镜角色音色展示与继承

角色卡片显示当前生效的音色名称、来源项目与配置范围。

- 未单独配置的形态继承角色默认音色，标记“角色默认音色”。
- 当前分镜某形态有覆盖时，优先显示覆盖音色，标记“当前分镜形态覆盖”。
- 未配置显示“未配置音色”；读取中和失败分别显示状态。
- 保留“配置音色”入口，复用现有音频库/上传选择弹窗，不另建音色ID配置体系。
- 保存、恢复默认、切换角色/形态、引用自动保存成功后刷新显示，并取消过期请求。

整合使用主干现有 `character_voice_reference` 与 `storyboard_character_voice` 数据及接口，角色默认绑定与分镜形态覆盖的持久化保持原有流程。视频生成继续使用既有角色参考音频拼接逻辑；跳过缺图后仍保留有效角色音频。

验证覆盖角色默认、分镜覆盖、形态/分镜切换、保存与恢复、过期请求、加载失败，以及弹窗和既有保存行为兼容。整合验证结果见 `session-workbench-master-integration-2026-10-26.md`。
