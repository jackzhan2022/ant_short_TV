## 使用方式

刷新后进入“模型管理 → 团队 Skill”。当前有效团队的所有者或 ADMIN 可自定义“短剧整集分镜规划”和“Seedance 视频提示词表达”，并可恢复系统默认；基础规范和素材引用只读。系统管理页增加 Agent 下拉、系统内置/租户级筛选及所属租户列；租户版本在系统页仅供查看。

同一 Skill 优先采用本团队版本，没有覆盖时使用系统文件。覆盖只对分镜 Agent 生效，不影响其他团队或其他 Agent。Markdown 编辑保留修订冲突检测；分镜保存结构、素材标签、未绑定占位和引用编译协议保持原有实现。
