# 会话工作台变更整合记录

## 功能范围

1. 缺图仅跳过不可用图片，保留其余有效图片和音频参考，提示词引用重新编号，原绑定保留。
2. 视频完成后从成片截帧，保存封面原图和展示版本，主预览与历史版本共用对应封面，封面收入项目图片资产库。
3. 角色、场景、道具卡片支持点击查看原图，悬浮操作层不阻挡图片点击。
4. 角色卡片显示默认或当前分镜形态覆盖音色，并在保存、恢复、切换及刷新时更新。
5. 分镜视频时长、分辨率、生成音频、水印自动保存，显示保存状态与重试，生成前等待最新参数保存。

## 主干兼容

以 `cf34576` 的 master 为整合基线，保留现有角色音频绑定、菜单权限、场景道具处理和虚拟形象功能。

音色显示复用主干现有音频库与角色/分镜绑定，不引入旧开发分支的重复音色配置表。视频参数新增迁移编号为 `V159__storyboard_video_generation_settings.sql`，避开主干既有 V157/V158 虚拟形象迁移。

自动封面具有普通删除引用保护，强制删除会清理相关封面地址。视频参数字段不参与通用实体更新，避免视频绑定等操作使用旧实体覆盖新设置。同项目分镜的保存队列跨页面生命周期保持顺序并接续待完成的编辑。
