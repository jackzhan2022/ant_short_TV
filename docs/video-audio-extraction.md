# 视频音色提取

采用用户选定的A版轻量弹窗，接入最新前端基线 `f7b3c6cf`。入口位于分镜当前视频的工具栏，以及资产库的视频预览弹窗。只有具备项目编辑权限的用户可操作，后端继续校验源视频读取、音频上传及保存权限。

## 使用流程

1. 打开“提取音色”，查看真实的项目名、来源视频及目标项目音频库。
2. 音轨读取完成后，在真实波形上拖动两端、拖动选中区域、使用键盘或输入时间选择对白。
3. 预览原视频时只播放选段，结束处暂停；点击“提取并试听”生成WAV，使用独立试听区检查结果。
4. 输入名称并保存。结果进入当前项目音频库，可继续在角色默认音色或分镜音色配置中选用。成功后可直接打开对应项目的音频页。

固定标题、来源摘要与底部操作，正文在较小屏幕中独立滚动。试听区始终保留位置，加载、报错和保存成功在原位反馈。原视频和结果音频互斥播放。改变选段会清除旧的试听和待保存会话，防止误存其他片段。

## 处理边界

- 提取选段原声，背景音乐和其他说话人的声音也会保留；不执行人声分离或音色模型训练。
- 使用浏览器Web Audio解码。部分视频音轨编码可能不受浏览器支持，无音轨或无法解码时明确报错，可重试读取。
- 只在用户打开弹窗后读取视频；输入最多100MB，音轨最多120秒，读取超时45秒。单次选段最多30秒，输出单声道16-bit PCM WAV，最大10MB。
- 波形按真实声道采样归一化，最多160个区间；不会用装饰数据冒充波形。
- 保存复用已有媒体上传与项目音频注册接口；注册失败复用已完成上传，上传失败复用原句柄重试。
- 用于视频生成时，继续遵守所选模型的参考音频数量、单条时长及总时长限制。
- 关闭、项目或视频切换、团队切换时中止读取和上传，撤销对象URL、清理播放器，忽略过期响应。

本次为前端能力，无新模型服务、后端依赖或数据库迁移。2026-11-12 已部署线上，发布结果见 [发布记录](video-audio-extraction-release-2026-11-12.md)。

## 验证

定向测试覆盖真实采样的WAV头和音频范围、波形归一化、多声道与静音、时间格式、权限门控、键盘选段、数值校验、原视频选段播放、解码失败重试、正确项目保存、注册/上传重试、重复提交防护、团队切换与媒体资源释放。

2026-11-12：8个相关测试文件共228项通过。包含分镜工作台、角色音色弹窗、角色引用、资产库、视频工具栏及本次提取组件。Biome、TypeScript和Ant Design检查通过，正式前端生产构建及本地正式组件预览构建通过，保留仓库既有的非阻断提示。

本地预览已改用正式A版组件，示例素材与本地保存适配仅位于忽略目录。当前工具设置禁止浏览器自动化；不把源码检查、单元测试或预览HTTP可访问性记为真实浏览器视觉验收。
