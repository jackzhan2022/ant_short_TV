# 角色形态相似度检查与重复形态处理

角色设置入口统一为“角色形态相似度检查”。保留跨角色外貌检查，增加同一角色下服装与造型的语义重复检查；形态名称、外观描述、提示词共同参与，尚未生成图片也可检查。

“墨蓝色工装外套”和“墨蓝工装外套”等颜色后缀、空白或标点差异会被识别为疑似重复。明确的服装颜色、款式、配饰、年龄阶段及湿透、破损状态差异仍应保留。

## 处理操作

- 合并形态：预览双方现有图片、完整提示词、出镜集数并集、涉及分镜和音色冲突；选择保留项并明确确认。涉及默认形态时必须保留默认形态。
- 合并保留目标已有图片和提示词；去重迁移有效集数绑定、可编辑分镜引用及音色设置后，软删除来源形态。双方已有同一分镜音色设置时保留目标设置。
- 已生成媒体和已提交任务快照保留历史。旧编辑页保存已合并形态引用时定向回保留项。
- 保留为不同形态：保留双方资产并持久记录决定；描述未变化的后续报告继续显示已处理，内容变化后重新判断。
- 每组独立校验。处理一组后，其他内容未变化的组可继续处理。查看原形态与修改权限分别控制。
- 处理要求项目编辑权限，校验租户、项目、角色、剧本版本和原报告归属。合并确认复核最新图片和影响范围，生成中或内容已变化时阻止提交；重复请求幂等，失败整体回滚。

## 迁移与兼容

新增 `V165__character_variant_similarity_resolution.sql`，仅创建处理记录表，保留历史迁移文件与校验值。检查路由和AI任务类型沿用原标识，费用预估和任务名称更新为角色形态相似度检查。合并和保留判断不调用模型。

## 验证范围

后端覆盖语义重复、跨角色隔离、缺图形态、历史报告、权限与版本校验、集数重叠去重、默认形态保护、音色冲突、分镜迁移、旧编辑页保存、幂等及事务回滚。前端覆盖取消零写入、保留项选择、确认单次提交、重试、已处理状态、独立组继续处理及原外貌修改稿。
