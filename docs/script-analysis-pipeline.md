# 剧本四阶段智能分析流水线

## 触发边界

- 仅项目首次创建且请求包含非空 `initialScriptContent` 时自动创建一次分析任务。
- 普通剧本保存不会自动重新分析。
- 后续手动重新分析走显式 API，不和首次创建自动分析混用。

## 四阶段

1. 剧情全局理解
2. 智能分集拆分
3. 分集概要提炼
4. 角色、场景、道具识别

每个阶段独立返回 `status`、`progressPercent`、`completedUnits`、`totalUnits`、`currentAction`、错误信息和结果元数据。

## 进度语义

- 百分比表示服务端阶段进度，不表示模型供应商内部 token 或推理进度。
- 模型推理期间只能显示单调递增的阶段估算和当前动作提示。
- 阶段只有在结构化结果通过校验并完成持久化后才能变为 `100%`。
- 总进度按四个阶段等权计算；失败阶段保留失败时的进度。

## 分集输入规则

- 有明确标题时优先使用规则解析，例如 `第1集`、`第十二集`、`EP03`。
- 没有可靠标题或规则结果不足时，进入 AI 智能分集。
- AI 分集结果必须满足集号从 1 连续递增、正文非空、边界不重复，并覆盖原剧本开头内容。
- 智能分集结果只作为分析结果和工作区派生展示，不修改用户原始剧本文本。

## 重试

- 重试从指定失败阶段开始。
- 目标阶段和后续阶段重置为 `PENDING`。
- 目标阶段之前已成功的结果保持不变。
- 如果剧本当前版本已经变化，旧版本任务不得覆盖新版本工作区结果。

## 模型与调用日志

- 四阶段均使用项目范围内解析到的 TEXT 模型配置。
- 每次 AI 调用记录业务场景、AI 调用日志 ID、供应商请求 ID、耗时和状态。
- 原始响应会做长度裁剪后保存，便于排查结构化解析失败。
- 不保存 API Key 或授权头。

## 故障处理

- 分析调度失败不阻塞项目创建，项目创建仍返回成功，并记录项目日志。
- 阶段失败时返回 `errorCode`、`errorMessage` 和 `retryable`。
- 前端只在存在未完成的首次分析任务时轮询；完成后再次进入页面不重启自动分析。
