# 剧本审核 Markdown 报告运行说明

QUICK 和 DEEP 固定使用当前审核 Agent，无路由或格式开关。启动时幂等初始化默认定义；缺少启用的工具调用模型时显示配置诊断。

- QUICK 读取可信上下文和冻结正文后直接返回 Markdown，由服务端保存。
- DEEP 按冻结维度及正文单元生成 Markdown 片段；成功单元可复用，失败单元可重试，聚合只使用本快照片段且不允许工具。
- 非空且未截断的 Markdown 才能成功；空白、截断或读取契约不完整均失败。
- 缓存观测、Run 与模型调用日志、积分结算是正常能力，不受切流开关控制。
- 复制和下载只输出 UTF-8 Markdown，旧结构化问题、候选和语义阶段已退役。

部署时按 remove-legacy-ai-workflow-paths 的数据清理清单先停止旧 worker、备份并执行迁移，再协调启动新版本。迁移删除旧结构，恢复旧二进制必须连同迁移前数据库和 Skill 快照一起恢复，不能只切换应用版本。

验证 QUICK、长剧本 DEEP、失败单元重试、仅聚合重试、取消竞争、积分结算、报告查看和下载。不要使用旧结构化任务作为当前流程验收样本。
