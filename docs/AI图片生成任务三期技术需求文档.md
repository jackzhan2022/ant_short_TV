# AI图片生成任务三期技术需求文档

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 文档名称 | AI图片生成任务三期技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 关联前置能力 | AI 服务中台、项目管理、素材管理、角色/场景/分镜基础数据 |
| 本期目标 | 建设图片生成任务能力，支持角色图、场景图、分镜首帧图生成 |
| 服务依赖 | 使用平台已配置的图片类 AI 服务 |
| 不包含 | 视频生成、语音合成、图片编辑、批量自动生成、成本统计 |

## 2. 建设目标

第三期目标是在 AI 服务中台基础上，建设图片生成任务模块，使短剧制作流程可以从文本资产进入视觉资产生产阶段。

本期需要实现：

| 目标 | 说明 |
| --- | --- |
| 统一图片生成入口 | 支持角色、场景、分镜三个业务对象发起图片生成 |
| 统一任务管理 | 所有图片生成请求以任务形式记录和追踪 |
| 统一图片服务调用 | 通过 AI 服务中台选择可用图片服务，不由业务模块直接调用外部模型 |
| 统一结果管理 | 生成成功图片可预览、下载、保存素材、设置主图 |
| 统一状态流转 | 支持待执行、生成中、生成成功、生成失败、已取消 |
| 支撑后续视频生成 | 分镜首帧图作为后续视频生成的默认输入 |

## 3. 本期范围

### 3.1 包含范围

| 模块 | 说明 |
| --- | --- |
| 图片生成任务创建 | 支持创建角色图、场景图、分镜首帧图生成任务 |
| 图片任务列表 | 支持查看、筛选、取消、重新生成、删除记录 |
| 图片任务详情 | 展示任务参数、提示词、服务信息、结果和失败原因 |
| 图片生成执行 | 调用 AI 服务中台中的图片服务完成生成 |
| 生成结果管理 | 支持大图预览、下载、保存素材、设为主图 |
| 业务对象关联 | 生成结果可关联角色、场景、分镜 |
| 权限控制 | 接入当前系统 RBAC 和租户/项目权限 |
| 调用日志 | 复用或写入 AI 调用日志，记录服务商、模型、耗时、状态 |

### 3.2 不包含范围

| 模块 | 说明 |
| --- | --- |
| 图片局部重绘 | 不支持局部编辑、蒙版重绘 |
| 扩图 | 不支持 outpainting |
| 批量自动生成 | 不支持一键为全部分镜批量生成 |
| 视频生成 | 后续第四期规划 |
| 语音合成 | 后续规划 |
| 成本统计 | 后续 AI 运营治理规划 |
| 自动故障切换 | 本期失败后由用户手动重新生成 |
| 内容审核 | 本期预留状态，不做审核流 |
| Prompt 模板管理 | 本期仅支持手动提示词和业务信息拼接 |

## 4. 业务对象关系

图片生成任务需要和短剧制作核心对象关联。

```text
项目
 ├─ 角色
 │   └─ 角色图片生成任务
 │       └─ 角色图片素材
 ├─ 场景
 │   └─ 场景图片生成任务
 │       └─ 场景图片素材
 └─ 分镜
     └─ 分镜首帧生成任务
         └─ 分镜首帧素材
```

### 4.1 业务对象说明

| 对象 | 说明 |
| --- | --- |
| 项目 | 图片任务必须归属某个短剧项目 |
| 角色 | 角色图任务必须关联角色 |
| 场景 | 场景图任务必须关联场景 |
| 分镜 | 分镜首帧图任务必须关联分镜 |
| 素材 | 生成成功的图片可沉淀为素材 |
| AI 服务配置 | 任务执行时实际使用的图片服务配置 |

## 5. 技术架构

### 5.1 总体链路

```text
前端页面
  -> 创建图片生成任务
    -> 后端校验租户 / 项目 / 权限
      -> 查询可用图片 AI 服务
        -> 创建任务记录
          -> 提交任务执行
            -> 调用外部图片模型
              -> 下载或保存图片结果
                -> 写入生成结果
                  -> 更新任务状态
                    -> 前端轮询查看结果
```

### 5.2 模块划分

建议后端新增或扩展以下包：

```text
com.antshorttv.ai.image
com.antshorttv.ai.image.task
com.antshorttv.ai.image.result
com.antshorttv.ai.gateway
com.antshorttv.material
```

| 模块 | 职责 |
| --- | --- |
| image task | 图片生成任务创建、取消、查询、重新生成 |
| image executor | 图片生成任务执行、服务调用、结果解析 |
| image result | 生成图片结果保存、预览、关联 |
| ai gateway | 统一调用图片类 AI 服务 |
| material | 生成图片保存素材库 |
| business binding | 角色主图、场景主图、分镜首帧图绑定 |

## 7. 状态设计

### 7.1 任务状态

| 状态 | 说明 |
| --- | --- |
| 待执行 | 任务已创建，尚未开始调用 AI 服务 |
| 生成中 | 已开始调用 AI 服务，等待返回结果 |
| 生成成功 | 至少生成一张有效图片 |
| 生成失败 | 未生成有效图片或调用失败 |
| 已取消 | 用户取消任务，或任务尚未执行时被取消 |

### 7.2 状态流转

```text
待执行
 ├─ 开始执行 -> 生成中
 ├─ 用户取消 -> 已取消
生成中
 ├─ 返回有效图片 -> 生成成功
 ├─ 调用失败 / 超时 / 无结果 -> 生成失败
 └─ 用户取消 -> 已取消
生成成功
 └─ 重新生成 -> 创建新任务
生成失败
 └─ 重新生成 -> 创建新任务
已取消
 └─ 重新生成 -> 创建新任务
```

### 7.3 状态规则

| 规则 | 说明 |
| --- | --- |
| 任务状态不可回退 | 已完成状态不允许回到生成中 |
| 重新生成创建新任务 | 不覆盖原任务，保留历史记录 |
| 删除为逻辑删除 | 删除任务记录不删除已保存素材 |
| 部分成功算成功 | 只要返回至少一张有效图片，任务状态为生成成功 |
| 全部失败算失败 | 无有效图片时任务状态为生成失败 |

## 8. 服务选择规则

图片生成任务依赖 AI 服务中台中的图片服务配置。

| 场景 | 处理规则 |
| --- | --- |
| 用户指定图片服务 | 使用指定服务 |
| 用户未指定图片服务 | 使用当前团队默认图片服务 |
| 无默认图片服务 | 使用当前团队启用状态下优先级最高的图片服务 |
| 指定服务已停用 | 阻止提交 |
| 当前团队无可用图片服务 | 阻止提交 |
| 服务调用失败 | 任务失败，不自动切换其他服务 |

本期不做自动故障切换，避免同一任务在不同模型间生成风格不一致。

## 9. 图片生成参数

### 9.1 通用参数

| 参数 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 任务类型 | 是 | 无 | 角色图、场景图、分镜首帧图 |
| 关联对象 | 是 | 无 | 角色、场景或分镜 |

| 清晰度 | 否 | 标准 | 标准、高清 |
| 随机种子 | 否 | 空 | 用于复现相近结果 |

| 任务类型 | 默认比例 | 默认参考信息 |
| --- | --- | --- |
| 角色图 | 3:4 | 角色名称、外貌、身份、气质 |
| 场景图 | 16:9 | 场景名称、空间描述、时间氛围 |

## 12. 任务执行方式

### 12.1 本期建议

本期建议采用“创建任务 + 后端异步执行 + 前端轮询”的方式。

```text
用户提交
  -> 创建任务为待执行
  -> 后端异步执行
  -> 前端轮询任务状态
  -> 生成完成后展示图片
```

### 12.2 执行要求

| 要求 | 说明 |
| --- | --- |
| 异步执行 | 图片生成可能耗时较长，不阻塞前端请求 |
| 状态可查询 | 前端通过任务 ID 查询状态 |
| 超时控制 | 单次任务需有最大执行时长 |
| 幂等控制 | 避免重复点击创建多条相同任务 |
| 异常记录 | 所有异常需写入任务失败原因 |
| 日志记录 | 调用开始、成功、失败均记录日志 |

### 12.3 前端轮询

| 项目 | 建议 |
| --- | --- |
| 轮询间隔 | 2-3 秒 |
| 轮询结束 | 生成成功、生成失败、已取消 |
| 最大轮询时长 | 与后端任务超时时间保持一致 |
| 页面关闭 | 不影响任务执行 |
| 重新进入页面 | 可继续查看任务状态 |

| 图片服务停用 | 阻止提交，提示“当前图片服务已停用” |

| 部分图片失败 | 展示成功图片，任务状态为生成成功，并在详情展示部分失败说明 |
| 图片下载失败 | 任务失败或结果失败，提示图片保存失败 |
| 素材保存失败 | 不影响生成结果展示，允许用户重试保存 |
| 设置主图失败 | 不影响任务结果，提示设置失败原因 |
| 用户重复提交 | 前端按钮 loading，后端做幂等校验 |

## 19. 验收标准

1. 用户可以在角色详情页创建角色图生成任务。
2. 用户可以在场景详情页创建场景图生成任务。
3. 用户可以在分镜详情页创建分镜首帧图生成任务。
4. 图片任务创建时能够正确校验图片服务、提示词、比例、数量。
5. 当前团队无可用图片服务时，任务无法提交，并展示明确提示。
6. 图片任务支持待执行、生成中、生成成功、生成失败、已取消状态。
7. 前端可以轮询查看任务状态。
8. 生成成功后可以展示图片缩略图和大图。
9. 生成成功图片可以保存到素材库。
10. 角色图可以设置为角色主图。
11. 场景图可以设置为场景主图。
12. 分镜首帧图可以设置为分镜首帧。
13. 生成失败时任务详情展示失败原因。
14. 用户可以基于历史任务重新生成，新任务不覆盖旧任务。
15. 删除任务记录不删除已保存素材。
16. 已被业务对象引用的图片不能被静默物理删除。
17. 图片任务按租户和项目隔离。
18. 无权限用户不能创建、取消、删除图片任务。
19. 每次图片模型调用均写入 AI 调用日志。
20. 图片生成相关关键操作均写入操作日志。
