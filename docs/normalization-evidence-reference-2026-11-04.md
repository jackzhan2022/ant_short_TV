# 全剧归一引文错字修复

## 线上原因

项目 75、分析任务 69、执行 181271 的 70 个逐集提取单元已全部成功。最终归一运行 5950、快照 27 在保存时失败，未提交归一变更。

260 个分组、21 项拆分的 99 条引文中，仅 `splits[15].evidence[0]` 不符合冻结原文。对应第 70 集（剧集 ID 1812）：

- 原文：`▲水龙头哗哗流水，王大山在水槽边洗净双手，拿毛巾擦干手。`
- 模型引文：`▲水龙头哗哇流水，王大山在水槽边洗净双手，拿毛巾擦干手。`

模型复制时改了一个字，原有逐字校验因此拒绝整次归一。

## 修复

归一输入按每集 `sourceSegments` 提供完整的非空原文行及片段编号，避免同时重复发送正文。证据优先提交 `episodeId + quoteRef.segmentId`，服务端从冻结原文中提取真实引文；可选 `start/end` 沿用已有 UTF-16 范围、长度及完整字符校验。

保存前深拷贝模型请求，解析引用后仍执行完整的分组、拆分、绑定、作用域及逐字校验。保存真实引文供审计，原始模型请求不变。旧 `quote` 格式仍严格校验，不做模糊匹配或自动纠正引文。无效引文错误增加字段位置和剧集 ID。

继续使用单次归一模型调用及事务保存。重试沿用已成功的逐集单元，只进入尚未完成的归一阶段。
