# 运维监控与桌面资产后端联合发布

## 发布范围

- `/operations` 平台运维中心：总览、接口性能、AI 运行、后台任务、错误、告警及设置。
- 桌面资产接口 `/api/desktop/source-projects`：团队隔离的来源项目与资产名称清单、项目绑定、匹配及读取已有提示词。
- ANTV 生图 0.2.0 桌面客户端：个人模型配置、本地图片、全局最多 5 个图片任务并发。
- 新增 Flyway V174/V175 运维表、权限和扫描索引，V176 来源项目与资产名称表。

## 发布约束

生产地址 `https://antv.aixmax.cn`，沿用现有账号、团队及项目授权。剧本正文、火山登录态、个人模型 Key 和生成图片均不上传至资产清单库。保留共享环境、工作流技能、模型和价格配置。发布前备份数据库及共享资源；保留旧版本和静态资源，失败自动切回旧应用。

即时告警默认关闭，观察期 24 小时。外部探测需要独立主机，未部署验证前保持未配置。火山全部项目枚举仍需真实登录后验证，无法确认完整范围时不宣称同步完整。生产发布不调用付费模型，也不发送人工飞书测试消息。

## 发布前验证

- 隔离 MySQL 8.0 使用生产结构副本执行 V174–V176，验证 14 张新增表和 5 项运维权限。
- 检查扫描 SQL 执行计划及生产业务表规模；隔离实例不包含业务数据。
- 前端运维、权限及计费/商业化回归 110 项通过；Biome、TypeScript 和 antd 检查通过。
- 桌面客户端检查及 39 项测试通过；外部探测脚本 4 项测试通过。
- 后端联合回归、最终构建、线上备份及发布结果在部署完成后补录。
