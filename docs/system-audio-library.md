# 系统音频库

角色音色弹窗提供「本地上传 / 系统音频 / 项目音频库」。系统音频页位于 `/system-audio`，支持搜索、性别和年龄筛选、分页和试听。界面不展示素材包名称或共享说明。

系统素材以 `SYSTEM_AUDIO_ASSET` 保存到现有角色/分镜音色绑定中，使用当前项目作为权限上下文；角色默认继承、分镜独立覆盖和视频生成音频附件继续使用同一条链路。原始音频保存在 `materials/0/system_audio/<年月>/<SHA-256>/v1/original.<mp3|wav>`。系统音频读取和试听要求登录，角色/分镜写入继续检查目标项目编辑权限。试听返回用户绑定的 CDN 授权链接，API 不返回存储密钥。

## 部署

先部署后端，使 Flyway 应用 `V163__system_audio_library.sql`，再发布对应前端。迁移只创建系统音频表，不包含占位音色。回退应用时可保留新增表；若已经绑定系统音频，旧版应用不支持读取此来源，应保留新版后端。

## 素材录入

用户于 2026-10-26 确认稍后提供下载素材的本地目录，本次仅完成开发与导入工具，未下载或录入真实音频，也未修改生产库。

需要 Python 3.11+、FFmpeg 的 `ffprobe`；实际录入还需要 `pymysql` 和腾讯云官方 `cos-python-sdk-v5`。

```powershell
python -m pip install pymysql cos-python-sdk-v5
python scripts/import-system-audio.py "D:\素材\音色库" --report outputs/system-audio-import.json
```

预检检查文件头、音频流、真实时长、文件大小，并按 SHA-256 去重。支持 MP3/WAV，每个文件不超过 10MB。名称保留文件名，目录保留为分类；仅在目录明确包含「男/女」「少年/青年/中年/老年」时填充筛选字段，不明确的字段留空。说明文档和不支持的扩展名列入报告的 `skipped`，应在录入前核对，避免漏掉其他格式的音频。可先按需转码，再重新预检。

预检通过且 V163 已部署后执行：

```powershell
python scripts/import-system-audio.py "D:\素材\音色库" --env backend/env --report outputs/system-audio-import.json --apply
```

`--apply` 使用指定 env 文件中的 MySQL 和对象存储配置。导入逐项校验上传对象后写库，每个成功项即时保存到报告；重复运行复用已有活动记录，停用记录不会被自动重新启用。失败时保留已完成项，报告只记录异常类别，不输出凭据或签名 URL。工具要求 Flyway 已成功应用 V163，不自动建表或改迁移历史。

导入完成应核对报告的有效文件数、重复数、跳过项、错误项及实际录入 ID，再在系统音频页和角色弹窗中试听、绑定，确认角色回显与分镜继承。
