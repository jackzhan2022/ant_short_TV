# 统一短剧分镜制作 Skill 发布（2026-10-18）

## 当前行为

正式分镜 Agent 的内置关联从四份整合为 `short-drama-storyboard-production`，中文名称“短剧分镜制作”。文档包括可信原文、七类导演拆镜方法、景别与运镜、空间/持物/道具状态连续性、动作结果、微表演、对白时长与口型、素材引用、既有字段映射及保存前核对。

平台管理员维护一份系统 Skill；团队所有者/有效 ADMIN 只维护一份统一补充，普通成员只读本团队内容。系统 100 与租户 200 共同加载，冲突时租户创作规则优先；固定 Schema 3、时长、素材校验和富文本文档 2 保持。原文声音新增 `[声音]` 及对白/VO/OS 标签，文字仍由后端注入。

## 迁移与归档

V135 仅迁移分镜内置关联；模型、工具、参数及其他 Agent 关联保持。旧租户规划和视频表达按原顺序合并，完整文档、修订、创建与编辑信息先写入 `tenant_workflow_skill_merge_archive`，再移除旧活动记录。已有统一文档也会留档；迁移具备重复执行与事务回滚测试。

当前生产没有旧租户规则，实际迁移团队数和租户来源留档数均为 0。三个无其他 Agent 引用的旧分镜专用目录已移到 `/opt/antv/shared/workflow-skills/.retired-storyboard-skills/2176c74`，原始字节可恢复；共享基础 Skill 保留供其他 Agent 使用。
