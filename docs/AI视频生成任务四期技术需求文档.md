# AI视频生成任务四期技术需求文档

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 文档名称 | AI视频生成任务四期技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 关联前置能力 | AI 服务中台、AI 图片生成任务、项目管理、角色/场景/分镜基础数据、素材管理 |
| 本期目标 | 建设分镜视频生成任务能力，支持基于分镜首帧图、提示词和镜头参数生成单镜头视频 |
| 服务依赖 | 使用平台已配置的视频类 AI 服务 |
| 不包含 | 语音合成、字幕生成、单镜头音画合成、单集合成、成片导出、成本统计 |

## 2. 建设目标

第四期目标是在第三期图片生成任务基础上，建设 AI 视频生成任务能力，使平台可以将分镜首帧图、分镜描述和镜头语言转化为单个分镜视频，为后续语音、字幕、镜头合成和单集合成提供视频素材。

本期需要实现：

| 目标 | 说明 |
| --- | --- |
| 统一视频生成入口 | 支持在分镜详情、分镜列表和视频任务列表发起视频生成 |
| 统一任务管理 | 所有视频生成请求以任务形式记录和追踪 |
| 统一视频服务调用 | 通过 AI 服务中台选择可用视频服务，不由业务模块直接调用外部模型 |
| 统一状态流转 | 支持待执行、提交中、生成中、生成成功、生成失败、已取消 |
| 统一结果管理 | 生成成功视频可预览、下载、保存素材、设置为分镜视频 |
| 支撑后续合成 | 分镜视频作为后续配音、字幕、单镜头合成和单集合成的基础输入 |

## 4. 业务对象关系

视频生成任务以分镜为核心对象，依赖分镜首帧图和分镜描述，生成结果沉淀为视频素材，并可设置为当前分镜视频。

```text
项目
 └─ 分镜
     ├─ 分镜首帧图
     ├─ 视频生成任务
     │   └─ 分镜视频结果
     │       └─ 视频素材
     └─ 当前分镜视频
```

### 4.1 业务对象说明

| 对象 | 说明 |
| --- | --- |
| 项目 | 视频任务必须归属某个短剧项目 |
| 分镜 | 视频任务必须关联分镜 |
| 分镜首帧图 | 视频生成的默认视觉输入，来自第三期图片生成结果或用户上传素材 |
| 视频任务 | 每次视频生成请求对应一条任务记录 |
| 视频结果 | 服务商生成并保存到平台的视频文件 |
| 素材 | 生成成功的视频可沉淀为项目视频素材 |
| AI 服务配置 | 任务执行时实际使用的视频服务配置 |

## 5. 技术架构

### 5.1 总体链路

```text
前端页面
  -> 创建视频生成任务
    -> 后端校验租户 / 项目 / 权限
      -> 查询可用视频 AI 服务
        -> 创建任务记录
          -> 提交外部视频生成任务
            -> 保存外部任务 ID
              -> 定时查询生成状态
                -> 下载或保存视频结果
                  -> 写入视频结果
                    -> 更新任务状态
                      -> 前端轮询查看结果
```

### 5.2 模块划分

建议后端新增或扩展以下包：

```text
com.antshorttv.ai.video
com.antshorttv.ai.video.task
com.antshorttv.ai.video.result
com.antshorttv.ai.video.polling
com.antshorttv.ai.gateway
com.antshorttv.material
```

| 模块 | 职责 |
| --- | --- |
| video task | 视频生成任务创建、取消、查询、重新生成 |
| video executor | 视频任务提交、服务调用、结果解析 |
| video polling | 外部任务状态查询、超时处理 |
| video result | 视频结果保存、预览、关联 |
| ai gateway | 统一调用视频类 AI 服务 |

| business binding | 分镜视频绑定 |

## 7. 状态设计

### 7.1 任务状态

| 状态 | 说明 |
| --- | --- |
| 待执行 | 任务已创建，尚未提交外部视频服务 |
| 提交中 | 正在向外部服务商提交任务 |
| 生成中 | 外部服务商已受理，视频正在生成 |
| 生成成功 | 至少生成一个有效视频 |
| 生成失败 | 未生成有效视频或服务商返回失败 |
| 已取消 | 用户取消任务，或任务尚未完成时被取消 |

### 7.2 状态流转

```text
待执行
 ├─ 开始提交 -> 提交中
 ├─ 用户取消 -> 已取消
提交中
 ├─ 提交成功 -> 生成中
 ├─ 提交失败 -> 生成失败
 └─ 用户取消 -> 已取消
生成中
 ├─ 查询成功且有视频 -> 生成成功
 ├─ 查询失败 / 超时 / 无结果 -> 生成失败
 └─ 用户取消 -> 已取消
生成成功
 └─ 重新生成 -> 创建新任务
生成失败
 └─ 重新生成 -> 创建新任务
已取消
 └─ 重新生成 -> 创建新任务
```

### 7.3 状态规则

| 规则 | 说明 |
| --- | --- |
| 任务状态不可回退 | 已完成状态不允许回到生成中 |
| 重新生成创建新任务 | 不覆盖原任务，保留历史记录 |
| 删除为逻辑删除 | 删除任务记录不删除已保存视频素材 |
| 外部状态需映射 | 服务商状态需转换为平台统一状态 |
| 取消以平台状态为准 | 若服务商不支持取消，平台标记取消后不再主动绑定结果 |
| 生成成功以有效视频为准 | 必须成功保存至少一个可播放视频文件 |

## 8. 服务选择规则

视频生成任务依赖 AI 服务中台中的视频服务配置。

| 场景 | 处理规则 |
| --- | --- |
| 用户指定视频服务 | 使用指定服务 |
| 用户未指定视频服务 | 使用当前团队默认视频服务 |
| 无默认视频服务 | 使用当前团队启用状态下优先级最高的视频服务 |
| 指定服务已停用 | 阻止提交 |
| 当前团队无可用视频服务 | 阻止提交 |
| 服务调用失败 | 任务失败，不自动切换其他服务 |

本期不做自动故障切换，避免同一分镜在不同模型间生成风格、运动幅度和画面稳定性不一致。

## 9. 视频生成参数

### 9.1 通用参数

| 参数 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 关联分镜 | 是 | 当前分镜 | 视频任务必须关联分镜 |
| 视频服务 | 否 | 默认视频服务 | 可手动选择 |
| 首帧图 | 是 | 当前分镜首帧图 | 可从素材库或生成图片中选择 |
| 尾帧图 | 否 | 无 | 本期预留，用于首尾帧视频生成 |
| 视频提示词 | 是 | 根据分镜信息生成初稿 | 最多 3000 字 |
| 负向提示词 | 否 | 系统默认负向提示词 | 最多 1000 字 |
| 视频比例 | 是 | 9:16 | 支持 9:16、16:9、1:1 |
| 视频时长 | 是 | 5 秒 | 支持 5 秒、8 秒、10 秒，具体以模型支持为准 |
| 分辨率 | 否 | 标准 | 标准、高清 |
| 镜头运动 | 否 | 跟随分镜镜头语言 | 推近、拉远、平移、环绕、固定镜头等 |
| 运镜强度 | 否 | 中 | 弱、中、强 |
| 随机种子 | 否 | 空 | 用于复现相近结果 |

### 9.2 默认值规则

| 场景 | 默认值 |
| --- | --- |
| 从分镜详情发起 | 自动带入当前分镜 |
| 当前分镜已有首帧图 | 自动选中当前首帧图 |
| 当前分镜无首帧图 | 阻止提交，提示先生成或上传首帧图 |
| 视频比例 | 默认跟随首帧图比例，若无法识别则默认 9:16 |
| 视频提示词 | 根据分镜内容、出场角色、场景、镜头语言生成初稿 |
| 视频时长 | 默认 5 秒 |

## 10. 业务场景规则

### 10.1 分镜视频生成

| 项目 | 规则 |
| --- | --- |
| 发起入口 | 分镜详情页、分镜列表快捷操作 |
| 必须关联 | 分镜 |
| 必须输入 | 首帧图、视频提示词、视频比例、视频时长 |
| 默认提示词 | 根据分镜内容、角色、场景、镜头语言、情绪氛围生成 |
| 默认比例 | 跟随首帧图比例，短剧竖屏默认 9:16 |
| 生成结果 | 可保存为分镜视频素材 |
| 主视频设置 | 支持选择一个结果设为当前分镜视频 |
| 历史保留 | 同一分镜可保留多条历史视频任务和多个视频结果 |

### 10.2 分镜视频重新生成

| 场景 | 规则 |
| --- | --- |
| 从失败任务重新生成 | 带入原提示词、首帧图和参数，允许修改后提交 |
| 从成功任务重新生成 | 创建新任务，不覆盖旧视频 |
| 更换首帧图 | 重新生成时允许选择新的首帧图 |
| 更换视频服务 | 重新生成时允许选择其他启用视频服务 |
| 重新生成结果 | 默认不自动替换当前分镜视频，需用户手动设为当前视频 |

### 10.3 分镜视频设置

| 操作 | 规则 |
| --- | --- |
| 设为分镜视频 | 仅生成成功且可播放的视频可设置 |
| 替换当前视频 | 设置新视频后，旧视频保留为历史素材 |
| 取消当前视频 | 本期不提供单独取消入口，可通过设置其他视频替换 |
| 删除当前视频 | 当前分镜视频不允许静默删除，需先解除或替换引用 |

## 12. 任务执行方式

### 12.1 本期建议

本期采用“创建任务 + 提交外部任务 + 后端轮询 + 前端轮询”的方式。

```text
用户提交
  -> 创建任务为待执行
  -> 后端异步提交外部任务
  -> 保存外部任务 ID
  -> 后端定时查询外部任务
  -> 外部生成完成后保存视频
  -> 前端轮询平台任务状态
```

### 12.2 执行要求

| 要求 | 说明 |
| --- | --- |
| 异步执行 | 视频生成耗时较长，不阻塞前端请求 |
| 外部任务 ID | 提交成功后必须保存服务商任务 ID |
| 定时查询 | 后端定时查询生成状态，直到完成、失败或超时 |
| 超时控制 | 单次视频任务需有最大执行时长 |
| 幂等控制 | 避免重复点击创建多条相同任务 |
| 异常记录 | 所有异常需写入任务失败原因 |
| 日志记录 | 提交、查询、成功、失败均记录日志 |

### 12.3 后端轮询

| 项目 | 建议 |
| --- | --- |
| 轮询间隔 | 10-20 秒，具体可按服务商限制调整 |
| 最大轮询时长 | 默认 20 分钟，超过后标记失败 |
| 轮询结束 | 生成成功、生成失败、已取消、超时 |
| 并发控制 | 限制同一团队同时生成中的视频任务数量 |
| 错误重试 | 查询接口临时失败可重试 2-3 次 |

### 12.4 前端轮询

| 项目 | 建议 |
| --- | --- |
| 轮询间隔 | 5 秒 |
| 轮询结束 | 生成成功、生成失败、已取消 |
| 页面关闭 | 不影响任务执行 |
| 重新进入页面 | 可继续查看任务状态 |
| 长时间生成 | 展示“生成耗时较长，请稍后查看”提示 |

| 文件格式 | 本期优先支持 mp4 |

## 16. 异常处理

| 异常 | 处理规则 |
| --- | --- |
| 无可用视频服务 | 阻止创建任务，提示“当前团队未配置可用视频服务” |
| 视频服务停用 | 阻止提交，提示“当前视频服务已停用” |
| 分镜无首帧图 | 阻止提交，提示“请先生成或上传分镜首帧图” |
| 首帧图不可访问 | 阻止提交或任务失败，提示首帧图不可用 |
| 服务商提交失败 | 标记任务失败，记录提交失败原因 |
| 外部任务查询失败 | 临时失败可重试，多次失败后标记任务失败 |
| 外部任务超时 | 标记任务失败，提示视频生成超时 |
| 服务商鉴权失败 | 标记任务失败，提示服务鉴权失败 |
| 模型不支持参数 | 标记任务失败，提示当前模型不支持所选参数 |
| 返回结果为空 | 标记任务失败，提示未生成有效视频 |
| 视频下载失败 | 标记任务失败，提示视频保存失败 |
| 视频不可播放 | 标记结果无效，任务失败或要求重新生成 |
| 素材保存失败 | 不影响生成结果展示，允许用户重试保存 |
| 设置分镜视频失败 | 不影响任务结果，提示设置失败原因 |
| 用户重复提交 | 前端按钮 loading，后端做幂等校验 |

## 19. 验收标准

1. 用户可以在分镜详情页创建视频生成任务。
2. 用户可以在分镜列表中对单条分镜创建视频生成任务。
3. 创建视频任务时能够正确校验视频服务、首帧图、提示词、比例和时长。
4. 当前团队无可用视频服务时，任务无法提交，并展示明确提示。
5. 当前分镜无首帧图时，任务无法提交，并提示先生成或上传首帧图。
6. 视频任务支持待执行、提交中、生成中、生成成功、生成失败、已取消状态。
7. 后端能够保存外部服务商任务 ID，并定时查询生成状态。
8. 前端可以轮询查看平台任务状态。
9. 生成成功后可以在线播放视频。
10. 生成成功视频可以下载。
11. 生成成功视频可以保存到素材库。
12. 生成成功视频可以设置为当前分镜视频。
13. 设置新分镜视频后，旧视频保留为历史素材。
14. 生成失败时任务详情展示失败原因。
15. 用户可以基于历史任务重新生成，新任务不覆盖旧任务。
16. 删除任务记录不删除已保存素材。
17. 已被分镜引用的视频不能被静默物理删除。
18. 视频任务按租户和项目隔离。
19. 无权限用户不能创建、取消、删除视频任务。
20. 每次视频模型提交和查询均写入 AI 调用日志或任务执行日志。
21. 视频生成相关关键操作均写入操作日志。
