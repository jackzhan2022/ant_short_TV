# AI语音字幕与单镜头合成五期技术需求文档

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 文档名称 | AI语音字幕与单镜头合成五期技术需求文档 |
| 所属系统 | 自研短剧制作平台 |
| 关联前置能力 | AI 服务中台、AI 文本创作工作流、AI 图片生成任务、AI 视频生成任务、素材管理、分镜基础数据 |
| 本期目标 | 建设分镜语音合成、字幕生成和单镜头音画合成能力 |
| 服务依赖 | 使用平台已配置的语音类 AI 服务，并复用视频素材处理能力 |
| 不包含 | 单集合成、整集导出、复杂剪辑、角色声纹训练、成本统计 |

## 2. 建设目标

第五期目标是在第四期分镜视频生成能力基础上，补齐分镜声音和字幕生产能力，使单个分镜从“无声视频素材”升级为“带配音、字幕的单镜头片段”，为第六期单集合成和成片导出提供标准输入。

本期需要实现：

| 目标 | 说明 |
| --- | --- |
| 统一语音合成入口 | 支持按分镜旁白、角色对白生成语音 |
| 统一字幕生成能力 | 支持根据旁白/对白文本生成字幕片段 |
| 统一单镜头合成 | 支持将分镜视频、语音、字幕合成为单镜头视频 |
| 统一任务管理 | 语音合成、字幕生成、镜头合成均以任务形式记录和追踪 |
| 统一结果管理 | 生成音频、字幕、合成视频可预览、下载、保存素材、绑定分镜 |
| 支撑整集合成 | 单镜头合成结果作为第六期单集合成的基础输入 |

## 4. 业务对象关系

第五期以分镜为核心对象，将视频、音频、字幕合成为单镜头产物。

```text
项目
 └─ 分镜
     ├─ 当前分镜视频
     ├─ 旁白 / 对白文本
     ├─ 语音合成任务
     │   └─ 音频结果
     ├─ 字幕生成结果
     └─ 单镜头合成任务
         └─ 单镜头合成视频
```

### 4.1 业务对象说明

| 对象 | 说明 |
| --- | --- |
| 项目 | 所有任务必须归属某个短剧项目 |
| 分镜 | 语音、字幕、单镜头合成任务必须关联分镜 |
| 分镜视频 | 单镜头合成的基础视频输入，来自第四期视频生成结果或用户上传视频 |
| 分镜文本 | 旁白、对白、字幕生成的文本来源 |
| 音频结果 | 语音合成输出的音频文件 |
| 字幕结果 | 根据文本和音频生成的字幕数据 |
| 单镜头视频 | 分镜视频、语音、字幕合成后的镜头片段 |
| 素材 | 音频、字幕文件、合成视频可沉淀为素材 |

## 5. 技术架构

### 5.1 总体链路

```text
前端页面
  -> 创建语音合成任务
    -> 调用语音 AI 服务
      -> 保存音频结果
        -> 生成字幕数据
          -> 创建单镜头合成任务
            -> 读取分镜视频 / 音频 / 字幕
              -> 后端媒体处理
                -> 输出单镜头视频
                  -> 绑定到分镜
```

### 5.2 模块划分

建议后端新增或扩展以下包：

```text

com.antshorttv.ai.subtitle
com.antshorttv.media.compose
com.antshorttv.media.ffmpeg
com.antshorttv.material
```

| 模块 | 职责 |
| --- | --- |
| voice task | 语音合成任务创建、查询、取消、重新生成 |
| voice executor | 调用语音模型、保存音频结果 |
| subtitle | 字幕生成、字幕时间轴、字幕样式配置 |
| compose | 单镜头音画合成任务创建和执行 |
| ffmpeg | 视频、音频、字幕合成处理 |

## 7. 状态设计

### 7.1 语音合成任务状态

| 状态 | 说明 |
| --- | --- |
| 待执行 | 任务已创建，尚未调用语音服务 |
| 合成中 | 正在调用语音服务生成音频 |
| 合成成功 | 已生成有效音频 |
| 合成失败 | 未生成有效音频或调用失败 |
| 已取消 | 用户取消任务 |

### 7.2 单镜头合成任务状态

| 状态 | 说明 |
| --- | --- |
| 待执行 | 任务已创建，尚未开始媒体合成 |
| 合成中 | 正在执行视频、音频、字幕合成 |
| 合成成功 | 已生成有效单镜头视频 |
| 合成失败 | 合成失败或输出文件无效 |
| 已取消 | 用户取消任务 |

### 7.3 状态规则

| 规则 | 说明 |
| --- | --- |
| 任务状态不可回退 | 已完成状态不允许回到执行中 |
| 重新生成创建新任务 | 不覆盖原任务，保留历史记录 |
| 删除为逻辑删除 | 删除任务记录不删除已保存素材 |
| 语音成功以有效音频为准 | 必须成功保存可播放音频文件 |
| 合成成功以有效视频为准 | 必须成功保存可播放单镜头视频文件 |
| 当前绑定需唯一 | 同一分镜只能有一个当前音频、当前字幕、当前单镜头结果 |

## 8. 服务选择规则

语音合成任务依赖 AI 服务中台中的语音服务配置。

| 场景 | 处理规则 |
| --- | --- |
| 用户指定语音服务 | 使用指定服务 |
| 用户未指定语音服务 | 使用当前团队默认语音服务 |
| 无默认语音服务 | 使用当前团队启用状态下优先级最高的语音服务 |
| 指定服务已停用 | 阻止提交 |
| 当前团队无可用语音服务 | 阻止提交 |
| 服务调用失败 | 任务失败，不自动切换其他服务 |

本期不做自动故障切换，避免同一角色的声音表现不一致。

## 11. 单镜头合成规则

### 11.1 合成输入

| 输入 | 是否必填 | 说明 |
| --- | --- | --- |
| 分镜视频 | 是 | 来自第四期视频生成结果或用户上传视频 |
| 音频 | 否 | 来自语音合成结果；无音频时可仅合成字幕 |
| 字幕 | 否 | 来自字幕结果；用户可选择不加字幕 |
| 合成配置 | 否 | 字幕样式、音量、输出格式等 |

### 11.2 合成规则

1. 分镜必须存在可播放视频，才允许创建单镜头合成任务。
2. 若选择音频，系统将音频与视频合并。
3. 若音频时长短于视频，视频保持原时长，音频播放结束后静音。
4. 若音频时长长于视频，本期默认以视频时长为准裁剪音频。
5. 若选择字幕，字幕需烧录到视频画面中。
6. 本期输出格式优先为 mp4。
7. 合成成功后，用户可设置为【当前单镜头视频】。

### 11.3 输出规则

| 输出 | 说明 |
| --- | --- |
| 合成视频 | 视频、音频、字幕合成后的单镜头视频 |
| 视频封面 | 默认使用视频首帧 |
| 素材记录 | 可保存为视频素材 |
| 分镜绑定 | 可设置为当前分镜单镜头结果 |

## 13. 任务执行方式

### 13.1 语音合成执行

```text
用户提交
  -> 创建语音任务为待执行
  -> 后端异步调用语音服务
  -> 保存音频文件
  -> 生成或关联字幕
  -> 更新任务状态
```

### 13.2 单镜头合成执行

```text
用户提交
  -> 创建合成任务为待执行
  -> 后端校验视频 / 音频 / 字幕文件
  -> 执行媒体合成
  -> 保存合成视频和封面
  -> 更新任务状态
```

### 13.3 执行要求

| 要求 | 说明 |
| --- | --- |
| 异步执行 | 语音合成和视频合成都不阻塞前端请求 |

## 17. 异常处理

| 异常 | 处理规则 |
| --- | --- |
| 无可用语音服务 | 阻止创建语音任务，提示“当前团队未配置可用语音服务” |
| 语音服务停用 | 阻止提交，提示“当前语音服务已停用” |
| 合成文本为空 | 阻止提交，提示“请输入合成文本” |
| 音色不可用 | 阻止提交或任务失败，提示“当前音色不可用” |
| 语音服务超时 | 标记任务失败，记录超时原因 |
| 语音结果为空 | 标记任务失败，提示未生成有效音频 |
| 字幕时间轴异常 | 阻止保存或提示自动修正 |
| 分镜无视频 | 阻止创建合成任务，提示“请先生成或上传分镜视频” |
| 音频文件不可访问 | 阻止合成或任务失败，提示音频不可用 |
| 字幕文件生成失败 | 不影响音频结果，允许用户重试字幕生成 |
| 媒体合成失败 | 标记合成任务失败，展示失败原因 |
| 合成视频不可播放 | 标记结果无效，任务失败或要求重新合成 |
| 用户重复提交 | 前端按钮 loading，后端做幂等校验 |

## 20. 验收标准

1. 用户可以在分镜详情页创建语音合成任务。
2. 用户可以基于分镜旁白生成旁白音频。
3. 用户可以基于角色对白生成对白音频。
4. 当前团队无可用语音服务时，语音任务无法提交，并展示明确提示。
5. 语音合成成功后可以在线试听音频。
6. 语音合成成功后可以将音频设置为当前分镜音频。
7. 用户可以根据语音文本和音频生成字幕。
8. 用户可以编辑字幕文本、开始时间、结束时间和基础样式。
9. 用户可以导出字幕 SRT 文件。
10. 用户可以基于分镜视频、音频和字幕创建单镜头合成任务。
11. 分镜无可用视频时，单镜头合成任务无法提交，并展示明确提示。
12. 单镜头合成成功后可以在线播放视频。
13. 单镜头合成成功后可以下载视频。
14. 单镜头合成成功后可以设置为当前分镜单镜头结果。
15. 用户可以基于历史任务重新生成语音或重新合成视频，新任务不覆盖旧任务。
16. 删除任务记录不删除已保存素材。
17. 已被分镜引用的音频、字幕、单镜头视频不能被静默物理删除。
18. 语音、字幕、合成任务按租户和项目隔离。
19. 无权限用户不能创建、取消、删除相关任务。
20. 每次语音模型调用均写入 AI 调用日志。
21. 语音、字幕、单镜头合成关键操作均写入操作日志。
