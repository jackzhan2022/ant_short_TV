# 自由创作发布说明（2026-10-23）

自由创作由管理员页面扩展为独立的图片／视频生成入口，接入现有模型、上传、执行调度、积分预估与结算、私有媒体预览和下载。

- 我的创作按当前团队及创作人查询；团队素材展示当前团队所有成员的创作，无分享状态或分享操作。
- 创作记录包含缩略图、参考素材、提示词、创作人、时间、模型和参数，支持筛选、搜索、详情及复用。
- 入口和接口要求平台管理员且为当前团队有效成员。上传会话校验用户与团队，既有素材复用校验团队及发布状态。
- 请求幂等；已受理视频保持远端并发占用，降低并发限制不阻塞其继续轮询；失效执行不能结算或发布结果。
- OpenAI Responses 图片接口数量为1，其他现有图片适配器保留各自数量能力。

## 数据库与发布

新增 Flyway V148，仅新增 free_creation 和 free_creation_media 两张表及索引，不修改既有业务表。后端启动时执行迁移。

按 docs/antv-deployment-runbook.md 从已推送的 master 提交构建。部署前校验线上版本与迁移历史，备份数据库、共享技能及运行环境，等待 AI 执行排空后切换版本。发布后验证服务健康、静态资源、V148、管理员读取及普通成员拒绝访问。

旧版本不识别 FREE_CREATION 任务；新版本产生进行中的自由创作任务后，回退前应先等待其完成或明确处理，不直接把仍在执行的任务交给旧版本。
