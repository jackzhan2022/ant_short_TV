# 资产形态详情超限自动降级

`read_asset_details` 保留默认完整详情返回方式。只有完整响应超过既有 32 KiB 响应预算及 2 KiB 安全余量时，才在同一次工具调用内自动返回摘要，不需要额外模型请求或重新调用工具。

## 返回协议

- 正常：`detailLevel=FULL`、`degraded=false`。保留当前页的完整资产元数据、形态内容、提示词和证据；每个资产仍按最多 20 个形态分页。
- 超限：`detailLevel=SUMMARY`、`degraded=true`、`degradationReason=RESPONSE_SIZE_LIMIT`。保留所有请求的资产及其可信标识、名称、提示词存在状态；形态保留标识、名称、默认/本集绑定状态和最多 120 个 Unicode 码点的外观描述。长提示词、完整证据及其他元数据不返回，`contentTruncated` 标明内容省略。
- 摘要为每个请求资产预留返回空间；形态不完全装入时，保留 `hasMore` 和可信 `nextCursor`。续页以指定单个资产读取，游标指向最后实际返回的形态，不能跳过已加载但未返回的形态。后续请求仍默认尝试完整详情。
- `hasPrompt=true` 始终表示数据库里已存在非空提示词，不能因为摘要没有 `prompt` 就重新生成。摘要不能被当成已读取完整证据。

大小判断基于同一次读取获得的数据，不重新查询数据库。权限拒绝、资产不存在、游标不属于当前作用域、元数据损坏和数据库故障仍正常失败，不会被自动降级掩盖。摘要自身仍无法安全容纳时明确报错，不能静默漏掉资产。

工具名称和输入参数不变，原有调用无需选择模式。运行协议、内置技能及持久化技能 v3 追加规则同步更新；保留既有自定义技能内容，重复启动不会重复追加。

## 验证

211 项相关后端回归通过，覆盖默认完整详情、单资产/单形态/多资产合计超限、摘要大小与连续分页、错误隔离、旧查询兼容、持久化技能升级，以及完整/摘要均可在同一次详情调用后正常保存的 Agent 流程。未在测试中调用付费模型。
