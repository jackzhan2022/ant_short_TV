# ANTV 生图 0.2.2 火山登录窗口白屏修复

## 原因与修复

独立 Electron 45.2.3 进程、全新临时用户目录复现：调试器已连接，但窗口 URL 为空且没有开始导航；`Network.enable` 一直等待。对照实验保持相同运行时和窗口设置，启动首次导航后该命令立即完成并跳转火山登录页。

原实现等待 `Network.enable` 后才调用 `loadURL`，而前者依赖首次导航创建的渲染进程，形成相互等待。现在先注册列表观察器，再同时启动网络监听和首次导航。重复打开会等待同一次初始化；初始化或导航失败时销毁失败窗口，显示错误，下次点击可重新创建，持久登录会话保持原分区。
