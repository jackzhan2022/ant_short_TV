# 分镜技能2.0：参考风格对齐更新

已发布，名称仍为“分镜技能2.0”。

- 新增切镜门槛：切换需要必要信息或观察角度，减少起手、重复反应和重复成品展示。
- 新增对白交锋、连续工序、群体反应、抵达与转场四类组织示例，同时保留关键接触、细节及结果的必要切镜。
- 整句对白先计时，再分配镜头；6.5秒内能自然说完时优先同镜。长句跨镜共用预算，不因切镜重复加停顿，不提高语速硬压台词。
- 密集串行动作应明确跳切，必要时增加可读时间；不能仅为少镜头把多步操作塞进极短镜头。
- 分镜内镜头时长求和为整数，明确分配半秒余量；补充一次生成前的参考风格对齐检查。

验证：9项后端相关测试通过；前端Biome/TypeScript及antd检查通过，保留原有非阻断提示。通用Codex技能检查器只接受英文hyphen-case名称，本平台按用户指定保留中文名称，平台技能加载测试通过。

本轮完成技能更新、检查及热发布，未重新生成剧集，尚无本版的镜头数和时长实测结论。现存70集对比结果仍属于上一技能版本。群体对白的上游分类问题不在本轮技能更新中修复。
