接口契约

方法路径用途
GET/api/team-miniapps/code/templates普通模板查询
POST/api/team-miniapps/{id}/code/commit上传开发版本
GET/api/team-miniapps/{id}/code/trial-qrcode体验二维码，可选path

{id} 是平台数据库中的小程序绑定记录ID，不是AppID。沿用登录会话、X-Tenant-Id，POST需CSRF。

{"templateId":0,"version":"0.1.0","description":"基础剧库选集播放模板"}

上传成功返回data.status=SUCCEEDED。未知结果返回HTTP 502、errorCode=WECHAT_COMMIT_UNKNOWN、data.status=UNKNOWN，不应自动重试。

权限与安全

  • 平台管理员和团队MINIAPP:MANAGE双重检查，保留团队隔离。
  • 上传及二维码仅接受启用且有效的官方授权；上传权限集18，二维码18或86。
  • 模板ID 0合法；服务端构造目标extAppid，授权凭据不返回客户端。
  • 上传不自动重试，不跟随重定向；同AppID单JVM并发锁，不是跨实例持久化幂等。
  • 二维码仅接受符合类型与签名的PNG/JPEG，最大2MiB；错误JSON不作为图片。no-store、nosniff。
